# 💼 회사 DB 사용 관련 매뉴얼

> [!ABSTRACT] 🏢 사내 시험/계측 데이터 플랫폼 매뉴얼 허브
> 사내 Insight Portal 계정 활성화, Databricks 클러스터(Warehouse) 연동, Tableau Desktop 시각화 대시보드 구축 및 제동평가 데이터베이스 스키마와 SQL 쿼리 매뉴얼 모음입니다.

---

## 📑 매뉴얼 구성 및 바로가기

### 1. [[20_회사_Tableau_사용_매뉴얼|Tableau 사내 DB 연동 매뉴얼]]
* **Insight Portal 계정 활성화**: 포털 재접속 및 권한 상태 확인
* **Teams 라이선스 인증**: SSO 세션 연동 유지
* **Databricks SQL Warehouse 연결**: Host, HTTP Path, 포트 설정 및 웹 브라우저 인증 (스크린샷 4종 포함)

---

### 2. 📊 [[20_제동평가_DB칼럼명_및_타입정리|제동평가(Dry, Wet, Snow) DB 컬럼명 및 타입 정리]]
* **Databricks 3대 제동 시험 통합 스키마** (총 65개 컬럼):
  * **핵심 키 & 공통 (1~16번)**: `TRS_TITM_OBJ_TBLK`, `RQST_CD`, `TIRE_SET_VAL`, `DATA_CRDTM` 등
  * **Wet / Snow 공통 (17~18번)**: `BRKGT_BRKGDST_AVRG`, `BRKGT_IDX`
  * **Dry / Wet 공통 (19~32번)**: `TMPR_AIR_STRT`, `TMPR_SUF_STRT`, `HUMD_STRT`, `WND_SPEED_STRT` 등 환경 인자
  * **Wet 고유 (33~34번)**: `BRKGT_BRKGDST_STDDVT`, `BRKGT_BRKGDST_CNCRTN`
  * **Snow 고유 및 랩별 (35~65번)**: `BRKGT_FIRST_DRVR_RES_AVRG`, `BRKGT_RDSF_TMPRT`, `BRKGT_SRDSF_HRDN` 등

---

### 3. 📐 [[10_계산필드|Tableau 계산된 필드(Calculated Fields) 수식 가이드]]
* `BRK_DIST_INPUT_BRK_TYPE`: 매개변수에 따른 Dry/Wet/Snow 제동거리 자동 분기
* `VAR_FIX_X_AVR_Y`: 세트 기준 평균 거리 고정(LOD 수식)
* `VAR_Y_INPUT_BRK_TYPE`: 동적 Y축 전환 공식
* `TEST_BRK_SNOW_BRKGT_BRKGDST_DRIVER_AVRG`: 1차/2차 드라이버 결과 병합 로직

---

### 4. 🛠️ [[11_스펙인자_만들기|PLM 타이어 스펙 인자 생성 SQL 쿼리]]
* **PLM 스펙 기본 테이블**(`tb_pl_dw_spec_plm_tire_bas`)과 **시험의뢰 스펙 테이블**(`tb_th_req_tire_spec_bas`) 조인 SQL
* 캡트레드/서브트레드 컴파운드, 그루브 깊이, 벨트 각도, 비드필러 등 13대 분석 인자 매핑
