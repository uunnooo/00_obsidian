## 🏛️ 1. SVM(분류) vs SVR(회귀): 도로를 놓는 상반된 철학

서포트 벡터 머신(SVM)과 서포트 벡터 회귀(SVR)는 **"공간에 최적의 초평면(도로, Hyperplane)을 구축한다"**는 공통 수학적 기반을 공유하지만, **도로를 활용하는 목적과 방식은 정반대**입니다.

```
       [ SVM (분류) : 도로 비우기 ]                     [ SVR (회귀) : 도로 채우기 ]
   클래스 A                                                    
      ●   ●                                         ●       ┌───────────────┐ +ε
   ─────────────── (마진 경계)                                 │   ●   ●   ●   │
      ( 도로 : 데이터 진입 금지! )              ── ─ ─ ─ ─ ─ ─ ─│─ ─ ─ ─ ─ ─ ─ ─│─ ─ 중심 초평면 f(x)
   ─────────────── (마진 경계)                                 │ ●   ●     ●   │
          ▲   ▲                                     ●       └───────────────┘ -ε (ε-불감대 튜브)
       클래스 B                                             * 튜브 밖 점들만 오차 페널티
```

### 1) 비교 매트릭스

| 비교 항목 | 서포트 벡터 머신 (SVM, Classification) | 서포트 벡터 회귀 (SVR, Regression) |
| :--- | :--- | :--- |
| **궁극적 목표** | 두 이종 데이터 집단을 가장 안전하게 **분리(Separation)** | 데이터의 전반적인 추세와 흐름을 가장 잘 **적합(Fitting)** |
| **초평면의 역할** | 두 집단을 가르는 **결정 경계(Decision Boundary)** | 데이터 중심을 통과하는 **예측 함수 곡선/곡면 ($f(x)$)** |
| **마진(도로)의 철학** | **"도로 내부를 완전히 비워라!"**<br>마진 폭을 최대화하여 양 집단 사이의 안전거리 확보 | **"도로 내부에 최대한 많은 데이터를 품어라!"**<br>$\pm \epsilon$ 폭의 불감대(Tube) 안의 오차는 0으로 완전 무시 |
| **서포트 벡터 (SV)의 정의** | 마진 경계선 상에 걸쳐서 **도로의 폭을 떠받치는 점들** | $\epsilon$-튜브 바깥으로 벗어나서 **도로의 경로를 잡아당기는 점들** |
| **과적합 제어 핵심** | 마진 경계 침범을 얼마나 허용할 것인가 ($C$) | 튜브 폭($\epsilon$)과 튜브 이탈에 대한 페널티 강도($C$) |

### 2) 중요한 정정: 초평면(Hyperplane)의 개수는 정하는 것이 아닙니다
* **SVR에서 결정 초평면(회귀 함수)은 언제나 단 1개로 고정**입니다. 사용자가 늘리거나 줄일 수 있는 값이 아닙니다.
* 따라서 *"초평면 개수가 많으면 과적합, 적으면 과소적합"*이라는 서술은 오류이며, **실제 모델의 복잡도와 유연성을 결정하는 것은 "서포트 벡터(Support Vector)의 개수"**입니다.
* 서포트 벡터의 개수 또한 사용자가 직접 숫자로 지정하는 것이 아니라, 사용자가 설정한 **$\epsilon$(튜브 폭), $C$(페널티), $\gamma$(커널 영향 반경)**의 조합에 의해 최적화 알고리즘이 자동으로 결정하는 **결과값(Consequence)**입니다.

## 🌀 2. 초평면은 직선/평면인데, 어떻게 구불구불한 곡선이 되는가?

초평면(Hyperplane)은 수학적 정의상 절대 구부러질 수 없는 **'완벽하게 평평한 선(2D) 또는 평면(3D+)'**입니다.  
그렇다면 평평한 칼(초평면)로 어떻게 둥글게 둘러싸인 데이터나 물결치는 비선형 시계열을 분리하고 회귀할 수 있을까요?

그 해답은 **"차원 상승(Mapping to High-Dimensional Feature Space)"**과 **"커널 트릭(Kernel Trick)"**에 있습니다.

### 1) 1차원 $\to$ 2차원 차원 상승의 기하학적 직관
수직선(1차원 $x$) 위에 다음과 같이 점들이 놓여 있다고 가정해 봅니다:
* **내부 데이터 (클래스 A)**: $x = -1, 0, 1$ (원점 부근 밀집)
* **외부 데이터 (클래스 B)**: $x = -3, -2, 2, 3$ (양쪽 끝으로 분산)

1차원 공간에서는 단 하나의 점(칼)으로 클래스 A와 B를 동시에 가를 수 없습니다. (비선형 분리 불가능)

이때 각 데이터 $x$에 대해 **$\phi(x) = (x, x^2)$**이라는 2차원 변환 함수를 적용해 봅니다:
* 클래스 A 점들: $(-1, 1), (0, 0), (1, 1)$ $\to$ 2차원 좌표계 아래쪽에 모임
* 클래스 B 점들: $(-2, 4), (2, 4), (-3, 9), (3, 9)$ $\to$ 2차원 좌표계 위쪽에 위치

이제 2차원 공간에서는 $y = 2$라는 **완벽하게 곧은 수평 직선(1차원 초평면)** 하나만 쓱 그어도 두 집단이 단칼에 완벽히 분리됩니다!

> 💡 **핵심 원리**:  
> **"저차원에서 복잡하게 얽혀 있는 데이터라도, 충분히 높은 고차원 공간으로 들어 올리면 완벽한 평평한 평면(초평면)으로 자를 수 있다."**  
> 고차원 공간에서는 칼(초평면)을 전혀 구부리지 않고 평평하게 잘랐지만, 그 단면을 **원래의 저차원 세계로 투영하여 내려다보면 구불구불한 '곡선'이나 '원형 경계선'**으로 보이게 되는 것입니다.

### 2) 커널 트릭 (Kernel Trick): 차원의 저주를 피하는 지름길
"차원을 올리면 해결된다"는 것을 알았지만, 현실적인 심각한 장벽이 있습니다:
* 2차원 데이터를 100차원, 10,000차원, 혹은 무한 차원으로 매핑하려면 엄청난 컴퓨터 메모리와 계산 시간이 소모됩니다. (차원의 저주)

SVM과 SVR의 최적화 유도 식(듀얼 폼, Dual Formulation)을 면밀히 분석하면 경이로운 성질이 드러납니다:
$$\max_{\alpha} \sum_{i} \alpha_i - \frac{1}{2} \sum_{i} \sum_{j} \alpha_i \alpha_j y_i y_j \mathbf{\langle \phi(x_i), \phi(x_j) \rangle}$$
* 최적화 수식에서 고차원 좌표 벡터 $\phi(x)$ 자체가 단독으로 쓰이는 곳은 단 한 군데도 없으며, **오직 두 데이터 간의 내적(Dot Product: 유사도 측정값) $\langle \phi(x_i), \phi(x_j) \rangle$ 형태로만 사용**됩니다.
* 수학자들은 고차원으로 직접 좌표를 변환하지 않고도, 원래 저차원 공간의 좌표들만 가지고 특정 함수를 거치면 고차원 내적과 동일한 값을 즉시 뱉어내는 함수 $K(x, x')$를 찾아냈습니다:
$$K(x_i, x_j) = \langle \phi(x_i), \phi(x_j) \rangle$$
* 이것이 바로 **커널 트릭(Kernel Trick)**입니다.  
  컴퓨터는 데이터를 10,000차원으로 올리는 계산을 단 한 번도 수행하지 않고도, **저차원에서의 가벼운 커널 계산 하나로 마치 무한 차원에서 초평면을 그은 것과 100% 동일한 효과**를 냅니다.

## ⛺ 3. RBF (가우시안) 커널의 물리적 비밀: "서포트 벡터마다 텐트 치기"

현업에서 가장 널리 쓰이는 커널은 **RBF(Radial Basis Function, 방사 기저 함수, 가우시안 커널)**입니다:
$$K(x_i, x) = \exp\left(-\gamma \|x_i - x\|^2\right)$$

수학적으로 RBF 커널은 데이터를 **'무한 차원 힐베르트 공간'**으로 매핑하는 것과 완전히 같습니다.  
이를 물리적인 현실 세계의 감각으로 이해하면 **"서포트 벡터마다 종 모양(가우시안) 텐트를 세우는 것"**입니다.

### 1) 곡선이 합성되는 3단계 메커니즘
SVR의 최종 예측 함수는 다음과 같습니다:
$$f(x) = \sum_{i \in SV} (\alpha_i - \alpha_i^*) K(x_i, x) + b$$

```
   [1단계: SV 선정]            [2단계: 가우시안 텐트 기립]              [3단계: 텐트 중첩 및 최종 곡선]
  
      ● (SV 1)                      ▲ 텐트 1      ▲ 텐트 2                 ╭────────╮
                                   / \           / \                      /          \_______
      ● (SV 2)                    /   \         /   \                    /                   \
  ─────────────────           ───/─────\───────/─────\───             ──/─────────────────────\──
   데이터 공간                 가우시안 종 모양 기저 함수 생성         부드럽게 이어진 비선형 회귀 곡선 f(x)
```

1. **서포트 벡터(말뚝) 박기**: 모델 학습이 끝나면 전체 데이터 중 $\epsilon$-튜브 경계에 걸치거나 벗어난 핵심 점들만 **서포트 벡터(Support Vector)**로 채택됩니다.
2. **텐트(봉우리) 세우기**: 각 서포트 벡터의 위치 $x_i$에 중심이 솟아오른 종 모양(가우시안 텐트)이 세워지며, 오차의 크기에 비례하는 가중치 $(\alpha_i - \alpha_i^*)$가 텐트의 높이와 부호를 결정합니다.
3. **부드러운 곡면 합성**: 각 말뚝에서 뿜어져 나오는 텐트 천들이 서로 겹치고 중첩(Superposition)되면서, 꺾이거나 각지지 않은 **극도로 매끄러운 유선형 곡선(2D) 또는 등고선 곡면(3D)**이 형성됩니다.

## 🎛️ 4. SVM / SVR 전수 하이퍼파라미터 마스터 레퍼런스

Scikit-learn의 `SVR`, `SVC`, `NuSVR`, `NuSVC`에서 제공하는 전수 하이퍼파라미터를 목적별로 완벽 정리합니다.

### 1) 핵심 3대장 조절 손잡이 ($C, \epsilon, \gamma$)
모델의 복잡도와 과적합/과소적합 여부를 결정짓는 95% 이상의 지분은 이 3개 파라미터가 쥐고 있습니다.

| 파라미터 | 명칭 및 정의 | 값을 키울 때 ($+$) | 값을 줄일 때 ($-$) | 과적합 방향 |
| :---: | :--- | :--- | :--- | :---: |
| **$\epsilon$**<br>(`epsilon`) | **불감대 마진 폭**<br>(SVR 전용) | 튜브가 넓어짐 $\to$ 대부분 점을 수용 $\to$ SV 감소 $\to$ **단순하고 평평한 모델** | 튜브가 좁아짐 $\to$ 미세 노이즈까지 SV로 지정 $\to$ SV 급증 $\to$ **극도로 복잡한 모델** | **$\epsilon \downarrow$**<br>(줄이면 과적합) |
| **$C$** | **오차 페널티 가중치**<br>(규제의 역수) | 튜브 밖 오차를 절대 용납 안 함 $\to$ 데이터 하나하나에 과도하게 밀착 $\to$ **구불구불한 모델** | 오차를 관대하게 포용 $\to$ 큰 마진 우선 $\to$ **부드럽고 완만한 모델** | **$C \uparrow$**<br>(키우면 과적합) |
| **$\gamma$**<br>(`gamma`) | **RBF 커널 영향 반경**<br>(가우시안 폭의 역수) | 봉우리가 뾰족하고 좁아짐 $\to$ 각 점 주변 국소 영역에만 맹렬히 반응 $\to$ **극단적 굴곡** | 봉우리가 넓고 완만해짐 $\to$ 먼 거리 점까지 영향력 공유 $\to$ **직선에 가까운 모델** | **$\gamma \uparrow$**<br>(키우면 과적합) |

> ⚠️ **골디락스(Goldilocks) 규칙**:
> * **최악의 과적합 조합**: $C$ 매우 큼 + $\gamma$ 매우 큼 + $\epsilon$ 매우 작음 $\to$ 훈련 데이터 암기, 외삽 시 진동/말림 폭발.
> * **최악의 과소적합 조합**: $C$ 매우 작음 + $\gamma$ 매우 작음 + $\epsilon$ 매우 큼 $\to$ 데이터를 무시하고 단순 수평선 추종.

### 2) 커널(Kernel) 기하 형상 파라미터
* **`kernel`** (`'rbf'`, `'poly'`, `'linear'`, `'sigmoid'`):
  * 차원 상승에 사용할 수학적 커널 함수를 지정합니다. 기본값은 `'rbf'`(가우시안)입니다.
* **`degree`** (다항식 차수, `poly` 전용, 기본값 `3`):
  * $K(x, x') = (\gamma \langle x, x' \rangle + coef0)^{\mathbf{degree}}$
  * 곡선을 $N$차 다항식 곡선으로 피팅합니다. 차수가 커질수록 변곡점이 늘어나며 외삽 영역에서 발산 위험이 급증합니다.
* **`coef0`** (독립 상수항, `poly` 및 `sigmoid` 전용, 기본값 `0.0`):
  * 고차항(고차 다항식)과 저차항(기본 선형 성분) 간의 영향력 균형을 조절합니다. 값이 클수록 고차 비선형성이 두드러집니다.

### 3) 이상치 비율 기반 직관적 제어: $\nu$ (Nu-SVR / Nu-SVC)
* **`nu`** ($\nu$, 범위: $(0, 1]$, 기본값 `0.5`):
  * $C$와 $\epsilon$은 데이터의 물리적 단위(m, kg, V 등)에 종속적이어서 직관적인 설정이 어렵습니다.
  * `NuSVR`의 $\nu$ 파라미터는 **"서포트 벡터 개수의 하한선"**이자 **"튜브 밖 마진 오류(이상치) 비율의 상한선"**을 비율(%)로 직접 통제합니다.
  * 예: `nu=0.15`로 설정 시 $\to$ *"전체 데이터 중 최대 15%까지만 이상치(오차)로 허용하고, 최소 15%의 서포트 벡터를 확보하겠다"*는 의미를 가집니다.

### 4) 수치 최적화 및 연산 속도 제어 파라미터
* **`tol`** (Tolerance, 수렴 허용 오차, 기본값 `1e-3`):
  * 최적화 알고리즘(SMO)의 정지 조건입니다. 값을 줄이면(`1e-4`, `1e-5`) 더 정밀한 전역 최적해를 찾지만 연산 시간이 선형/지수적으로 증가합니다.
* **`shrinking`** (수축 휴리스틱, 기본값 `True`):
  * 최적화 과정에서 서포트 벡터가 될 가능성이 현저히 낮은 데이터 포인트를 조기에 계산 대상에서 배제하여 학습 속도를 획기적으로 향상시킵니다.
* **`cache_size`** (커널 행렬 캐시 메모리, MB 단위, 기본값 `200`):
  * RBF 커널 계산 결과를 RAM에 캐싱하는 크기입니다. 데이터가 수만 건 이상인 경우 `1000`~`2000`(1~2GB)으로 늘리면 계산 병목이 크게 해소됩니다.
* **`max_iter`** (최대 반복 횟수, 기본값 `-1` 무제한):
  * 스케일링 미적용 등으로 인해 수렴하지 않고 루프가 도는 경우를 방지하기 위한 강제 정지 상한선입니다.

### 5) 분류(SVC) 전용 특수 파라미터
* **`class_weight`** (`None` 또는 `'balanced'`):
  * 불균형 데이터셋(예: 정상 98%, 고장 2%)에서 소수 클래스에 페널티 가중치 $C$를 자동으로 역비례 증폭시켜 오분류를 방어합니다.
* **`probability`** (`True`/`False`, 기본값 `False`):
  * SVM은 본래 거리를 산출하는 결정론적 모델입니다. `True` 활성화 시 내부적으로 5-Fold 교차 검증 기반의 플랫 스케일링(Platt Scaling)을 수행하여 확률값(`predict_proba`)을 제공하지만, 학습 속도가 3~5배 지연됩니다.
* **`decision_function_shape`** (`'ovr'` 또는 `'ovo'`):
  * 다중 클래스 분류 시 One-vs-Rest(일대다) 방식 또는 One-vs-One(일대일) 방식을 선택합니다.

## 🩺 5. 가장 실용적인 모델 건전성 진단법: 서포트 벡터 비율 (SV Ratio)

SVR 모델을 훈련시킨 후, 이 모델이 과적합되었는지 과소적합되었는지 단 1초 만에 파악할 수 있는 가장 신뢰도 높은 엔지니어링 지표는 **서포트 벡터 비율(SV Ratio)**입니다:

$$\text{SV Ratio} = \frac{\text{서포트 벡터 개수 } (N_{SV})}{\text{전체 훈련 데이터 개수 } (N_{total})} \times 100 \ (\%)$$

```
[ SV 비율 진단 스펙트럼 ]
0% ──────────── 10% ────────────────────────── 30% ────────────── 60% ──────────────────────── 90% ──────────── 100%
     과소적합 ⚠️                주의                   적정 골디락스 존 ✅                 주의              과적합 ⚠️
 (데이터 무시, 튜브 과대)                                                                           (노이즈 암기, 튜브 과소)
```

| SV 비율 | 모델 상태 진단 | 물리적 현상 및 원인 | 권장 엔지니어링 조치 |
| :---: | :--- | :--- | :--- |
| **$90 \sim 100\%$** | **극심한 과적합 위험 ⚠️** | 튜브 폭($\epsilon$)이 너무 좁아 거의 모든 점이 튜브 밖으로 이탈함. 미세 측정 노이즈까지 모델이 억지로 따라가느라 곡면이 심하게 요동침. | • $\epsilon$을 대폭 확대<br>• $C$를 축소<br>• $\gamma$를 줄여 완만화 |
| **$30 \sim 60\%$** | **최적 골디락스 영역 ✅** | 적절한 수의 서포트 벡터가 뼈대를 잡고, 노이즈는 튜브 내부로 부드럽게 통과함. 일반화 성능 극대화. | 현 파라미터 조합 유지 및 검증셋 평가 확정 |
| **$5 \sim 10\%$ 미만** | **심각한 과소적합 위험 ⚠️** | 튜브 폭($\epsilon$)이 너무 넓어 데이터가 튜브 벽면에 닿지도 않음. 모델이 데이터의 실질적 패턴을 무시하고 단순 평면을 출력함. | • $\epsilon$을 축소<br>• $C$를 상향<br>• $\gamma$를 적절히 증대 |

## ❄️ 6. 실차 제동 & 스노우 노면 보정 실무 적용 노하우

### 1) 측정 불확도(Measurement Uncertainty, $u_c$)를 $\epsilon$에 연계하는 물리적 기법 💡
일반적인 데이터 과학에서는 $\epsilon$을 무작위 그리드 탐색으로 찾지만, **계측 공학(측정 불확도)을 이해하는 엔지니어는 물리적 사전 지식(Prior)을 직접 주입**할 수 있습니다.

* **핵심 논리**:
  * 실차 제동거리 계측 시스템(VBOX GPS, 휠 속도 센서 등)의 **합성표준불확도가 $\pm 0.5\text{m}$** 수준이라면, $\pm 0.5\text{m}$ 이내의 데이터 변동은 타이어나 차량의 실제 반응이 아니라 **"단순 계측 노이즈"**입니다.
  * 따라서 SVR의 $\epsilon$을 계측 불확도 수준인 **$\epsilon \approx 0.5\text{m}$ (또는 $1\sigma \sim 2\sigma$ 범위)**로 설정하면, 모델은 노이즈 구간 내부의 잔차를 학습하려 들지 않고 0으로 무시합니다.
  * 불확도보다 훨씬 작은 $\epsilon$(예: $0.05\text{m}$)을 주면, 모델은 노이즈를 맞추기 위해 서포트 벡터를 무한정 양산하고 과적합됩니다.
* **SVR만의 독보적 장점**:
  * 랜덤 포레스트나 신경망과 달리, SVR은 **"어디까지가 노이즈이고 어디서부터가 진짜 신호인가"를 $\epsilon$을 통해 수학적으로 명시할 수 있는 유일한 회귀 모델**입니다.

### 2) 외삽 말림(Curling) 현상 규명 및 $\gamma$ 완만화 규제
RBF 커널은 가우시안 수식 특성상, **훈련 데이터가 희소한 외곽 영역(외삽 구간)으로 나가면 지수 감쇠($\exp \to 0$)하여 0으로 수렴**하려는 성질이 있습니다.
* **현상**: 스노우 노면 보정에서 침하 깊이가 $+3.5\text{mm}$ 이상으로 깊어질 때, 제동거리가 계속 증가해야 함에도 불구하고 외곽 등고선이 안쪽으로 둥글게 닫히며 0m로 추락(말림)하는 비물리적 왜곡 발생.
* **해결책**:
  * $\gamma$를 너무 크게 주면($\gamma \ge 0.5$) 데이터가 없는 외곽에서 급격히 말려 들어갑니다.
  * $\gamma$를 **`0.05 ~ 0.07` 수준으로 완만화(Regularization)**하고 $C$를 적정선(`2.0`)으로 제한하면, 외곽 영역에서도 물리 법칙에 부합하는 완만하고 열린 유선형 등고선 곡면이 완벽히 유지됩니다.

### 3) 스케일링(StandardScaler) 필수 원칙
* SVR은 거리 기반($\|x_i - x_j\|^2$) 모델이므로, 변수의 단위(스케일)에 지대한 영향을 받습니다.
* 침하 깊이($0 \sim 10\text{mm}$)와 노면 온도($-10 \sim 5^\circ\text{C}$)의 스케일이 다르면 특정 축으로만 텐트가 찌그러집니다.
* **반드시 `StandardScaler`를 `Pipeline`으로 묶어 훈련과 추론 전 과정에 강제 결합**해야 합니다.

## 💻 7. Scikit-learn 표준 파이프라인 및 그리드 서치 실무 코드

실무 데이터셋에 즉시 적용 가능한 검증 파이프라인 표준 코드입니다.

```python
"""
SVR 최적 하이퍼파라미터 그리드 서치 및 서포트 벡터 무결성 검증 파이프라인
"""
import numpy as np
from sklearn.svm import SVR
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import GridSearchCV, KFold

# 1. 파이프라인 구축 (스케일러 + SVR 결합으로 데이터 누수 차단)
pipe_svr = Pipeline([
    ('scaler', StandardScaler()),
    ('svr', SVR(kernel='rbf'))
])

# 2. 하이퍼파라미터 그리드 정의 (로그 스케일 탐색 권장)
# 실차 계측 불확도가 0.1m 수준일 때의 예시
param_grid = {
    'svr__C':       [0.5, 1.0, 2.0, 5.0, 10.0],
    'svr__gamma':   [0.01, 0.05, 0.07, 0.1, 0.5, 'scale'],
    'svr__epsilon': [0.05, 0.10, 0.20, 0.50]
}

# 3. 5-Fold 교차 검증 그리드 서치 가동
cv_strategy = KFold(n_splits=5, shuffle=True, random_state=42)
grid_search = GridSearchCV(
    estimator=pipe_svr,
    param_grid=param_grid,
    cv=cv_strategy,
    scoring='neg_mean_absolute_error',
    n_jobs=-1,
    return_train_score=True
)

# 4. 모델 피팅
grid_search.fit(X_train, y_train)

# 5. 최적 모델 추출 및 서포트 벡터 건전성 진단
best_model = grid_search.best_estimator_
best_svr = best_model.named_steps['svr']

n_sv = len(best_svr.support_)
total_samples = len(X_train)
sv_ratio = (n_sv / total_samples) * 100.0

print(f"🏆 최적 파라미터 조합: {grid_search.best_params_}")
print(f"🎯 최적 CV MAE: {-grid_search.best_score_:.4f}")
print(f"📊 서포트 벡터 수: {n_sv} / {total_samples} (비율: {sv_ratio:.2f}%)")

# 6. 건전성 룰베이스 판정
if 30.0 <= sv_ratio <= 60.0:
    print("✅ SV 비율이 이상적인 골디락스 영역(30~60%)에 있어 일반화 성능이 매우 뛰어납니다.")
elif sv_ratio > 80.0:
    print("⚠️ 과적합 경고: SV 비율이 너무 높습니다. epsilon을 키우거나 C를 줄이십시오.")
else:
    print("⚠️ 과소적합 경고: SV 비율이 너무 낮습니다. epsilon을 줄이거나 C를 증대하십시오.")
```
