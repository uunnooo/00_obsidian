### 📌 1. 탐색적 데이터 분석 (EDA)의 개념 및 4대 원칙

* 탐색적 데이터 분석 (EDA, Exploratory Data Analysis) 개요통계학자 존 튜키(John Tukey)가 제안한 분석 기법으로, 가설 검정이나 정량적 모델링 이전에 그래프나 요약 통계량을 통해 데이터 원천의 날것 그대로의 특징을 다각도로 파악하고 숨겨진 패턴을 찾아내는 직관적 데이터 탐색 행위입니다.
* 시험 단골 출제! EDA의 4대 구성원칙저항성 (Resistance): 일부 수집 오류나 극단적인 이상치(Outlier)가 존재하더라도 산출된 대푯값이나 통계적 추정치가 심하게 흔들리지 않고 견뎌내는 성질입니다. (예: 극단치에 민감하게 흔들리는 산술평균에 비해, 위치적 대푯값인 중위수(Median)나 사분위값은 저항성이 매우 우수합니다.)
* 잔차 (Residual): 관측값에서 피팅값(정형화된 추세 또는 예측값)을 뺀 편차로, 데이터에 숨겨진 또 다른 비선형 변동성이나 이상 패턴을 주시하기 위한 핵심 분석 도구입니다. (공식: 잔차 = 실제 관측값 - 예측 모델의 추정값)
* 재표현 (Re-expression): 비대칭적인 치우침(왜도)을 줄이고 정규분포 가정을 만족시키기 위해 로그(log), 제곱근(sqrt), 역수(1/x) 등의 수치적 변환을 가하여 변수의 척도(Scale)를 균등하게 재조정하는 기법입니다.
* 시각화 (Visualization): 표 형태의 평평한 텍스트 수치만으로는 직관적으로 식별하기 힘든 데이터의 다차원적 구조, 군집, 밀도, 추세를 한눈에 식별할 수 있도록 그래프와 시각 도구로 변환하여 탐색하는 행위입니다.

### 📌 2. 분포의 비대칭성 측정: 왜도(Skewness)와 첨도(Kurtosis)

* 왜도 (Skewness): 분포의 좌우 비대칭도 측정수리적 정의: 데이터 분포의 비대칭성 정도를 나타내는 통계량으로, 3차 적률을 활용해 산출합니다.
* 텍스트 수식: Skewness = [ sum((x_i - mean)^3) / N ] / s^3 (mean은 산술평균, N은 데이터 수, s는 표준편차)
* 왜도 수치별 형태 판정 기준:Skewness = 0: 분포가 좌우 완벽한 대칭을 이룹니다. (표준정규분포 형태)
* Skewness > 0 (양의 왜도 / 오른쪽으로 긴 꼬리): 분포의 오른쪽 꼬리가 길게 처진 비대칭 형태이며, 수리적 크기는 최빈값 
* Skewness 
* 첨도 (Kurtosis): 분포의 뾰족함과 꼬리의 두터움 측정수리적 정의: 분포의 꼭대기가 얼마나 뾰족한지(중앙 집중도)와 양쪽 끝 꼬리가 얼마나 두터운지(Heavy-tail)를 4차 적률을 통해 정량화하는 지표입니다.
* 텍스트 수식: Kurtosis = [ sum((x_i - mean)^4) / N ] / s^4
* 첨도 수치별 형태 판정 기준:Kurtosis = 3 (또는 초과첨도 Kurtosis - 3 = 0 기준): 표준정규분포의 뾰족함 및 꼬리 두께와 일치합니다. (중첨, Mesokurtic)
* Kurtosis > 3 (또는 초과첨도 > 0): 정규분포보다 중앙 분산이 훨씬 뾰족하게 솟아오르고, 동시에 양쪽 꼬리가 정규분포보다 아주 무겁고 두껍게 쳐지는 형태입니다. (급첨, Leptokurtic)

### 📌 3. 데이터 시각화 기획 프로세스 5단계

* 데이터 시각화의 수명주기 단계별 핵심 태스크1단계: 정보 조직화 (Information Organizing): 복잡한 원천 데이터 속에서 전달하고자 하는 핵심 비즈니스 목적과 가치를 도출하고, 이에 부합하는 유의미한 원천 지표들을 발굴 및 정제하는 기초 설계 단계입니다.
* 2단계: 정보 시각화 (Information Visualizing): 선정된 핵심 지표들의 유형(수치형, 범주형 등)과 데이터 차원 관계에 부합하도록 적합한 비주얼 속성(색상, 형태, 크기, 위치)과 그래픽 요소를 매핑하는 단계입니다.
* 3단계: 정보 구조화 (Information Structuring): 분산된 개별 시각화 도구들을 전체적인 맥락과 스토리라인에 맞추어 하나의 통합 레이아웃(대시보드 또는 인포그래픽)으로 짜임새 있게 배열하고 화면을 정돈하는 단계입니다.
* 4단계: 정보 전송 (Information Transmitting): 구현된 시각화 산출물을 대상 타겟(의사결정권자, 최종 사용자)의 인터페이스 환경(모바일, 웹, 태블로 대시보드 등)에 맞춰 최적화하여 송출하고 피드백을 수용하는 단계입니다.
* 5단계: 정보 정교화 (Information Elaborating): 수용된 사용성 피드백을 기반으로 디자인 노이즈를 걷어내고, 색상 보정 및 상호작용성(인터랙티브 드릴다운 등)을 보완하여 정보 전달력을 극대화하는 최종 고도화 단계입니다.

### 📌 4. 데이터 유형별 시각화 기법 및 특수 그래픽스

* 비즈니스 분석을 위한 데이터 탐색 시각화 도구 유형비교 및 순위 시각화 기법막대 차트(Bar Chart): 범주별 크기를 막대 길이로 나타내며 순위와 격차를 비교할 때 가장 우수한 인지 효과를 보입니다.
* 트리맵(Treemap): 계층적 데이터의 구성 비율을 사각형의 면적과 색상 대비로 정밀 구조화하여 표현하는 기법입니다.
* 시간 흐름 및 추세 시각화 기법선 그래프(Line Chart): 시간의 연속적인 흐름(Time-series)에 따른 데이터 변동 추세와 방향성을 도출하는 데 탁월합니다.
* 영역 차트(Area Chart): 누적된 양적 변화량을 시계열 추세선 아래 영역의 면적으로 강조하여 합산 흐름을 관찰할 때 유용합니다.
* 관계 및 분포 시각화 기법산점도(Scatter Plot): 두 개의 연속형 변수 간의 선형적/비선형적 분포 패턴 및 상관성의 유무를 2차원 평면 위의 점으로 투영하여 탐색합니다.
* 버블 차트(Bubble Chart): 3가지 변수를 동시에 탐색하는 도구로, 산점도의 X, Y 축 값 외에 점의 크기(Radius)를 세 번째 변수로 매핑합니다.
* 히스토그램(Histogram): 연속형 데이터의 특정 구간(Bin)별 분포 및 왜곡도 형태를 한눈에 밀도로 측정하는 면적 차트입니다.
* 상자그림(Box Plot): 데이터의 5수 요약치(Min, Q1, Median, Q3, Max)와 이상치 경계인 IQR(IQR = Q3 - Q1, 하한펜스 = Q1 - 1.5 * IQR, 상한펜스 = Q3 + 1.5 * IQR)을 한 공간에 시각화하여 데이터 정제 기준을 제시하는 강력한 도구입니다.
* 다차원 특수 시각화 기법 (필기 단골 타겟!)체르노프 페이스 (Chernoff Faces): 데이터의 다차원 변수 수치들을 인간의 얼굴 부위(눈의 크기, 코의 길이, 입의 기울기 등)에 1:1로 매핑하여 인간 고유의 인지 직관으로 변동 형태를 구별하도록 돕는 특수 그래픽스입니다.
* 스타 차트 (Star Chart / 방사형 레이더 차트): 중심점으로부터 여러 개의 변수 축을 방사형으로 뻗쳐 각 축 위의 수치를 선으로 연결한 도형으로, 개체 간 다차원 성향(예: 선수 역량 평가 능력치 비교 등)의 일치율을 비교할 때 유용합니다.
* 모자이크 플롯 (Mosaic Plot): 다차원의 다변량 범주형 데이터의 빈도와 복합적인 비율 관계를 격자 모양 사각형들의 가로/세로 분할 면적 대비로 표현하는 지각적인 비주얼 기법입니다.

> [!INFO] **교안 상세 보강 (2. 데이터 탐색 – 데이터 탐색의 기초)**

  * ● 데이터의 문제성을 확인한다. 즉, 데이터의 결측치의 유무, 이상치의 유무 등을 확인하고 추가적으로

  * 거친다).
  * ● 관계성 확인 절차를 가진다. 즉, 개별 데이터 간의 속성 관찰에서 보지 못한 데이터 간의 속성(예,
  * 상관관계 등)을 확인한다.
  * 4) 이상치의 검출
  * ① 개별 데이터 관찰
  * ▶ 데이터 값을 눈으로 살펴보면서 전체적인 추세와 특이사항을 관찰할 수 있다.
  * ▶ 데이터가 많다고 앞부분만 보면 안 되고, 패턴이 뒤에서 나타날 수도 있으므로 뒤 or 무작위로
  * 표본을 추출해서 관찰한다. 단, 이상치는 표본의 크기가 작은 경우 나타나지 않을 수도 있다.

* 4) 이상치의 검출
  * ② 통계값 활용

  * ▶ 데이터의 중심을 알기 위해서는 평균(mean), 중앙값(median), 최빈값(mode)을 사용할 수 있다.

  * ▶ 통계 지표를 이용할 때는 데이터의 특성에 주의해야 한다. 예를 들어, 평균에는 집합 내 모든
  * 데이터 값이 반영되기 때문에, 이상값이 있으면 값이 영향을 받지만, 중앙값에는 가운데 위치한
  * 값 하나가 사용되기 때문에 이상값의 존재에도 대표성이 있는 결과를 얻을 수 있다.
  * ③ 시각화 활용
  * ▶ 시각적인 표현은, 분석에 많은 도움을 준다. 시각화를 통해 주어진 데이터의 개별 속성에 어떤
  * 통계 지표가 적절한지 결정할 수 있다.
  * - 시각화 방법에는 확률밀도함수, 히스토그램, 박스플롯(box plot), 워드 클라우드, 시계열
  * 차트, 지도 등이 있다.

### 1. 공분산 (Covariance)의 정의 및 한계성

두 확률 변수가 함께 변하는 변동 방향성과 선형성의 강도를 정량화하는 기초 지표입니다.

* 공분산 계산 공식 (표본 공분산)Cov(X, Y) = [ sum((x_i - mean_x) * (y_i - mean_y)) ] / (n - 1)
* 두 변수의 편차(측정값에서 평균을 뺀 값)의 곱을 모두 더한 후, 표본 자유도(n - 1)로 나누어 산출합니다.
* 부호에 따른 해석 기준양(+)의 공분산: X가 증가할 때 Y도 함께 증가하는 동일한 방향의 선형 경향을 가집니다.
* 음(-)의 공분산: X가 증가할 때 Y는 감소하는 반대 방향의 선형 경향을 가집니다.
* 0에 가까운 공분산: 두 변수 간에는 아무런 선형적 연관성이 존재하지 않습니다. (단, 비선형 관계는 존재할 수 있음)
* 수학적 한계성공분산은 각 변수의 원래 측정 단위(단위 크기)를 그대로 곱해 사용하므로, 데이터의 크기나 단위에 따라 수치 가 과도하게 변동합니다. (예: 키 단위를 m에서 cm로 바꾸면 공분산 값만 급격히 커짐)
* 따라서 공분산의 절댓값 크기 자체만으로는 두 변수 간의 선형 관계가 '얼마나 강한지'를 객적으로 정량 비교할 수 없습니다. 이 단점을 극복하기 위해 공분산을 표준화한 것이 바로 상관계수입니다.

### 2. 3대 상관계수 비교 매트릭스

공분산을 각 변수의 표준편차로 나누어 측정 단위의 영향을 완벽히 제거한 표준화 지표들입니다.

* 피어슨 선형 상관계수 (Pearson Correlation Coefficient)검정 성격: 모수적 방법 (Parametric Method)
* 데이터 형태: 양적 변수 (연속형 변수 - 등간척도, 비율척도)
* 전제 조건: 선형성(두 변수가 선형 관계여야 함), 정규성(두 변수가 모두 정규분포를 따라야 함) 만족 필수
* 공식: r = Cov(X, Y) / (std_x * std_y) (범위는 무조건 -1 이상 +1 이하)
* 스피어만 순위 상관계수 (Spearman Rank Correlation Coefficient)검정 성격: 비모수적 방법 (Non-parametric Method)
* 데이터 형태: 질적 변수 (서열형/순위 변수 - 서열척도)
* 전제 조건: 정규성 및 선형성 가정이 무너졌을 때 사용하며, 두 변수 간의 '단조 관계(Monotonic Relationship)'만을 평가
* 원리: 실제 데이터 측정값 대신 데이터의 '순위(Rank)'로 변환한 후 피어슨 공식을 대입하여 연산
* 켄달의 타우 (Kendall's Tau)검정 성격: 비모수적 방법 (Non-parametric Method)
* 데이터 형태: 질적 변수 (서열형/순위 변수 - 서열척도)
* 전제 조건: 데이터의 정규성 가정이 무너졌을 때 사용하며, 특히 표본의 크기가 아주 작거나 동일한 순위(동률)가 많을 때 스피어만보다 우수함
* 원리: 모든 데이터 쌍(Pair)에 대해 부호가 일치하는 쌍(Concordant Pair)과 일치하지 않는 쌍(Discordant Pair)의 개수 비율로 계산

### 3. 다차원척도법 (MDS, Multidimensional Scaling)

다차원 공간 상에 존재하는 개체들 간의 유사성/비유사성(거리) 데이터를 기반으로, 정보를 최대한 보존하면서 시각적으로 직관 인지가 가능한 저차원(2차원 또는 3차원) 공간 상에 점으로 배치하는 기하학적 다변량 탐색 기법입니다.

* 스트레스 지표 (Stress Value)의 정의실제 고차원 공간에서의 개체 간 거리와 저차원으로 투영된 평면 공간에서의 거리 간 오차(불일치도)를 정량화한 품질 평가 척도입니다.
* 스트레스 값은 오차율의 성격을 띠므로, 값이 0에 가까울수록(낮을수록) 저차원 시각화 배치가 고차원 원래 정보를 왜곡 없이 완벽하게 복원했다고 해석합니다.
* 스트레스 값에 따른 적합도 공식 판정 가이드라인Stress 
* 0.05 
* 0.10 
* 0.15 
* Stress > 0.20: 수용 불가능 (Unacceptable)

* 02 상관관계분석
  * 1) 변수 간의 상관성 분석
  * ; 두 변수 간에 어떤 선형적 관계를 갖고 있는지를 분석하는 방법이다. 두 변수는 서로 독립적인 관계
  * 이거나 상관된 관계일 수 있으며 이때 두 변수 간의 관계의 강도를 상관관계(correlation)라 한다.
  * ① 단순상관분석(Simple Correlation Analysis) : 단순히 두 개의 변수가 어느 정도 강한 관계에 있는가를
  * 측정한다.
  * ② 다중상관분석(Multiple Correlation Analysis) : 3개 이상의 변수 간의 관계강도를 측정한다.
  * ▶ 편상관 관계 분석(Partial Correlation Analysis) : 다중상관분석에서 다른 변수와의 관계를 고정
  * 하고 두 변수의 관계강도를 측정하는 것을 말한다.
  * 2) 상관분석의 기본가정
  * ① 선형성 : 두 변인 X와 Y의 관계가 직선적인지를 알아보는 것으로 이 가정은 분포를 나타내는 산점도를
  * 통하여 확인할 수 있다.
  * ② 동변량성 : X의 값에 관계없이 Y의 흩어진 정도가 같은 것을 의미한다. 반의어는 이분산성이다.
  * ▶ 산포도가 특정 구간에 상관없이 퍼진 정도가 일정할 때 자료가 동변량성을 띤다고 얘기하며,
  * 반대로 그 정도가 일정하지 않으면 이분산성을 보인다고 말한다.

  * 산점도는 직교 좌표계를 이용해 두 개 변수 간의 관계를 나타내는 방법이며, 산포도는 변량이 흩어져 있는 정도를 하나의 수로 나타낸 값이다.

### 4. 차원 축소의 형제 기술: 주성분분석 (PCA) vs 요인분석 (FA)

다량의 변수 정보를 보존하면서 차원을 효과적으로 축소하는 통계 기법이지만, 수학적 목적과 전제 구조에서 명확한 차이점을 보입니다.

* 주성분분석 (PCA, Principal Component Analysis)수학적 목적: 원래 변수들의 전체 분산(정보)을 최대한 보존하는 최소 개수의 새로운 무상관 선형 조합 변수(주성분)를 도출하는 것입니다.
* 변수 관계: 원래 변수들의 단순 선형 결합으로 주성분이 생성되며, 주성분 간에는 완벽한 직교(독립, 상관관계 0) 관계를 유지합니다.
* 활용 목적: 정보 손실을 최소화하는 차원 축소 자체에 주안점을 두며, 머신러닝 모형의 다중공선성 제거 및 예측 속도 향상을 위한 변수 변환 도구로 애용됩니다.
* 요인분석 (FA, Factor Analysis)수학적 목적: 관측된 변수들 밑에 숨겨져 있어 눈에 직접 보이지 않는 가상의 잠재 요인(Latent Factor)을 규명하고, 변수 간의 복잡한 공분산 구조를 설명하는 것입니다.
* 변수 관계: 잠재적인 공통 요인이 원래 관측 변수들에 영향을 미친다는 인과 구조를 전제하며, 도출된 잠재 요인들 간에는 직교 회전 또는 사각 회전 방식에 따라 상관관계가 존재할 수 있습니다.
* 활용 목적: 정보 축소보다는 변수 뒤에 숨겨진 학술적/비즈니스적 잠재 개념(예: 고객 만족도, 브랜드 선호도 등)의 타당성을 파악하고 요인 구조를 규명하는 데 집중합니다.

> [!INFO] **교안 상세 보강 (2. 데이터 탐색 – 데이터 탐색의 기초)**
* 2) 상관분석의 기본가정
  * ③ 두 변인의 정규 분포성 : 두 변인의 측정치 분포가 모집단에서 모두 정규분포를 이루는 것이다.
  * ④ 무선독립표본 : 모집단에서 표본을 뽑을 때 표본대상이 확률적으로 선정된다는 것이다.
  * 3) 상관분석 방법
  * ① 피어슨 상관계수(Pearson Correlation Coefficient 또는 Pearson's r)
  * ▶ 두 변수 X와Y 간의 선형 상관관계를 계량화한 수치이다.
  * ▶ 피어슨 상관계수는 +1과 -1 사이의 값을 가지며, +1은 완벽한 양의 선형상관관계, 0은 선형 상관
  * 관계없음, -1은 완벽한 음의 선형상관관계를 의미한다.

  * 상관계수 : 두 변량 x, y 사이의 상관관계의 정도를 나타내는 수치
  * 공분산(covariance) : 2개의 확률변수의 선형 관계를 나타내는 값이다

### 2. TF-IDF 단어 가중치 산출 수식 및 의미

단어 빈도-역문서 빈도(TF-IDF)는 단순히 한 문서 내에 자주 등장하는 단어가 아닌, '특정 문서군 전체를 대조했을 때 해당 문서 내에서만 유독 독창적으로 집중되어 나타나는 정보 가치가 높은 단어'에 높은 가중치를 부여하는 통계 기법입니다.

* 핵심 지표 정의단어 빈도 TF(t, d): 특정 문서 d 안에서 해당 단어 t가 등장한 횟수입니다. (단일 문서 내에서 많이 등장할수록 수치가 커짐)
* 역문서 빈도 IDF(t, D): 특정 단어 t가 전체 문서군 D 내에서 얼마나 희소하고 독창적으로 쓰였는지 측정하는 지표입니다.
* 가중치 계산 공식 (표준 및 라플라스 평활화 적용)TF-IDF(t, d, D) = TF(t, d) * IDF(t, D)
* 기본 IDF(t, D) = log10( N / DF(t) ) (N은 전체 문서 수, DF(t)는 단어 t가 등장한 문서의 총 개수)
* 라플라스 평활화(Laplace Smoothing) 적용 IDF 공식 (수험 표준)IDF(t, D) = log10( N / (1 + DF(t)) )
* 수집된 전체 데이터 중 특정 단어가 단 한 번도 등장하지 않았을 경우 분모가 0이 되어 무한대 오류(Division by Zero)가 터지는 데이터 파괴 현상을 원천 방지하기 위해 분모에 가상의 값 1을 더해 연산을 안정화시킵니다.

### 4. SNA 4대 중심성 (Centrality) 비교 수식

네트워크 안에서 특정 개체가 얼마나 영향력이 크고 주도적인 핵심 허브 역할을 하는지 측정하는 4대 통계량입니다.

* 연결 중심성 (Degree Centrality)개념: 한 노드가 네트워크 내부에서 직접적으로 맺고 있는 이웃 노드들의 연결 개수를 측정하는 가장 직관적인 중심성입니다. 마당발 개체를 찾을 때 쓰입니다.
* 계산 공식 (표준화)C_D(i) = d(i) / (n - 1)
* d(i)는 해당 노드 i의 직접 연결선 개수이며, n은 전체 네트워크 노드의 총 개수입니다. 자신을 제외한 최대 연결 수(n - 1)로 나누어 표준화합니다.
* 매개 중심성 (Betweenness Centrality)개념: 한 노드가 네트워크 내의 다른 모든 노드 쌍들 간의 최단 경로(Shortest Path) 위에서 얼마나 자주 길목을 지키고 서 있는지를 정량화합니다. 허브 정보의 '중개자/브로커'를 찾아낼 때 탁월합니다.
* 계산 공식C_B(i) = sum( g_jk(i) / g_jk )
* j와 k 사이의 전체 최단 경로 수(g_jk) 중 해당 노드 i를 강제로 관통해 지나는 최단 경로의 수(g_jk(i))가 차지하는 상대적 비율을 모든 노드 쌍에 대해 누적 합산합니다.
* 근접 중심성 (Closeness Centrality)개념: 한 노드가 네트워크 내부의 다른 모든 노드들에게 얼마나 기하학적으로 신속하게 닿을 수 있는지 최단 거리의 역수로 측정합니다. 소문이나 유행, 정보 전파 속도가 가장 빠른 핵심 인물을 파악할 때 유용합니다.
* 계산 공식 (표준화)C_C(i) = (n - 1) / sum( d_ij )
* sum(d_ij)는 해당 노드 i에서 다른 모든 노드 j까지 이르는 최단 거리들의 단순 총합입니다. 이 거리 합이 작을수록 분모가 작아져 근접 중심성은 극대화됩니다.
* 위세 중심성 (Eigenvector Centrality)개념: 단순히 관계를 맺고 있는 이웃의 개수만 세는 것이 아니라, **'연결된 이웃 노드가 얼마나 네트워크 내에서 권력과 영향력이 높은지'**까지 반영하는 질적 영향력 지표입니다.
* 실무적 적용: 구글(Google)의 심장부 기술이자 웹페이지 간 링크 평판을 측정하는 페이지랭크(PageRank) 알고리즘의 통계학적 근간이 됩니다.

### 1. 시공간 데이터 탐색의 차원적 이해

### 2. 다차원 다변량 고급 그래픽 탐색 도구

* 실무적 효용: 데이터 간의 유사 패턴을 보이는 선들이 특정 구역으로 밀집되는 것을 파악하여 다차원 군집(Cluster)과 숨겨진 다변량 양의 상관/음의 상관관계를 직관적으로 포착하는 데 특화되어 있습니다.
* 스타 차트 (Star Chart / 방사형 레이더 차트)정의 및 원리: 중심점에서 360도 방사형으로 뻗어 나가는 축에 여러 독립 변수의 수치들을 매핑하고 이를 하나의 다각형 면적으로 이어 표현하는 개체별 프로파일링 기구입니다.
* 실무적 효용: 하나의 관측치가 가진 다양한 성능이나 속성의 전반적인 밸런스, 강점과 약점 등 데이터 개체 간의 전반적인 형태 유사성을 비교 분석하는 데 유용합니다.
* 모자이크 플롯 (Mosaic Plot)정의 및 원리: 범주형 다변량 변수들이 주어졌을 때, 각 변수의 범주별 상대적 빈도 크기를 사각형의 가로 너비와 세로 높이 면적으로 분할하여 중첩 표기하는 시각화 기법입니다.
* 실무적 효용: 다변량 분할표의 수치 구조를 단번에 기하학적 면적으로 대조할 수 있어, 범주형 데이터 간의 독립성 여부와 확률 분포 불균형을 신속히 판별합니다.

### 3. 시계열 데이터 탐색 및 4대 변동 요인

* 추세 변동 (Trend, T)특징: 수년간의 아주 장기적인 시야에서 데이터가 지속적이고 일정한 방향으로 우상향(상승)하거나 우하향(하강)하는 연속적인 영구적 성향을 말합니다.
* 순환 변동 (Cycle, C)특징: 고정된 단기 주기가 아닌, 수년(보통 2년~10년) 이상의 장기적인 비주기적 경기 변동, 인플레이션 파동, 거시 경제 침체 등 완만하고 넓은 주기성을 띠고 반복되는 변동성입니다.
* 계절 변동 (Seasonal, S)특징: 1년 이내의 고정된 짧은 주기(예: 봄/여름/가을/겨울 기후 변화, 설날/추석 명절 사회적 관습, 월말 정산 등)에 따라 일정한 진폭으로 정형화되어 매년 반복적으로 출몰하는 강력한 주기성 변동입니다.
* 불규칙 변동 (Irregular, I)특징: 지진, 전쟁, 돌발적인 파업, 대형 사고 등 통제 및 예측이 원천적으로 불가능한 일시적이고 무작위적인 비체계적 충격 잡음(Noise) 성분입니다.

### 4. 시계열 평활화 (Smoothing) 작동 메커니즘

시계열 평활화는 원본 데이터에 존재하는 복잡한 불규칙 무작위 변동(잡음)을 필터링하여 기저에 숨어있는 장기적인 추세나 계절성 성분을 깨끗하게 부각시키는 전처리 및 탐색 분석 기법입니다.

* 이동평균법 (Moving Average, MA)원리: 분석 시점 기준 가장 가까운 과거 n개 구간의 관측값들에 대해 평등한 가중치를 부여하고 단순 산술 평균을 계산하여 순차적으로 한 칸씩 전진 이동하는 방식입니다.
* 계산 공식MA_t = ( Y_t + Y_t-1 + Y_t-2 + ... + Y_t-n+1 ) / n
* Y_t는 t시점의 실제 데이터값이고 n은 지정된 과거 이동평균 구간의 폭입니다.
* 한계성: 모든 과거 관측치를 N분의 1로 똑같이 정량 취급하므로 최근 발생한 중요한 급진적 트렌드 변화를 수식에 민첩하게 투영하지 못하고 뒤늦게 따라가는 시차 지연(Lag) 현상이 필연적으로 유발됩니다.
* 지수평활법 (Exponential Smoothing)원리: 모든 과거의 수집 관측치들을 소멸시키지 않고 전부 누적하여 수식에 보존하되, 최근의 데이터일수록 가장 높은 기하학적 가중치인 지수평활계수(alpha)를 주고 먼 과거로 갈수록 가중치를 지수곱 단위로 매우 빠르게 감소시켜 완충 예측하는 스마트 기법입니다.
* 계산 공식F_t+1 = alpha * Y_t + (1 - alpha) * F_t
* F_t+1은 차기 평활 예측치이며, Y_t는 현재 시점의 실제 관측치, F_t는 현재 시점의 평활 예측값입니다.
* 평활계수(alpha)의 영향력 원리alpha 가 1에 수렴할수록: 최근의 변화 상황을 극도로 신속하고 거칠게 수용합니다. (Y_t의 가중치가 높아져 파동의 진폭이 크고 예민하게 움직임)
* alpha 가 0에 수렴할수록: 최근의 변동을 노이즈로 취급하여 과거 추정 파형(F_t)에 전적으로 의존합니다. (파형이 극도로 단조롭고 완만하며 직선에 가까운 형태로 평활화됨)

### 1. [2-2-1] 탐색적 데이터 분석(EDA) 및 분포 통계량 코어 요약

* EDA 4대 구성원칙:저항성 (Resistance): 데이터셋에 소수의 이상치(Outlier)나 극단값이 존재하더라도 통계적 대푯값이 과도하게 흔들리지 않고 견고하게 버텨내는 성질입니다. (평균은 저항성이 매우 낮고, 중위수는 저항성이 극도로 높음)
* 잔차 (Residual): 실제 관측값에서 분석 모델이 설명하는 적합값(경향성)을 뺀 편차(잔차 = 실제값 - 적합값)를 구하여, 데이터에 숨어있는 주류 패턴을 제외한 국소적 변동과 특이점을 정밀 추적합니다.

### 2. [2-2-2] 상관분석 및 다변량 분석 코어 요약

* 공분산 (Covariance)의 치명적 한계:한계: 두 변수 간의 선형적 방향성(양의 비례, 음의 반비례)은 기하학적으로 규명하지만, 각 변수의 측정 단위를 그대로 곱하기 때문에 공분산 수치 크기만으로는 연관성의 실제 강도(세기)를 정량 대조할 수 없습니다. (단위 정규화 필요성 유발)
* 3대 상관계수 전제 및 산출 공식:피어슨 선형상관계수 (r): 두 변수가 모두 연속형 등간/비율 척도이며 정규성 가정을 완벽히 충족할 때 사용합니다. 수식은 r = Cov(X,Y) / (표준편차_X * 표준편차_Y) 로 정의되며 선형적 관계 강도를 측정합니다.
* 스피어만 순위상관계수 (rho): 데이터가 서열/순위 척도이거나 정규성 가정이 완전히 무너진 극단적인 비선형 단조 증가/감소 관계일 때 사용합니다. 수식은 rho = 1 - ( 6 * sum(d_i^2) ) / ( n * (n^2 - 1) ) 로 산정됩니다.
* 켄달의 타우 (tau): 모든 관측치 쌍 간의 부합(Concordant)하는 쌍의 개수와 비부합(Discordant)하는 쌍의 개수의 상대적 비율을 계산하여 연계 강도를 측정하며, 극단적인 이상치에 대한 저항성이 가장 뛰어납니다.
* 다차원척도법 (MDS) 품질 평가지표 (Stress):실제 고차원 거리와 저차원 투영 공간의 기하학적 거리 오차 불일치를 나타내며, 낮을수록 우수한 품질을 증명합니다.

* 변수 축소 형제 기술 비교 (PCA vs FA):주성분분석 (PCA): 데이터 전체의 고유한 총분산(Variance)을 최대로 보존하는 선형 조합 축(주성분)을 찾으며, 변수 개수 자체를 압축하여 다중공선성을 제거하는 데 목적이 있습니다. (공통요인 개념 없음)
* 요인분석 (FA): 변수 이면에 숨어있는 가상의 잠재적 공통 요인(Common Factor)을 발굴하기 위해 오직 '공통 분산'만을 활용하며, 변수 뒤의 근본적인 학술적 개념을 명명하고 설명하는 데 목적이 있습니다.

* 근접 중심성 (Closeness): 한 노드에서 다른 모든 노드까지 도달하는 데 걸리는 최단 경로 거리들의 합의 역수입니다. 수식은 Closeness_i = 1 / sum( d(i,j) ) 로 정의됩니다.
* 매개 중심성 (Betweenness): 네트워크 내부의 모든 노드 쌍 간의 최단 경로들 중, 해당 노드가 중간에서 징검다리 통제 역할을 대리 수행하는 비율입니다. 수식은 Betweenness_i = sum( g_jk(i) / g_jk ) 로 구성됩니다.
* 위세 중심성 (Eigenvector): 단순히 연결이 많음을 넘어, 영향력이 강하고 힘이 있는 인싸 노드들과 밀접하게 연결되어 있는지를 측정하는 기하학적 중심성입니다.

### Q7. 라플라스 평활화(Laplace Smoothing)를 적용하여 통계적 단어 가중치인 TF-IDF를 정교하게 연산하고자 한다. 아래 조건에 따를 때 최종 도출되는 TF-IDF(t,d,D)의 기댓값으로 가장 적절한 것은?

```text
[ 입력 매개변수 조건 ]
- 단어 빈도 TF(t,d) = 10
- 분석 대상 전체 문서 집합의 수 N = 1000
- 해당 단어가 등장한 문서의 개수 DF(t) = 99
```

① 1.0② 10.0③ 20.0④ 30.0

* ▶ 클릭하여 정답 및 해설 확인정답: ②
* 정답 공식 해설:라플라스 평활화를 적용한 통계적 TF-IDF 산출 수식은 다음과 같이 정의됩니다.
* TF-IDF(t,d,D) = TF(t,d) * log10( N / (1 + DF(t)) )
* 문제에서 주어진 각 변수의 세부 입력 수치는 다음과 같습니다.
* 단어 빈도 TF(t,d) = 10, 전체 문서 수 N = 1000, 단어 등장 문서 수 DF(t) = 99
* 수식에 값을 매핑하여 산출하는 정밀 과정은 다음과 같습니다.
* IDF(t,D) = log10( 1000 / (1 + 99) ) = log10( 1000 / 100 ) = log10(10) = 1
* TF-IDF = 10 * 1 = 10
* 따라서 최종 연산된 기댓값은 10이 되므로 정답은 ②번입니다.
* 오답 분석:① TF-IDF = 1.0 은 IDF 값만 구했을 때의 결과입니다.
* ③ TF-IDF = 20.0 은 분모 평활화 항 1을 더하지 않고 계산한 오류 수치입니다.
* ④ TF-IDF = 30.0 은 로그 밑을 e로 오인했거나 연산이 잘못된 오답입니다.

### Q8. 사회네트워크분석(SNA)의 주요 중심성(Centrality) 지표에 대한 설명 중 가장 적절하지 않은 것은?

* ▶ 클릭하여 정답 및 해설 확인정답: ③

### Q10. 지수평활법(Exponential Smoothing) 시계열 분석 기법을 이용하여 다음 달 판매 수요를 예측하고자 한다. 지수평활계수(평활상수) alpha = 0.3으로 설정하고 아래 조건을 만족할 때, 최종 도출되는 다음 달 수요 예측치 F_t+1 값으로 가장 옳은 것은?

```text
[ 시계열 변동성 데이터 조건 ]
- 이번 달의 실제 수요 실적값 (Y_t) = 120
- 이번 달에 사전에 추정했던 예측치 (F_t) = 100
```

① 100② 106③ 114④ 120

* ▶ 클릭하여 정답 및 해설 확인정답: ②
* 정답 공식 해설:지수평활법을 이용한 예측치 산출 수식은 최근 실제값에 가중치 alpha를 부여하고, 과거 예측치에 1 - alpha 가중치를 부여하는 누적 지수곱 계산식으로 다음과 같습니다.
* F_t+1 = alpha * Y_t + (1 - alpha) * F_t
* 수식에 주어진 입력 조건을 그대로 매핑하여 대입합니다.
* F_t+1 = 0.3 * 120 + (1 - 0.3) * 100
* F_t+1 = 36 + 0.7 * 100
* F_t+1 = 36 + 70 = 106
* 따라서 연산 결과 기댓값은 106이 되므로 정답은 ②번입니다.
* 오답 분석:① 100은 이번 달 예측 가중치만 반영한 잘못된 고정값입니다.
* ③ 114는 평활계수 가중치를 정반대로 매핑하여 연산했을 때의 오답입니다. (120 * 0.7 + 100 * 0.3 = 114)
* ④ 120은 실제 관측치만 그대로 다음 달로 예측한 단순 단순이동평균(시차 1) 오답입니다.
