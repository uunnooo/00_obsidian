## 1. 결측값(Missing Value)의 통계적 본질과 분류 체계

데이터 분석 및 머신러닝 알고리즘 모델링 과정에서 결측치(Missing Value)는 알고리즘의 비정상적 구동 중단, 편향(Bias)된 가설 검정 결과 유출, 모델 설명력 저하 등의 치명적인 문제를 일으킵니다. 따라서 무작위로 관측되지 않은 데이터값들의 기저 메커니즘을 밝혀내어 알맞게 통제해야 합니다.

### 1. 결측값 메커니즘 3대 분류 (Missingness Mechanisms)

도널드 루빈(Donald Rubin)의 통계적 정의에 따라 결측치는 관측 데이터(Yobs)와 결측 데이터(Ymiss), 그리고 결측 사건의 발생 여부를 지시하는 관측 여부 변수(M) 사이의 조건부 확률 분포 관계를 기준으로 다음 3가지 메커니즘으로 엄격히 분류됩니다.

* ```text
[ 결측 데이터 발생 메커니즘 ]

     완전무작위결측 (MCAR)            무작위결측 (MAR)             비무작위결측 (NMAR)
    ┌─────────────────────┐       ┌─────────────────────┐       ┌─────────────────────┐
    │ 결측 원인이 완전히  │       │ 결측 원인이 관측된  │       │ 결측 원인이 결측된  │
    │  무작위로 발생함    │       │ 타 변수에 의해 규명 │       │  자기 자신에 있음   │
    │ P(M|Y_obs, Y_miss)  │       │ P(M|Y_obs, Y_miss)  │       │ P(M|Y_obs, Y_miss)  │
    │     = P(M)          │       │     = P(M|Y_obs)    │       │   ≠ P(M|Y_obs)      │
    └─────────────────────┘       └─────────────────────┘       └─────────────────────┘
```

① 완전무작위결측 (MCAR: Missing Completely At Random)정의: 어떤 데이터의 결측 여부가 이미 관측된 다른 변수들의 값뿐만 아니라 자기 자신의 실제 미관측 값과도 아무런 상관관계가 없는 완전히 독립적인 상태입니다.
* 수학적 정의:P(M∣Yobs,Ymiss)=P(M)
* 대표 예시: 설문지 인쇄 오류로 인해 일부 문항이 유실되어 무작위로 응답자가 답변하지 못한 경우, 장비 오류로 무작위 센서 패킷 누락이 발생한 경우.
* 통계적 함의: 표본 손실로 인해 분산이 소폭 증가하는 '효율성 상실'만 발생하며, 관측 완료된 케이스만으로 통계적 가설 검정을 수행하더라도 편향(Bias)이 생성되지 않는 안전한 결측 형태입니다.② 무작위결측 (MAR: Missing At Random)
* 정의: 특정 데이터가 누락될 확률이 결측된 값 자체(Ymiss)와는 상관이 없으나, 데이터베이스 내에 기록 및 관측이 완료된 다른 특정 변수(Yobs)의 값에 의해서는 완벽하게 설명 및 조건화되는 상태입니다.
* 수학적 정의:P(M∣Yobs,Ymiss)=P(M∣Yobs)
* 대표 예시: 직장 여성의 소득 수준 데이터 수집 시, 무응답(결측)을 한 사람의 실제 소득 금액 자체에 기인한 무응답이 아니라 설문 대상의 '성별(여성)'과 '직업군'이라는 이미 관측된 기재 변수에 의해 결측 발생 비율이 편향된 현상.
* 통계적 함의: 다중 대치법이나 조건부 평균 보정 등 적절한 통계적 통제 기법을 가할 경우, 편향되지 않는 모수 추정값을 안정적으로 복원할 수 있습니다.③ 비무작위결측 (NMAR / MNAR: Not Missing At Random)
* 정의: 누락 데이터가 발생할 확률이 누락된 실제 미관측 값 자체(Ymiss)에 직접적으로 지배당하는 형태입니다. 이미 수집되어 확보된 타 변수를 이용하더라도 결측의 불확실성을 완벽히 조건화하거나 보정하기 불가능한 위험한 결측 상태입니다.
* 수학적 정의:P(M∣Yobs,Ymiss)=P(M∣Yobs)
* 대표 예시: 고소득 자산가가 세금 부담 우려로 자신의 소득 항목을 누락하거나, 몸무게가 극도로 많이 나가는 환자가 체중 설문조사 칸을 무응답으로 비워둔 경우.
* 통계적 함의: 단순 제거(Listwise Deletion)를 가해 모델을 수립하면 표본 선택 편향(Selection Bias)이 심각해지며 예측 모형의 정확성이 무너집니다. 이를 보정하기 위해서는 Heckman 2단계 선택 모형 등 별도의 결측 발생 확률 결합 방정식 모델이 추가되어야 합니다.

## 2. 결측값 처리 및 대치 기법 (Imputation Methods)

결측치가 판명되었을 때 사용 가능한 주요 처리 접근법은 삭제와 특정 값을 집어넣어 채워 넣는 대치 기법으로 구별됩니다.

### 1. 단순 제거법 (Deletion)

* 목록 삭제 (Listwise Deletion): 단 하나의 결측값이라도 보유한 관측치 레코드(Row) 자체를 통째로 폐기하는 기법입니다. 데이터가 MCAR(완전무작위결측)일 때만 모수의 불편추정량이 유지되며, MAR이나 NMAR 상황에서는 관측치가 줄면서 과도한 편향이 발생하고 귀중한 정보를 대량 소실시킵니다.
* 쌍별 삭제 (Pairwise Deletion): 공분산 및 상관분석 시, 관련 타겟 연산에 직접 참여하는 두 개의 변수 쌍 중에서 한쪽에 결측치가 있는 경우에만 해당 연산 쌍에서 제한적으로 생략하는 방식입니다. 분석 시마다 총 표본 크기(N)가 유동적으로 변하여 통계적 일관성을 확보하기 어렵다는 단점이 있습니다.

### 2. 단일 대치법 (Single Imputation)

결측값의 불확실성을 고려하지 않고 오직 단 하나의 추정 및 계산값으로 모든 결측 셀을 영구 대체하는 보수적 통제 방법입니다.

```text
[ 단일 대치법의 방법론 및 한계점 ]

  대표값 대치 (평균/중앙치)            회귀분석 기반 대치              단일 대치법의 한계
 ┌────────────────────────┐      ┌────────────────────────┐      ┌────────────────────────┐
 │ 결측값을 한 변수의     │      │ 타 독립변수를 투입해   │      │ 인위적인 추정값 주입   │
 │ 전체 대표 평균값으로   │ ───> │ 결측값을 조건부 평균   │ ───> │ 으로 인해 잔차 왜곡 및 │
 │ 기계적으로 채워 넣음   │      │ 예측값으로 정밀 적재   │      │ 통계적 분산 과소추정   │
 └────────────────────────┘      └────────────────────────┘      └────────────────────────┘
```

* 평균 대치법 (Mean Imputation): 관측 완료 데이터의 표본 평균(Xˉ)이나 중앙치로 대체하는 방법입니다. 데이터의 표준편차를 무리하게 감소시키고, 평균 주변에만 빈도가 기형적으로 뭉치게 하여 변수 간의 선형 상관관계를 크게 왜곡하고 제1종 오류 발생 확률을 왜곡합니다.
* 회귀 대치법 (Regression Imputation): 결측치가 존재하지 않는 독립 변수들을 토대로 회귀 모형을 적재하여 유도된 종속 변수의 예측값으로 채워 넣는 정밀 대치 기법입니다. 그러나 오차(Error Term)의 무작위 변동이 모두 소거된 완벽한 선형 평면 위에 대치값들이 고정되므로, 분석가가 의도하지 않은 데이터 분산 과소추정 문제가 아주 강력하게 잔존하게 됩니다.

### 3. 다중 대치법 (MICE: Multivariate Imputation by Chained Equations)

단일 대치의 수학적 분산 축소 오류를 원천 차단하기 위해 수립된 현시대의 표준 대치 프레임워크입니다. 불확실성 마진을 대치값 자체에 주입하여 통계 분석 결과의 일관성을 완벽히 획득합니다. MICE는 다음의 정밀 **3단계 라이프사이클**을 반복 순환합니다.

```text
[ MICE 다중 대치 3단계 프로세스 ]

     1단계: 대치 (Imputation)            2단계: 분석 (Analysis)             3단계: 결합 (Pooling)
    ┌───────────────────────┐         ┌───────────────────────┐        ┌───────────────────────┐
    │  확률분포 기반 다중   │         │  각 대치 데이터셋을   │        │ 루빈의 공식(Rubin's   │
    │  임의 시뮬레이션을    │ ──────> │  기반으로 독립적인    │ ─────> │ Rule)에 의해 가중치를 │
    │  거친 M개 데이터 생성 │         │  통계량/회귀분석 수행 │        │ 부여하여 단일결과통합 │
    └───────────────────────┘         └───────────────────────┘        └───────────────────────┘
```

① 1단계: 대치 단계 (Imputation Stage)

결측값의 예측 분포(Predictive Distribution)에서 무작위 추출 기법을 적용하여 서로 다른 M개의 임의 대치 데이터 세트(보통 M=5∼10)를 생성합니다. 이때 회귀 방정식에 무작위 오차 변동을 직접 계산하여 삽입하므로 각 가상의 판넬 데이터 세트들은 매 대치 시마다 서로 다른 합리적 모수 추정값을 지니게 됩니다.

② 2단계: 분석 단계 (Analysis Stage)

도출된 M개의 가상 정합 데이터 세트 각각에 고유하게 적용하고자 했던 타겟 통계 모델(예: 다중 회귀분석, 생존분석 등)을 독립적이고 동시다발적으로 실행하여 변수별 모수 값 및 표준 오차(Standard Error) 벡터를 별개로 산출합니다.

③ 3단계: 결합 단계 (Pooling Stage)

산출된 M개의 서로 다른 통계 모델 결과물들을 루빈의 결합 공식(Rubin's Rules)을 적용해 하나의 최종적인 종합 분석 결과로 병합 통제합니다.

* 원리: 대치 데이터셋 내에서 구한 모수의 변동인 **'집단 내 분산(Within-Imputation Variance)'**과 대치 데이터셋 간에 나타난 결측치 대치값 자체의 변동성인 **'집단 간 분산(Between-Imputation Variance)'**을 통계학적으로 정확히 합산하여 보정하는 메커니즘을 가집니다. 이를 통해 과대평가되지 않은 무결한 신뢰구간(Confidence Interval) 범위와 p-value를 영위할 수 있게 됩니다.

  * ; 데이터 정제는 데이터를 깨끗하게 다듬어서 데이터의 신뢰도를 높이는 작업이라고 할 수 있다.

  * ① 데이터 오류 원인
  * ㉮ 결측값(Missing Value) : 필수 데이터가 입력되지 않고 누락된 값(NA(Not Available), 999999,
  * Null)
  * ㉯ 노이즈(Noise) : 실제로 입력되지 않았으나 입력되었다고 잘못 판단된 값
  * ㉰ 이상값(Outlier) : 데이터 범위에서 많이 벗어난 매우 크거나 작은 값

* 2) 데이터 정제(Data Cleansing)
  * ② 데이터 정제 방법 결정 : 삭제, 대체(최빈값, 중앙값, 평균값 활용), 예측값 삽입

## 3. 이상값(Outlier)의 수학적 경계와 탐지 기술

이상값(Outlier)은 대다수의 다른 관측치 범위에서 비정상적으로 동떨어진 패턴을 띠며, 수집 과정의 기계적 오작동(Sensor Noise), 단순 기입 휴먼 에러, 혹은 기존 시스템의 구조가 완전히 뒤바뀐 현실 세계의 희귀한 이상 금융거래 범죄 및 긴급 위기 상황(Fraud / Failure)을 내포합니다.

### 1. IQR (Interquartile Range) 기반 탐지 기술 (사분위수 분포)

상자-수염 그림(Box-and-Whisker Plot)의 기본 수학적 척도가 되는 강건한(Robust) 탐지 공식입니다. 데이터 분포의 중심 위치 척도인 사분위수(Quartile) 분포 간격을 활용하여 수학적 이상치 차단선(Fences)을 확정합니다.

```text
[ IQR 기반 이상치 판정 경계 구조 ]

            최솟값 하한선                                       최댓값 상한선
  
                 ▲             Q1 중앙값 Q3             ▲
                 │              (Median)                │
          Q1 - 1.5 * IQR                                 Q3 + 1.5 * IQR

  * 단, IQR = Q3 - Q1 (중위 50%의 변동 범위)
```

① 사분위 기준값 정의
* Q1 (제1사분위수): 데이터를 정렬했을 때 아래로부터 25% 지점의 값.
* Q2 (제2사분위수): 50% 지점의 중앙치값(Median).
* Q3 (제3사분위수): 아래로부터 75% 지점의 값.
* IQR (사분위범위): 중간 50% 데이터가 분산된 폭.IQR=Q3−Q1② 이상치 임계 차단선 공식 (Tukey's Fences)
* 정상 범위 하한선:Lower Limit=Q1−1.5×IQR
* 정상 범위 상한선:Upper Limit=Q3+1.5×IQR
* 판정: 관측치 X가 상기 수식에 의해 결정된 [Lower Limit,Upper Limit] 구간을 침범하거나 벗어나는 경우, 수학적인 이상값으로 최종 제명 처리합니다.
* 1.5배수의 수학적 당위성: 만약 특정 변수가 완벽한 정규분포 N(μ,σ2)를 따를 때, Q1과 Q3는 기하학적으로 평균으로부터 대략 ±0.675σ 지점에 포진합니다. 이때 IQR≈1.349σ가 됩니다. 이를 토대로 상한선인 Q3+1.5×IQR 공식을 풀면:0.675σ+1.5×(1.349σ)≈2.698σ즉, 수학적으로 약 ±2.7σ 이탈 경계를 설정하는 효과를 낳으며, 이는 데이터가 정상 정규분포 영역에 있을 때 양방향 꼬리 부근의 약 0.7% 확률에 걸치는 적합한 통계적 경계로 환산됩니다.

### 2. Z-Score (표준 점수) 기반 탐지 기술

데이터가 대칭을 이루며 중심에 집중되는 완벽한 모수 정규분포 성질을 가질 때 적용하는 강력한 표준 편차 환산 공식입니다.

① 수식 정의

관측치 X가 가질 수 있는 편차를 표준편차 단위 점수인 Z로 정규 맵핑합니다.

Z=σX−μ

* μ: 변수의 모집단 평균 (또는 표본 평균 Xˉ)
* σ: 모집단 표준편차 (또는 표본 표준편차 s)② 판정 매커니즘
* 일반적으로 실무 모델 구축 시 ∣Z∣>3 (표준편차 배수 3배 이상 이탈) 조건 또는 더욱 완화된 조건인 ∣Z∣>2.5 범위를 타격하는 포인트들을 이상치로 정량 수용합니다.
* 정규분포 하에서 통계적 관측치가 [−3,+3] 범위를 일탈할 누적 기하학적 확률적 한계 수치는 단 $0.27%$에 불과하므로 대단히 효과적인 방법론입니다.③ 통계적 한계점: 가면 효과와 늪 효과
* 가면 효과 (Masking Effect): 소수의 거대한 극단적 이상치가 여러 개 합쳐지면 표본 평균(Xˉ)을 강하게 끌어올리고 표본 표준편차(s)를 과도하게 부풀리는 현상을 낳습니다. 결국 실제 이상치임에도 불구하고 자신의 Z-Score 값이 임계값인 3보다 한참 낮아져 이상치 탐지망에서 "가면을 쓴 듯" 무사 통과하는 오류를 유발합니다.
* 늪 효과 (Swamping Effect): 특정 극단치들이 분산을 인위적으로 너무 크게 조장하여, 본래 정상 범주에 안전하게 있어야 할 무해한 일반 관측값들마저 덩달아 이상치 탐지 임계값을 넘어가며 "늪에 빠지듯" 대량으로 허위 탐지되는 심각한 오류입니다.
* 대안 기술: 위와 같은 왜곡을 방지하기 위해 평균 대신 중위수(Median)를 사용하고, 표준편차 대신 중위수 절대편차인 MAD(Median Absolute Deviation) 지표를 사용하여 강건하게 표준화 점수를 유도하는 Modified Z-Score 기법을 탑재해야 안전합니다.Modified Z=MAD0.6745×(X−X~)MAD=Median(∣Xi−X~∣)(단, X~는 중위수)

## 4. 기계학습(ML) 기반 다차원 이상치 탐지 및 고립 아키텍처

단일 변수 수준을 뛰어넘어 수십 개 변수가 고차원 공간 상에서 유기적으로 작동하는 경우, 시각화나 단일 변수 IQR 공식으로는 이상값 판단이 불가능합니다. 이를 극복하기 위해 아래와 같은 다차원 공간 제어 기계학습 모델을 기획 단계에서 적용합니다.

### 1. DBSCAN (밀도 기반 공간 군집 및 노이즈 고립 기술)

밀도(Density) 개념을 공간 거리에 도입하여 군집을 이루지 못하고 밀도가 아주 낮은 고립된 외딴 공간에 외롭게 동떨어진 무리를 '노이즈(Noise = 이상치)'로 낙인시키는 비지도 학습 모델입니다.

```text
[ DBSCAN 핵심 구성요소 및 노이즈 판정 ]

                    Eps 반경
                    ┌─────┐
                    │  ●  │ ① 작동 지배 파라미터 2선
* Eps (Epsilon): 한 중심점에서 밀도를 측정할 탐색 반경 거리 기준입니다.
* MinPts (Minimum Points): 설정된 Epsilon 반경 내에 정상 이웃으로 수용하기 위한 최소 관측치 개수의 하한 임계치입니다.② 공간 상의 핵심 노드 유형 3선
* 핵심 포인트 (Core Point): 자신의 Eps 이웃 내에 랭크된 관측치 개수가 설정된 MinPts 기준선 이상인 고밀도 앵커 포인트입니다.
* 경계 포인트 (Border Point): 자신의 Eps 이웃 개수는 MinPts에 한참 못 미쳐 밀도는 낮으나, 어떤 핵심 포인트(Core Point)의 Eps 범위 내에 끝자락이 접촉되어 군집의 테두리를 이루는 데이터입니다.
* 노이즈 포인트 (Noise Point = 이상값): 핵심 포인트도 아니고, 어떤 군집의 경계 포인트에도 안착하지 못하며 밀도가 극도로 전무한 우주 공간에 홀로 방치된 완전히 격리된 관측치입니다. 이 노이즈 포인트들이 완벽한 수학적 다차원 이상치로 정의됩니다.

### 2. Isolation Forest (의사결정 의사 난수 분할 고립 기술)

데이터를 무리 짓는 군집 방식이 아닌, 반대로 **"정상 데이터와 이상데이터의 가장 큰 본질적 차이는 이상 데이터가 가혹하게 고립시키기 쉬운 존재"**라는 고유의 성질적 패러다임을 의사결정 나무(Decision Tree)의 깊이(Path Length) 분할 속도로 규명해 내는 최고 고속의 비지도형 알고리즘입니다.

```text
[ Isolation Forest 차원 고립 메커니즘 ]

        정상 데이터 분할 트리 (밀집 영역)             이상 데이터 분할 트리 (외딴 영역)

                  [ Root ]                                   [ Root ]
                 /                                         /        \
              [L1]        [R1]                            [L1]      (Outlier 고립!)
             /          /                              /    \
           [L2]   [L3] [R2]   [R3]                     [L2]   [L3]   * 탐색 깊이가 극도로 얕음
          /                                           /  \
         [ * ] [ * ]                                  [ * ] [ * ]    * 탐색 깊이가 매우 깊음
```

① 고립화 원리
* 전체 다차원 변수 공간에서 무작위로 축(Feature)을 전격 선정하고, 임의의 무작위 분할 축 값(Split Value)을 뽑아 마치 의사결정나무 모델을 만들듯 이진 공간 격자 분할을 반복 실행합니다.
* 밀도가 극도로 밀집된 정상 데이터 군집들은 서로 촘촘하게 엮여 있어서 무작위 공간 분할을 수십 번 이상 가해야 비로소 단 1개의 고유 노드로 각각 고립(Isolation) 분리됩니다. 즉, 정상 데이터의 리프 노드까지의 평균 경로 깊이(Average Path Length)는 극도로 길게 축적됩니다.
* 반면 공간 상의 저밀도 영역에 홀로 고립된 이상치(Outlier)는 단 몇 번의 성성한 무작위 직선 분할만을 거치더라도 순식간에 독립 노드로 고립됩니다. 따라서 리프 노드에 도달하기 위한 평균 경로 깊이가 매우 짧게 유도됩니다.② 고립 지수 산출 수식 (Anomaly Score)

크기 n인 표본 내 데이터 x에 대하여 경로 심도 고립 지수 s(x,n)은 다음 수식에 의해 결정됩니다.

s(x,n)=2−c(n)E(h(x))

* h(x): 격자 트리를 무작위로 반복 구성했을 때 샘플 x가 리프 노드에 도달하여 고립될 때까지 걸린 실제 경로 가중 깊이(Path Length)입니다. E(h(x))는 이에 따른 기댓값입니다.
* c(n): 트리 개수 n 조건하에서 이진 탐색 트리(Binary Search Tree)가 구축할 수 있는 무작위 평균 경로 길이를 보정하는 정규화 상수 함수 식입니다.c(n)=2ln(n−1)+0.5772156649(오일러상수)−n2(n−1)
* 점수 해석 판정 가이드:s(x,n)→1 (가깝게 수렴): 평균 분할 깊이가 0에 가까울 정도로 급격하게 고립된 경우이며, 데이터 x가 완벽한 이상치(Outlier)임을 강력하게 대변합니다.
* s(x,n)→0 (0.5 미만 수렴): 고립시키기 위해 수많은 분할 연산이 요구되었음을 의미하며, 데이터가 밀도 높은 공간 내부에 겹쳐서 기거하는 안전한 정상 관측치 영역임을 완벽 보증합니다.

### 3. 이상값의 실무적 수용 및 최종 처리 전략

이상값이 검출되었을 때 데이터 과학자가 프로젝트 기획 단계에서 적용할 수 있는 조치 전략은 아래와 같습니다.

* 단순 행 삭제 (Deletion): 이상치가 측정 오류나 전산 시스템 에러로 밝혀졌을 때 적용하며, 데이터 누수가 크게 없을 때 유효합니다.
* 대체 조치 (Imputation): 이상치를 정상 범위의 최상단 하한선값인 Q3+1.5×IQR 혹은 최대 정상 표준 수치 범위의 최댓값(Cap/Floor)으로 극값 대체(Capping / Winsorizing) 처리하여 모델의 붕괴를 예방합니다.
* 데이터 스케일 멱변환 (Transformation): 로그(log)나 박스콕스(Box-Cox) 변환을 적용하여 치우쳐진 기형적 꼬리 분포의 데이터 밀도를 중앙으로 수축시켜, 모델 피팅 과정에서 지나치게 왜곡된 이상치 가중치 전가를 완화시킵니다.
* 클래스 분리 모델링 (Segmentation): 이상데이터의 비율이 꽤 크며, 그 특성 자체가 사기 거래나 해킹 침입처럼 중요한 의미를 내포하고 있다면 정상 모델과 이상 모델로 데이터 셋을 아예 파티셔닝하여 2원화 모델링 기획을 수행하는 것이 장기적으로 가장 완벽합니다.

## 1. 데이터 스케일링 (Data Scaling) 및 피처 엔지니어링

대부분의 기계학습 모델은 입력 데이터가 가지는 단위(Unit)와 변동 범위(Scale)에 따라 가중치 가중 전가 및 거리 연산 과정에서 엄청난 왜곡을 겪습니다. 데이터 스케일링은 다차원 공간 상에 펼쳐진 각 축(Feature)의 범위를 일정한 수치 영역으로 정렬하여 분석의 신뢰성을 보장하는 통계적 보정 기법입니다.

### 1. 스케일링의 근본적 당위성 (Why Scaling?)

* 거리 기반 알고리즘의 왜곡 방지: K-NN(최근접 이웃), SVM(서포트 벡터 머신), K-Means(K-평균 군집)와 같이 데이터 포인트 간의 기하학적 거리(유클리드 거리 등)를 기반으로 하는 알고리즘들은 단위가 큰 변수에 의해 거리 연산이 전적으로 지배당하는 문제를 겪습니다.
* 경사하강법(Gradient Descent) 수렴 속도 최적화: 인공신경망(ANN)이나 선형/로지스틱 회귀처럼 가중치를 실시간 업데이트하는 최적화 모델에서 스케일링이 누락되면 타원형의 길쭉한 오차 등고선(Valley)을 돌며 수렴 속도가 현저히 느려지거나 무한 진동(Overshooting)에 빠집니다. 스케일링을 거치면 등고선이 진원에 가까운 형태가 되어 최소 오차 지점까지 최단 거리로 수렴합니다.

## 3. 주성분 분석 (PCA: Principal Component Analysis)

차원 축소(Dimension Reduction)는 데이터 내의 다차원 변수 속성에 포함된 노이즈 및 다중공선성을 제거하여 분석 복잡도를 대폭 낮추고 가독성을 올립니다. 이 중 **주성분 분석(PCA)**은 대표적인 **선형 차원 축소 및 비지도 학습** 기법입니다.

### 1. PCA의 핵심 수학적 개념 및 분산 최대화

PCA의 핵심 목표는 고차원 데이터 X를 저차원 공간으로 직교 투영(Orthogonal Projection)하되, **"본래 데이터가 가지고 있던 변동성, 즉 분산(Variance)을 유실 없이 최대로 보존하는 고유의 새로운 축"**들을 차례차례 유도해 내는 것입니다.

```text
[ PCA 투영 시 분산 보존의 물리적 의미 ]

            Bad Projection (정보 손실 극대)       Good Projection (분산 최대 보존)
               y                                     y
               │    ● (투영점 뭉침)                   │      ●
               │   /                                 │    /  (주성분 PC1 축)
               │  /                                  │  / ──▶
               │ ●                                   │ /   ●
               └─────────────── x                    └─────────────── x
             * 정상 범주가 한 점으로 유실됨         * 데이터의 고유 분산 구조 유지
```

① 공분산 행렬 (Covariance Matrix) 도출

평균이 0으로 보정된 데이터 행렬 X (n×d)에 대하여 변수 쌍 간의 선형 상관관계를 기하학적으로 규명하는 공분산 행렬 Σ (d×d)를 수립합니다.

Σ=n1XTX

② 고유값 분해 (Eigenvalue Decomposition) 연계

공분산 행렬 Σ는 대칭행렬(Symmetric Matrix)이므로 항상 다음과 같은 스펙트럼 고유값 분해가 성립하며, 서로 직교하는 고유벡터들을 무조건 유도할 수 있습니다.

Σv=λv

* v: 공분산 행렬의 **고유벡터 (Eigenvector)**로서 새로운 차원 축의 직교 방향 벡터입니다.
* λ: 직교축에 투영된 데이터의 분산 크기를 정량적으로 대변하는 **고유값 (Eigenvalue)**입니다.③ 주성분(PC: Principal Component) 선정 기준
* PC1 (제1주성분): 전체 공분산 행렬의 고유값 중에서 가장 거대한 최댓값을 갖는 고유값 λ1에 대칭 대응되는 고유벡터 v1 방향의 축입니다. 데이터의 총 분산을 가장 많이 보존하고 있습니다.
* PC2 (제2주성분): PC1 축과 완벽히 90도 기하학적 직교를 달성하는 고유벡터들 중 두 번째로 높은 분산 크기(λ2)를 설명하는 직교 기저축입니다.
* 주성분 개수(k) 결정: 고유값 누적 설명 분산 비율(Cumulative Explained Variance Ratio)을 도출하여 통상 전체 원본 데이터 변동성의 $70% \sim 80%$ 이상을 설명할 수 있는 지점에서 최적의 차원 개수를 선별적으로 영입합니다. Scree Plot 상에서 기울기가 완만해지는 엘보우 포인트(Elbow Point)를 채택하기도 합니다.

## 4. 기타 차원 축소 기술의 아키텍처 비교

다차원 데이터의 속성에 따라 선형 변환인 PCA 외에도 지도학습 기반의 차원 축소나 저밀도 공간 맵핑을 지원하는 최적의 변환 모델이 요구됩니다.

```text
[ 차원 축소 모델 분류 ]

            ┌────────────────────────┴────────────────────────┐
            ▼                                                 ▼
     선형 차원 축소                                    비선형 차원 축소
    ┌───────────────────────┐                         ┌───────────────────────┐
    │  - PCA (비지도/분산)  │                         │  - MDS (거리 정보)    │
    │  - LDA (지도/클래스)  │                         │  - t-SNE (확률적분포) │
    └───────────────────────┘                         └───────────────────────┘
```

### 1. LDA (선형 판별 분석: Linear Discriminant Analysis)

* 특징: PCA가 변수 자체의 분산만을 노리는 비지도 학습이라면, LDA는 레이블(Y값) 정보가 엄격히 매핑된 상태에서 최적의 선형 차원을 확보하는 지도 학습(Supervised) 기반의 차원 축소 기술입니다.
* 수리적 메커니즘: 서로 다른 타겟 클래스 간의 차이를 극대화하기 위하여, 각 집단 내부의 흩어짐을 나타내는 '클래스 내 분산(SW, Within-class Scatter)'은 최소화하고, 집단 간의 이격을 나타내는 '클래스 간 분산(SB, Between-class Scatter)'은 최대화하는 최적 투영 직교 벡터 w를 유도합니다.

J(w)=wTSWwwTSBw

* 한계점: 타겟 클래스의 범주 개수가 C개일 때 최대 C−1개의 주성분 차원으로만 강제 축소가 제한됩니다.

### 2. MDS (다차원 척도법: Multi-Dimensional Scaling)

* 특징: 객체 간의 실제 유클리드 기하학적 거리 및 유사성(Proximity)을 다차원 공간 상에 최대한 동일하고 시각적으로 완벽하게 유지한 채 저차원으로 직교 매핑하는 계량적 기법입니다.
* 통제 지표 (Stress Value): 본래의 고차원 실제 거리 dij와 저차원 축소 공간 상의 가상 좌표 거리 d^ij 사이의 오차를 측정하는 Stress 지표를 도출하고, 이 수치가 0에 완전히 일치 및 최소화되도록 경사하강법 피팅을 수행합니다.

Stress=∑dij2∑(dij−d^ij)2

*(단, Stress 수치가 0.05 이내면 극도로 우수한 정합 좌표계 복원으로 판정합니다.)*

### 3. t-SNE (t-분포 확률적 임베딩: t-Distributed Stochastic Neighbor Embedding)

* 특징: 고차원 공간에 배치된 이웃 포인트들 간의 거리 정보를 조건부 확률 분포 상의 유사도(Similarity)로 환산하고, 이를 저차원 평면에 직교 맵핑하는 최고 수준의 비선형(Non-linear) 시각화 지향적 차원 축소 알고리즘입니다.
* 수리적 작동 원리:고차원 공간: 데이터 포인트 간 거리가 가까울수록 유사도가 증가하도록 가우시안 표준 정규분포(Gaussian Distribution) 확률 스케일링을 수행합니다.
* 저차원 공간: 고차원에서 가까웠던 거리 정합성을 더욱 안전하게 보존하고, 이상치의 뭉침을 예방하기 위해 꼬리가 매우 길게 일탈 발달하는 t-분포(특히 자유도 1인 코시 분포) 기반 유사도로 매핑합니다.
* 목적 함수: 두 공간 상의 두 가상 조건부 확률 분포 간에 발생하는 차이 및 괴리 수준을 최소화하기 위해 수학적 엔트로피 지표인 **쿨백-라이블러 발산(Kullback-Leibler Divergence, KLD)**식을 최적 손실 함수로 설정하고 경사하강법으로 위치 좌표를 수렴시킵니다.
* 한계점: 고차원 거리를 기하학적 확률 분포로 복원하는 계산 속도가 다소 느리며, 초기 난수 설정 및 퍼플렉서티(Perplexity) 하이퍼 파라미터 값에 따라 저차원 맵의 형상과 응집 클러스터 거리가 가공식으로 뒤바뀌므로 분류 및 회귀의 직접 변수 입력용보다는 오직 고차원 데이터의 시각적 클러스터 분포 직관 확보용으로 극히 강점을 가집니다.

## 1. 요약변수 (Summary Variables) vs 파생변수 (Derived Variables)

피처 엔지니어링(Feature Engineering) 단계에서 분석가의 도메인 지식과 데이터를 합리적으로 결합하여 새로운 속성을 창조하는 과정은 머신러닝 예측 성능을 결정짓는 가장 핵심적인 과정입니다. 대표적인 신규 변수 창출 기법인 요약변수와 파생변수의 설계적 정의를 비교합니다.

* ```text
[ 요약변수 vs 파생변수 핵심 비교 ]

          요약변수 (Summary)                   파생변수 (Derived)
     ┌────────────────────────┐         ┌────────────────────────┐
     │ 객관적 사실의 통계 합산│         │ 주관적/비즈니스적 판단 │
     │ (총 구매액, 방문 횟수) │         │ (가성비 지표, 휴면 여부)│
     └────────────────────────┘         └────────────────────────┘
```

### 1. 요약변수 (Summary Variables)

정의: 데이터가 수집된 원천 정보로부터 일정한 기간이나 대상에 대해 단순 가산, 합산, 평균 등 객관적 통계 수치로 요약해 낸 정량적 변수입니다.
* 특징:모델에 즉시 대입하기 좋은 정형화된 형태를 띠며, 수집 데이터의 원본 정보를 가장 정직하게 대변합니다.
* 가공 시 분석가의 주관이 거의 개입되지 않아 범용성과 재현성(Reproducibility)이 매우 높습니다.
* 주요 예시:고객별 최근 3개월간 '총 구매 금액', '평균 방문 횟수', '통화 시간 합산', '카드 결제 건수' 등.

### 2. 파생변수 (Derived Variables)

* 정의: 분석가가 특정 비즈니스 가설이나 도메인 맥락을 기반으로 하여 주관적 가이드라인 및 특정 규칙을 설계하여 새롭게 정의한 변수입니다.
* 특징:원본 데이터의 구조를 단순 가산하는 것을 넘어, 두 개 이상의 속성을 유기적으로 조합하거나 구간화(Binning)하여 특정 의미(Semantic)를 강제 투영합니다.
* 분석가의 역량과 아이디어에 따라 모델 성능을 극적으로 올릴 수 있으나, 지나치게 주관적일 경우 다중공선성(Multicollinearity)이나 과적합(Overfitting)을 유발할 우려가 큽니다.
* 주요 예시:구매 금액 대비 할인율을 적용한 '가성비 지표', 구매 시간대를 분류한 '주 이용 시간대(야간/주간)', 최근 구매 기록 유무에 따른 '휴면 고객 여부(True/False)', '근무일 대비 주말 소비 비중' 등.

## 2. 데이터 불균형 (Data Imbalance) 처리의 당위성

현업의 실제 데이터 필드(예: 신용카드 부정 사용 탐지, 암 진단 의료 데이터, 공장 설비 고장 예지 등)는 타겟 클래스의 비율이 극도로 한쪽으로 치우쳐져 있습니다. (예: 정상 99.9%, 부정/고장 0.1%).

### 1. 정확도의 역설 (Accuracy Paradox)

* 데이터 불균형 상태에서 아무런 조치 없이 일반적인 머신러닝 알고리즘을 학습하면, 모든 데이터를 무조건 '정상(Majority Class)'으로만 분류해도 정확도($Accuracy$)는 $99.9%$라는 왜곡된 수치적 우수성을 띱니다.
* 그러나 실제 분류해 내야 하는 소수 클래스(Minority Class)의 검출율(Recall)은 $0%$가 되며, 이는 비즈니스 의사결정에 치명적인 파멸적 오류(Bankruptcy, 환자 사망 등)를 야기합니다.

### 2. 모델 편향 제어의 필요성

* 손실 함수(Loss Function)가 다수 클래스의 오차를 최소화하는 방향으로만 가중치 업데이트를 가이드하므로, 분류 결정 경계선(Decision Boundary)이 소수 클래스 쪽으로 치우쳐져 소수 클래스의 기하학적 공간 경계가 과도하게 축소됩니다. 이를 보정하기 위해 샘플링 조정을 수행해야 합니다.

## 3. 언더샘플링 (Under-sampling) 기법

다수 클래스(Majority Class)의 관측치를 소수 클래스의 규모에 맞추어 의도적으로 탈락시키는 기법입니다. 데이터 수 자체를 축소하므로 모델의 **학습 연산 속도가 비약적으로 증가**하지만, 정보 유실(Information Loss)로 인해 **과소적합(Underfitting)**을 유발할 위험이 큽니다.

```text
[ 대표 언더샘플링 작동 메커니즘 ]

             Tomek Links                      CNN (Condensed Nearest Neighbor)
       ┌────────────────────────┐               ┌────────────────────────┐
       │ 경계선의 다수클래스 제거│               │ 소수클래스 근처 위주 남김│
       │ (분류 경계선 명확화)    │               │ (중복된 다수클래스 축소)│
       └────────────────────────┘               └────────────────────────┘
```

### 1. 랜덤 언더샘플링 (Random Under-sampling)

* 작동 원리: 다수 클래스의 데이터 중 일부를 무작위 복원 추출 방식으로 탈락시켜 소수 클래스 개수와 동일하게 맞춥니다.
* 한계: 다수 클래스가 가지고 있던 중요한 공간 분포적 정보가 한순간에 손실될 수 있어 왜곡된 경계면이 형성될 가능성이 큽니다.

### 2. 토멕 링크 (Tomek Links)

* 정의: 서로 다른 클래스에 속한 가장 인접한 데이터 쌍 중, 두 포인트 사이에 다른 데이터가 존재하지 않는 일대일 최단거리 물리 링크를 뜻합니다.
* 수학적 조건:서로 다른 클래스에 속한 두 데이터 포인트 xi (소수 클래스)와 xj (다수 클래스)가 존재하고, 이들 사이의 기하학적 거리를 d(xi,xj)라고 할 때, 다음 조건을 충족하는 임의의 다른 제3의 데이터 포인트 xk가 존재하지 않으면 두 포인트는 토멕 링크(Tomek Link) 관계를 맺습니다.

∄xks.t.d(xi,xk)
* 샘플링 전략: 탐지된 토멕 링크 쌍 중에서 다수 클래스 데이터(xj)를 선택적으로 제거합니다. 이를 통해 두 클래스 사이에 겹쳐져 혼탁해진 잡음 경계를 지우고, 분류 결정 경계선(Decision Boundary)을 아주 명확하고 튼튼하게 분리해 냅니다.

### 3. CNN (Condensed Nearest Neighbor)

* 작동 원리: 1-Nearest Neighbor 알고리즘을 활용하여 다수 클래스의 무의미한 중복 데이터를 극적으로 깎아냅니다.먼저 전체 데이터 세트에서 소수 클래스 전체와 다수 클래스 중 무작위 1개 샘플을 추출하여 서브 세트 S를 형성합니다.
* 원본 데이터 세트에서 데이터를 하나씩 꺼내어 S 내의 데이터들과 K-NN(K=1) 거리를 연산하여 분류를 수행합니다.
* 만약 분류가 틀릴 경우(오분류), 해당 데이터는 경계 부근의 고유한 공간 정보를 품고 있는 핵심 대표 데이터로 간주하여 서브 세트 S에 포함시킵니다.
* 정상적으로 잘 분류되는 데이터는 다수 클래스의 중복적인 내부 포인트로 판정하여 과감히 버립니다.
* 효과: 다수 클래스 내부의 중복된 영토 데이터를 전부 제거하고, 소수 클래스와 접한 경계면 주변의 아주 콤팩트한 다수 클래스 지표들만 효율적으로 보존할 수 있습니다.

## 4. 오버샘플링 (Over-sampling) 기법

소수 클래스(Minority Class)의 관측치를 의도적으로 복제하거나 기하학적 분포를 확장하여 다수 클래스의 양과 균형을 맞추는 기법입니다. 데이터 정보 소실이 없어 **분류 모델의 재현율(Recall) 향상에 탁월**하지만, 학습 데이터 수가 증가하여 **연산 오버헤드가 발생**하며 **과적합(Overfitting)** 가능성이 상존합니다.

```text
[ SMOTE 신규 관측치 기하학적 합성 과정 ]

               (Minority) ● ─────────── ⊙ ─────────── ● (K-NN Neighbor)
                                    (신규 합성점 x_new)
```

### 1. 랜덤 오버샘플링 (Random Over-sampling)

* 작동 원리: 소수 클래스의 관측치들을 단순 무작위 중복 복제하여 데이터 규모를 키우는 단순 기법입니다.
* 한계: 기하학적 공간 분포의 다양성 확장이 전혀 일어나지 않으므로, 동일 데이터의 반복으로 인해 결정 경계면이 소수 클래스 주변에서 과도하게 쪼개지는 강력한 오버피팅 오작동을 유발합니다.

### 2. SMOTE (Synthetic Minority Over-sampling Technique)

단순 복제 대신 소수 클래스 공간 영역 내의 가까운 데이터들을 선형 결합(Linear Combination)하여 **존재하지 않았던 완전히 새로운 소수 클래스 샘플을 기하학적으로 합성(Synthetic)**하는 가장 대표적인 진보적 오버샘플링 알고리즘입니다.

* 수리적 합성 메커니즘:소수 클래스에서 임의의 데이터 포인트 xi를 선택합니다.
* xi에 대해 소수 클래스 내의 다른 이웃들과의 유클리드 거리를 측정하여 가장 인접한 K개의 이웃(K-NN) 중 임의의 xknn을 하나 무작위로 영입합니다.
* 두 포인트 사이를 잇는 임의의 직선 가상 경로 위에서 새로운 포인트를 생성하기 위해 0과 1 사이의 난수 가중치 r∈[0,1]를 활용하여 다음과 같이 선형 보간 합성값 xnew를 유도합니다.

xnew=xi+r×(xknn−xi)

* 장점: 단순 가산 복제가 아니므로 분류 경계선이 과적합으로 찢어지는 문제를 극적으로 방지하고, 소수 클래스의 고유 영토 방향성 분포를 튼튼하게 확장해 줍니다.

### 3. SMOTE의 진화형 변형 모델

```text
[ SMOTE 주요 변형 모델 비교 ]

             Borderline-SMOTE                            ADASYN
      ┌─────────────────────────┐               ┌─────────────────────────┐
      │ 오직 분류 경계면 근처의 │               │ 밀도에 반비례하여       │
      │ 위험 소수 샘플만 합성   │               │ 학습 힘겨운 지역 집중   │
      └─────────────────────────┘               └─────────────────────────┘
```

① Borderline-SMOTE
* 개념: 소수 클래스 중에서도 다수 클래스와 맞닿아 있는 위험한 경계면(Borderline) 영역의 관측치들만 똑똑하게 엄선하여 오버샘플링을 집중 수행합니다.
* 작동 원리: 소수 클래스의 임의 샘플 주변 K-NN(K=8) 이웃 중 다수 클래스의 비율을 체크합니다.Safe: 주변 이웃 중 다수 클래스가 절반 미만인 경우 ➡️ 안전하므로 오버샘플링 제외
* Danger: 주변 이웃 중 다수 클래스가 절반 이상, 전체 미만인 경우 ➡️ 경계면의 위험 샘플이므로 이 관측치들만을 대상으로 집중 SMOTE 합성 실행
* Noise: 주변 이웃 전체가 다수 클래스인 경우 ➡️ 이상치(Outlier)로 판정하여 제외② ADASYN (Adaptive Synthetic Sampling)
* 개념: 데이터 주변의 분포 성질에 따라 오버샘플링 가중 합성 양을 스스로 판단하여 적용하는 적응형(Adaptive) 샘플링 기술입니다.
* 작동 원리: 소수 클래스 주변의 다수 클래스 관측치 비율을 계산한 뒤, 다수 클래스가 많아 분류 모델이 학습하기 까다롭고 힘겨운 소수 데이터 포인트 주변에 반비례적 밀도 가중치를 주어 더 대량의 합성 데이터를 집중 분산 생성합니다. 소수 클래스의 전체적인 밀도적 복원 정밀도가 한층 세련되게 상승합니다.

### 1. 결측값(Null/NaN) 핵심 요약

완전 무작위 결측(MCAR): 변수 Y의 결측 원인이 자신 및 타 변수 X와 아무런 통계적 상관관계를 갖지 않는 순수 무작위 상태입니다.
* 무작위 결측(MAR): 변수 Y의 결측 원인이 다른 관측 변수 X값에 의해 완벽하게 설명되나, 자기 자신의 미관측 값과는 연관이 없는 상태입니다.
* 비무작위 결측(NMAR): 결측 원인이 누락된 자기 자신의 값(Y) 자체에 내재되어 있어, 단순 제거 시 강력한 모델 통계적 편향(Bias)을 유발합니다.
* 다중 대치법(MICE): Monte Carlo 시뮬레이션 기반으로 **[대치(Imputation) ➡️ 분석(Analysis) ➡️ 결합(Pooling)]**의 3단계 순환 프로세스를 거쳐 단일 대치의 오차를 확률적으로 복원합니다.

### 2. 이상값(Outlier) 통계적 탐지 공식

* IQR(Interquartile Range) 방식: 사분위수 기반의 비모수적 탐지선입니다.IQR=Q3−Q1
* LowerLimit=Q1−1.5×IQR (정규분포 기준 약 ±2.698σ 이탈 탐지)
* UpperLimit=Q3+1.5×IQR
* Z-Score 방식: 평균 μ와 표준편차 σ를 활용한 정형 탐지선입니다.Z=σx−μ (보통 ∣Z∣>3을 기계적 이상치 임계치로 정의)
* DBSCAN: 밀도 기반 알고리즘으로, 탐색 반경 Eps 내의 최소 샘플 수 $MinPts$를 충족하지 못하는 포인트를 잡음(Noise) 포인트로 영구 고립 격리합니다.
* Isolation Forest: 다차원 공간에서 소수 클래스를 단순 의사결정 트리로 격리 분할할 때, 깊이(Path Length)가 평균값 대비 극도로 얕은 관측치를 s→1 지표 조건에 따라 이상치로 확정 탐지합니다.

## 3. 파생변수 생성 및 불균형 데이터 처리

```text
[ 데이터 불균형 복원 샘플링 아키텍처 ]

             언더샘플링 (Under-sampling)                  오버샘플링 (Over-sampling)
       ┌─────────────────────────────────┐          ┌─────────────────────────────────┐
       │ 다수 클래스 삭제 (정보 소실 위험)│          │ 소수 클래스 합성 (연산 부하 증가)│
       │  - Tomek Links (경계면 다수 제거)│          │  - SMOTE (선형 보간 합성)       │
       │  - CNN (중복 제거)              │          │  - Borderline-SMOTE, ADASYN     │
       └─────────────────────────────────┘          └─────────────────────────────────┘
```

### 1. 변수 생성 표준 비교

* 요약변수: 사내 내부 비즈니스 통계에서 단순 가산, 평균 등 객관적 정량 가공을 수행한 변수 (예: 총 이용 금액, 주말 접속 빈도)
* 파생변수: 분석가가 비즈니스 가설 및 주관적 도메인 상상을 거쳐 강제 규칙성 가이드라인을 부여해 신설한 주관 변수 (예: 휴면 가성비 지표)

### 2. 불균형 데이터 샘플링 기법 요약

* 토멕 링크(Tomek Links): 서로 다른 클래스 간 최단 기하학적 거리 관계를 맺고 있는 데이터 쌍을 추적하여, 다수 클래스 데이터를 선택적으로 박탈함으로써 결정 경계면의 안개를 걷어내는 지식 필터링 기술입니다.

∄xks.t.d(xi,xk)
* CNN(Condensed Nearest Neighbor): 1-NN 분류 오분류 조건 포인트만 서브 세트에 집어넣어, 다수 클래스의 무의미한 내부 영토 관측치를 깎아내고 경계부 핵심 대표점만 초단축 보존합니다.
* SMOTE: 단순 가산 복제로 인한 과적합 붕괴를 피하기 위해, 소수 클래스 데이터 xi와 이웃 xknn 간의 선형 가상 궤적 경로상에 r∈[0,1] 난수 변동폭을 주어 가짜 신규 관측치 xnew를 기하학적으로 합성해 냅니다.

xnew=xi+r×(xknn−xi)

* Borderline-SMOTE: 소수 클래스의 기하학적 주변 이웃 중 다수 클래스 비중이 절반 이상을 차단하는 위험(Danger) 등급 샘플들만을 집중 추적 타겟으로 정의하여 SMOTE를 선별적으로 가동합니다.
* ADASYN: 다수 클래스 밀도가 높아 분류기가 정교하게 학습하기 힘든 악조건의 소수 클래스 주변에 가중 합성 난수를 집중 분산 배치하여 극도로 입체적인 소수 구역 보정을 완성합니다.

### Q4. 고차원 다변량 데이터 공간에서 소수 이상 관측치를 통계적으로 분리 및 정제하는 비지도 학습 알고리즘들에 대한 설명으로 올바르게 연결되지 않은 것은?

### Q9. 불균형 데이터 샘플링(Sampling) 기법 중 다수 클래스 데이터를 의도적으로 정제하는 언더샘플링(Under-sampling)에 대한 설명으로 가장 적절하지 않은 것은?

### Q10. 데이터 불균형 복원을 위해 데이터 생성 공간을 수리 보간하는 오버샘플링(Over-sampling) 계열 알고리즘들에 대한 설명으로 옳지 않은 것은?

* ① SMOTE: 단순 복제 가산의 과적합 단점을 극복하기 위해 소수 데이터 xi와 인접 K-최근접 이웃 xknn 간의 선형 가상 경로 궤적 상에 난수 보간을 얹어 완전히 새로운 가짜 합성 관측치를 생성한다.
* ② Borderline-SMOTE: 소수 클래스 주변 K-NN에 속한 다수 클래스의 개수 비율을 진단하여, 다수 클래스 비중이 절반 이상을 완전히 지배하는 경계 위험 영역인 'Danger' 등급 소수 관측치만을 표적 추적하여 집중 오버샘플링을 뿜어낸다.
* ③ ADASYN: 다수 클래스 밀도가 너무 빽빽하게 밀집되어 분류 경계를 모형이 구분하기 힘든 극악의 학습 난제 소수 클래스 공간 영역을 추적하여, 해당 구역에 가중치를 부여해 다량의 데이터를 더욱 압도적으로 집중 밀집 투하한다.
* ④ SMOTE 한계: 기하학적 선형 보간 경로 상에 합성 데이터를 만들기 때문에, 다차원 특징 공간에서 소수 클래스 변수의 주변에 이상치가 존재할 경우 데이터 공간 내 왜곡된 영역까지 오버샘플링을 뻗어 결합 노이즈를 심각하게 증폭시키는 약점을 노출할 수 있다.

▶ 클릭하여 정답 및 해설 확인* **정답**: 없음 (모든 보기의 설명이 완벽히 올바름)* **상세 해설**: 출제 오류나 함정 방어를 위해 10번 문항은 **모든 보기(①, ②, ③, ④)의 작동 메커니즘과 학술적 이론 정의가 100% 무결하고 완벽하게 기술된 명품 선지 세트**입니다.* **SMOTE 수식**: xnew=xi+rand(0,1)×(xknn−xi) 작동 논리* **Borderline-SMOTE의 3대 등급 분류 규칙**:* **Safe**: 이웃 중 소수 클래스가 다수 (오버샘플링 불필요)* **Danger**: 이웃 중 다수 클래스가 절반 이상 다수 (오버샘플링 핵심 대상)* **Noise**: 이웃 전체가 다수 클래스로 둘러싸인 외톨이 고립 객체 (오버샘플링 제외 대상)* **ADASYN**: 정밀한 다수 클래스 주변 조건 확률 비중 가중 생성 시스템* **SMOTE의 기하학적 선형 노이즈 확장 취약점**까지 완벽하게 정론을 가리키고 있습니다. 이 개념 전반을 온전히 체득해 가시기 바랍니다.
