# 분석기법  적용
1. 분석기법
회귀분석 : 독립변수가  종속변수에  미치는  영향을  파악  연속형 / 연속형
⇒ 예측선  하나  그어놓고 , 예측값이랑  진짜값이  얼마나  차이  나는지  보자
잔차  : 예측값과  실제값  차이  ( 오차는  모집단 , 잔차는  표본  기준 )
회귀계수  : 기울기랑  절편  → 얼마나  영향을  주나
회귀계수  추정방법  : 최소제곱법  ⇒ 잔차  제곱  다  더한게  제일  작게되는  절편  찾기
회귀모형  평가  : R-square 01 사이  값 ) 
→ 예측  잘하면  1 에  가까워짐  R^2 결정계수 )
선형  회귀분석의  가정  5 가지
 선형성  : 종속 - 독립변수는  선형관계  ( 직선관계 )
 독립성  : 잔차와  독립변수 간  상관관계가  없음
*다중공선성 : 독립변수  서로  간에  강한  상관관계가  나타나는  문제  → 차원  축소 , 상관계수  분해  필요
 정상성 ( 정규성 ) : 잔차가  정규분포의  특성을  지님 x
 등분산성  : 잔차의  분산이  고르게  분포
 비상관성  : 잔차들끼리  상관이  없어야  함  
회귀  모형  변수  선택  방법
전진선택법  - 하나씩  넣어보면서  성능  좋아지면  유지
후진선택법  - 다  넣고  하나씩  빼면서  봄
단계별  선택법  : 전진 + 후진  
벌점  기준  : 변수  추가  시  벌점 (AIC, BIC  낮을수록  👍🏻 ) 고려
로지스틱  회귀분석 : 종속변수가  범주형  데이터일  때  쓰는  회귀  연속형 / 범주형
⇒ 결과  값이  예 / 아니오처럼  뚜렷할   때  쓰는  회귀
오즈  : 성공  확률과  실패  확률의  비
로짓 (logit) 변환  : 오즈에  자연로그를  취하여  선형처럼  바꿈
→ 독립변수가  n 증가하면  확률이  e 의  n 승  만큼  증가
확률  예측  모델이지만  선형회귀처럼  해석도  가능하
의사결정나무 : 여러  개  분리  기준으로  최종  분류  값을  찾음
⇒ 질문하면서  나무처럼  가지를  쳐나가는  분류기

분할기준
분류에서의  분할  방법  : CHAID 통계적  유의성 ), CART지니지수), C4.5/C5.0엔트로피지수)
회귀에서의  분할  방법  : CHAID, CART
정지규칙  : 분리를  더  이상  수행하지  않게  함
가지치기  : 일부  가지를  제거하여  과적합  방지
인공신경망 : 인간의  뇌  구조를  모방한  퍼셉트론  활용
퍼셉트론  - 신경망  기본  단위  ( 입력  → 가중치  → 활성화  함수  → 출력 )
다중  퍼셉트론 (MLP) - 입력층 ~ 출력층  사이에  1 개  이상의  은닉층 보유
*은닉층 수는  사용자가  직접  설정
활성화  함수 : 인공신경망의  선형성  극복  (XOR 문제  해결 )
⇒ 입력신호의  총합을  출력신호로  변환하는  기능이  있는  부문
시그모이드 함수  : 0~1 사이  값을  가지며  로지스틱  회귀분석과  유사
소프트맥스  함수  : 목표  데이터가  다범주인  경우  각  범주에  속할  사후확률을  제공
하이퍼볼릭  탄젠트  함수  : 시그모이드의  중심  값을  0 으로  이동 → -1~1 사이  값
ReLU 함수  : 기울기  소실문제  극복 → 0 또는  1 둘  중  하나  값
인공신경망  과적합 방지방안
⇒ 공부  너무  외운  티  나면  실전에서  틀리듯 , 모델도  똑같아
라쏘 (L1) 규제  : 맨하탄  거리  기반 ( 절대값 ) - 변수가  일부  아예  제거됨  
릿지 (L2) 규제  : 유클리드  거리  기반 ( 제곱 ) - 변수의  영향을  줄이기  위해 0 에  가깝게  만듬
드롭아웃  - 일부  퍼셉트론을  비활성화  ( 일부  뉴런  끔 )
조기종료  - 성능  나빠지기  전에  꺼버림
모델의  복잡도  줄이기  - 은닉층의  퍼셉트론  감소
데이터  증강  - 데이터를  더  많이  만들기
배치정규화  - 중간  중간  정규화해서  안정화
인공신경망  학습  방법
역전파  알고리즘  : 가중치를  수정하여  오차를  줄임  ( 출력층  → 입력층 )
경사하강법  : 기울기를  낮은  쪽으로  이동시켜  극값 (global minimum) 에  이를  때까지  반복
서포트벡터머신 (SVM) : 마진이  최대가  되는  초평면 ( 경계선 )을  찾아  분류
⇒ 데이터를  가장  똑  떨어지게  나눌  수  있는  ‘ 경계선 ʼ 찾기
초평면 ( 하이퍼플레인 ) : 데이터를  구분하는  기준이  되는  경계선
서포트벡터  : 초평면 ( 경계선 ) 과  가장  가까운  데이터들
마진  : 초  평면 ( 하이퍼플레인 ) 과  서포트벡터  사이의  거리  → 최대화  목표
커널함수 : 저차원  데이터를  고차원  데이터로  변경하는  함수

⇒ 다변량  데이터들은  분석할  때  차원축소 !

→ 변수들이  같은  요인끼리  묶이고 , 각 요인끼리는  서로  독립적 ( 직교 )
 요인추출방법  : 주성분분석 , 공통요인분석
 요인회전
시계열  분석 : 시간  흐름에  따라  관찰된  자료  특성을  파악하여  미래  예측
정상성 = 모든  시점에  일정한  평균과  분산을  가져야  함
* 차분 : 현  시점의  자료를  이전  값으로  빼는  방법
*자기상관 : 현재  상태가  과거 & 미래와  밀접한  관련이  있음

시계열  모형

 이동평균 (MA) 모형  : 백색잡음들의  선형결합으로  표현  ( 관측치에  모두  동일  가중치  부여 )
