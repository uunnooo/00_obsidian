이 과목은 전통적인 통계 기반의 선형/비선형 회귀 모델부터 규제 회귀, 분류, 군집, 연관규칙, 그리고 비모수 통계학에 이르는 핵심 지도/비지도 머신러닝 알고리즘의 작동 원리와 수식을 체계적으로 다룹니다.

## 📈 1. 회귀분석 및 규제 회귀분석

### ① 선형회귀분석 (Linear Regression)
독립변수 $X$와 종속변수 $Y$ 간의 선형 인과관계를 설명하고 예측하는 전통 통계 모델입니다.
* **선형회귀 기본 가정 5가지 (필수 암기 ⭐)**:
  1. **선형성**: 독립변수와 종속변수가 선형적인 형태여야 함.
  2. **독립성**: 오차항 간 상관관계가 없어야 함 (더빈-왓슨 값 $d \approx 2$ 부근일 때 독립성 확보, 0이나 4에 가까우면 자기상관 존재).
  3. **등분산성**: 독립변수 값에 관계없이 오차항의 분산이 항상 일정해야 함 (부채꼴 모양 잔차 분산은 등분산 위반).
  4. **비상관성**: 오차와 독립변수 간 상관관계가 없어야 함.
  5. **정규성**: 오차항의 분포가 평균이 0인 정규분포를 따라야 함 (Q-Q Plot 상에서 직선 형태를 이룸).
* **회귀계수($\beta_j$)의 올바른 해석**:
  * "다른 모든 설명변수들을 고정(통제)해 둔 채로, 특정 변수 $x_j$가 1단위 증가함에 따라 종속변수 $y$의 평균값이 변하는 수치"입니다. (단독 유의미성 검정은 $t$-검정을 수행)
* **다중공선성 (Multicollinearity)**:
  * 독립변수들 간의 강한 상관성으로 인해 회귀 계수의 분산이 불필요하게 커져 모형의 해석력이 훼손되는 현상.
  * **판별**: 분산팽창요인 **`VIF ≥ 10`** 또는 상태지수가 30을 넘을 경우 다중공선성 존재로 판별.
  * **해결**: 다중공선성을 야기하는 원인 변수 제거, PCA(주성분 회귀), Ridge/Lasso 규제 적용.

  * 1) 회귀 분석의 정의
  * ● 회귀 분석(Regresssion Analysis)은 하나 이상의 독립변수(X)가 종속변수(Y)에 끼치는 영향을 분석하는
  * 통계기법이다.
  * ● 회귀 분석에서 독립변수와 종속변수는 선형적인 관계를 갖고, 독립변수를 통해 종속변수를 예측하게
  * 된다.

> [!INFO] **교안 상세 보강 (3. 분석기법 적용 – 분석기법)**
* 2) 회귀 분석의 가정
  * ● 회귀 분석은 선형성, 독립성, 등분산성, 정상성(정규성)의 4가지 가정을 만족해야 한다.
  * ① 선형성
  * ▶ 독립변수 변화에 따라 종속변수도 선형적인 일정 크기로 변화한다.
  * ▶ 산점도를 통해 선형성 확인이 가능하다.
  * ② 독립성
  * ▶ 잔차와 독립변수의 값이 서로 독립적이어야 한다.
  * ▶ 더빈-왓슨 검정을 통해 통계량 확인이 가능하다.
  * ③ 등분산성
  * ▶ 잔차의 분산이 독립변수와 무관하게 일정해야 한다.
  * ▶ 잔차가 고르게 분포되어 있어야 한다.

  * 잔차(residual) : 표본(Sample)으로 추정한 회귀식과 실제 관측값의 차이로 각각의 자료가 직선에 얼마나 잘 맞는지 확인하는 도구
  * 오차(error) : 모집단(population)으로부터 추정한 회귀식으로 얻은 예측값과 실제 관측값의 차이
  * Durbin-Watson 검정 : 회귀분석에서 오차항의 1차 자기상관을 검출하는 방법으로 회귀분석 오차항의 독립성 가정을 확인하는 방법
  * 자기상관(Autocorrelation) : 시계열의 시차 값(lagged values) 사이의 선형 관계를 측정하는 것

> [!INFO] **교안 상세 보강 (3. 분석기법 적용 – 분석기법)**
* 2) 회귀 분석의 가정
  * ④ 정상성(정규성)
  * ▶ 잔차항이 평균 0인 정규분포 형태를 이뤄야 한다.
  * ▶ 샤피로-윌크 검정, 콜모고로프-스미르노프 검정을 통해 통계량 확인이 가능하다.
  * ▶ Q-Q plot에서 잔차가 오른쪽으로 치우친 직선 형태의 경우 정규성을 띈다고 할 수 있다.

  * 정규성(Normally) : 통계학에서 가설검증(hypothesis test)이 정규분포를 따른다는 성질을 전제하는 주요한 가정들 중 하나이다
  * 샤피로-윌크 검정, 콜모고로프-스미르노프 검정 : 정규성 검정 방법
  * Q-Q plot : 분위수대조도로 불리는 정규모집단 가정을 하는 방법 중 하나이다. 수집 데이터를 표준정규분포의 분위수와 비교하여 그리는 그래프로 데이터의 정규성 가정에 대한 검토를 가능하게 한다.

  * ㉮ 회귀계수(Regression Coefficient) 추정
  * → 회귀계수는 독립변수가 한 단위 변환함에 따라 종속변수에 미치는 영향력의 크기를
  * 의미하며, 최소제곱법을 사용한다.
  * → 최소 제곱법은 구하려는 값과 실제 값의 오차를 제곱한 합이 최소가 되는 해를 구하는

  * ① 활성화 함수는 입력 신호의 총합을 출력 신호로 변환 하는 함수이다.
  * ② 활성화 함수에는 시그모이드 함수, tanh함수, ReLU함수,
  * Leaky ReLU함수, 소프트맥스(Softmax)함수가 있다.
  * ③ tanh 함수는 시그모이드 함수의 기울기 소실 문제를 해결했다.
  * ④ Leaky ReLU 함수는 Dying ReLU 현상을 해결했다.
  * 활성화 함수
  * ● 활성화 함수(Activation Function)는 입력 신호의 총합
  * 을 출력 신호로 변환하는 함수이다.
  * ● 활성화 함수에는 계단 함수, 부호 함수, 시그모이드 함수, tanh 함수(hyperbolic function 함수), ReLU 함수,
  * Leaky ReLU 함수, 소프트맥스 함수가 있다.
  * ① 계단 함수(Step Function)
  * ▶ 가장 간단한 형태의 활성화 함수이다.
  * ▶ 특정한 값을 입력받았을 때, 값이 0이하인 경우(음수) 에는 0을, 0초과인 경우(양수)에는 1을 출력해주는 함수 이다.
  * ② 부호 함수(Sign Function)
  * ▶ 입력된 수의 부호를 판별하는 함수이다.
  * ③ 시그모이드 함수(Sigmoid Function)
  * ▶ 로지스틱 회귀 함수에 로짓 변환을 한 형태이다.
  * ▶ 기울기 수솔 문제의 원인이 된다.
  * ④ tanh 함수(hyperbolic tangent function)
  * ▶ 시그모이드 함수의 확장된 형태이다.
  * ▶ 시그모이드보다 학습 속도가 빠르다.
  * ⑤ ReLU(렐루 함수)
  * ▶ 양수 입력 시 어떠한 값의 변형 없이 입력값 그대로 출력하고, 음수 입력 시 항상 0을 리턴하는 함수이다.
  * ▶ 시그모이드 함수의 기울기 소실 문제를 해결한다.
  * ▶ 상대적으로 가중치 업데이트 속도가 빠르다.
  * ⑥ Leaky ReLU
  * ▶ 임계치보다 작을 때 0을 곱하는 ReLU와 달리 0.01을 곱한다.
  * ▶ ReLU 함수의 뉴런이 죽는 현상(Dying ReLU)을 해결한다.
  * ⑦ 소프트맥스 함수(Softmax Function)
  * ▶ 세 개 이상으로 분류하는 다중 클래스 분류 모델을 만들 때 사용된다.
  * ▶ 분류될 클래스의 개수가 n인 경우, n차원의 벡터를 입력
  * 받아 각 클래스에 속할 확률을 추정한다.
  * ▶ 입력 받은 값을 출력할 때 0~1 사이의 값으로 모두 정규화하며, 출력값의 총합은 항상 1이 된다.

### ② 로지스틱 회귀분석 (Logistic Regression)
종속변수가 수치형이 아닌 범주형(특히 예/아니오 같은 **이진 범주**)일 때 적용하는 확률적 지도학습 모델입니다.
* **오즈 (Odds, 성공 확률 / 실패 확률)**: 
  $$\text{Odds} = \frac{p}{1-p}$$
* **로짓 변환 (Logit Link Function)**: 오즈에 자연로그를 취해 우변의 선형 회귀식과 등치되게 만드는 함수.
  $$\ln\left(\frac{p}{1-p}\right) = \beta_0 + \beta_1 X_1 + \dots + \beta_p X_p$$
  * *로그오즈*와 선형예측값 범위는 수식상 $-\infty \sim +\infty$로 무제한입니다.
* **시그모이드 함수 (Sigmoid)**: 로짓 변환 수식을 $p$에 대해 정리하여 결과값을 상시 0~1 사이의 확률값으로 반환하게 만드는 활성화 함수.
  $$p = \frac{1}{1 + e^{-z}}$$

> [!WARNING] 🚨 [초빈출 함정] 로지스틱 회귀계수 지수화 $\exp(\beta_j)$ 해석
> * **핵심 공식**: 회귀계수에 자연대수를 취한 값인 $\exp(\beta_j)$는 $x_j$가 1단위 증가함에 따른 **오즈의 배수(Odds Ratio / 오즈비)**를 의미합니다.
> * **틀린 보기**: "$\exp(\beta_1) = 1.2$인 경우, $x_1$이 1단위 증가함에 따라 분류 확률($p$)이 20% 증가한다." ➡️ **완벽한 오답!**
> * **맞는 보기**: "$\exp(\beta_1) = 1.2$인 경우, $x_1$이 1단위 증가함에 따라 **성공 오즈(성공확률/실패확률)가 1.2배**가 된다." ➡️ **완벽한 정답!**

### ③ 가중치 규제 회귀 (Ridge, Lasso, Elastic Net)
모형이 필요 이상으로 복잡해져 과적합되는 것을 막기 위해 회귀 계수 크기에 벌점(Penalty)을 가하는 정밀한 변수 규제 모델입니다.

| 규제 기법 | 가해지는 벌점(Penalty) 형태 | 핵심 메커니즘 및 차별적 효과 |
| :--- | :--- | :--- |
| **릿지 회귀<br>(Ridge)** | **$L_2$ 규제** : $\lambda \sum \beta_j^2$<br>(계수 제곱합 벌점) | • 모든 회귀 계수를 전체적으로 0에 가깝게 부드럽게 축소(Shrinkage)시킴.<br>• 계수들이 완전히 0이 되지는 않으므로 **변수 제거 효과는 없음** (다중공선성 완화에 탁월). |
| **라쏘 회귀<br>(Lasso)** | **$L_1$ 규제** : $\lambda \sum |\beta_j|$<br>(계수 절댓값합 벌점) | • 가중치를 깎다가 무관한 변수의 계수를 **완벽하게 0으로 만들어 버림**.<br>• 자동적으로 불필요한 독립변수들을 배제하는 **변수 선택(Feature Selection) 효과**를 수행. |
| **엘라스틱넷<br>(Elastic Net)** | **$L_1$ + $L_2$ 혼합 규제** | • $L_1$ 규제와 $L_2$ 규제를 비율 조합하여 상호 장점을 유기적으로 결합한 기법. |

### ① 의사결정나무 (Decision Tree)
데이터를 무작위로 분할해 나가며 나무(Tree) 모양의 분류/회귀 규칙을 수립하는 높은 해석력의 지도학습 모델입니다.
* **나무의 복잡도 제어**: 과대적합을 예방하기 위해 **가지치기(Pruning), 최대 깊이(Max Depth), 최소 잎 표본 수(Min Samples Leaf)** 기준을 주어 성장을 제어합니다.
* **불순도(Impurity) 기준 공식 (필수 암기 ⭐)**:
  * **엔트로피 (Entropy)**: 한 노드 내 서로 다른 범주들이 섞인 무질서도 지표. (완벽 정제 시 0, 반반 균등 혼합 시 최대값 1).
    $$H = -\sum_{i=1}^{k} p_i \log_2(p_i)$$
  * **지니 지수 (Gini)**: 노드의 불순한 조합 정도를 측정하는 지표 (완벽 정제 시 0, 반반 균등 혼합 시 최대값 0.5).
    $$G = 1 - \sum_{i=1}^{k} p_i^2$$
  * **정보 이득 (Information Gain)**: 부모 노드의 불순도에서 분할 후 생성된 자식 노드들의 가중 평균 불순도를 뺀 값 (정보 이득이 최대가 되도록 나뭇가지를 가름).

  * 초깃값을 갱신하는 과정을 반복하여 K개의 최종 군집을 형성한다.
  * ▶ K-평균 군집 분석은 이상값에 민감하게 반응하는 단점이 있고, 이를 보완하는 방법으로는
  * K-중앙값 군집 사용 및 이상값 제거가 있다.
  * [K-평균 군집 분석 절차]
  * K개의 객체 선택 → 할당 → 중심 갱신 → 반복

  * K-중앙값 군집 : 평균값 대신 중앙값을 사용하여 형성된 군집

> [!INFO] **교안 상세 보강 (3. 분석기법 적용 – 분석기법)**
* 5) 비계층적 군집 분석
  * ① K-평균 군집 분석(K-means clustering)
  * ▶ K값 선정 기법
  * - 엘보우(Elbow) 기법 : 기울기가 완만한 부분에 해당하는 클러스터 선택
  * - 실루엣(Silhouette) 기법 : 각 군집 간의 거리가 얼마나 분리되어 있는지 나타내는 기법
  * - 덴드로그램(Dendrogram) : 트리 구조를 갖는 다이어그램인 덴드로그램을 활용한 시각화로
  * 군집의 개수 결정(덴드로그램 y축 : 군집과의 거리)
  * ② 밀도 기반 군집 분석(DBSCAN: Density-based spatial clustering of applications with noise)
  * ▶ 밀도 기반 군집 분석은 데이터 포인트(점)들이 밀집되어 밀도가 높은 부분을 군집화하는 방법이다
  * ▶ 밀도 기반 군집 분석은 특정 데이터를 중심으로 기준 거리 이내의 데이터 개수가 2개 이상 있을
  * 경우 이를 하나의 군집으로 인식하는 방식이다.
  * ▶ 밀도 기반 군집 분석은 K-평균 군집 분석과 다르게 군집의 수를 지정하지 않아도 되고, 밀도를
  * 기반으로 군집을 이루기 때문에 기하학적인 모양의 군집도 찾을 수 있다. 또한, 이상값 검출이
  * 가능하다.

  * 기하학적 : 기하학은 수학의 한 분야로서 도형의 성질과 공간의 구조를 다루는 학문이며 기하학적이라는 것은 도형이나 공간과 관련된 것을 의미한다.

### ② 앙상블 기법 (Ensemble)
복수의 약한 학습기(Weak Learner)들을 병렬/순차 결합해 뛰어난 단일 예측 성능을 수립하는 초강력 모형 결합 기법입니다.

| 구분 | 학습 방식 및 핵심 목적 | 대표적 알고리즘 / 모델 작동 원리 |
| :--- | :--- | :--- |
| **배깅<br>(Bagging)** | • 복원 추출 샘플링(**Bootstrap**)을 통해 여러 병렬 데이터셋 생성.<br>• 각 세트별 개별 모델을 독립 학습한 후 **평균(회귀)/다수결(분류) 취합**.<br>• 모델들의 **분산(Variance)을 대폭 감소**시켜 안정성 확보. | • **랜덤 포레스트 (Random Forest)**:<br>  - 부트스트랩 샘플링에 더해, 각 나무 노드 가중 분할 시 독립변수(특성)까지 무작위 샘플링하여 나무 간 상관성을 극도로 낮춘 안정적 모델.<br>  - **OOB (Out-of-Bag) 표본**: 부트스트랩 샘플링 시 선택받지 못한 약 36.8%의 데이터로, 검증 셋 없이 자체적인 일반화 오차 자체 검증에 활용 가능. |
| **부스팅<br>(Boosting)** | • 이전 단계의 약한 학습기가 저지른 오차(오답 샘플)를 가중 검출.<br>• 다음 학습기가 이 오답 샘플을 순차적(Sequential)으로 가중 학습.<br>• 모델의 **편향(Bias)을 크게 낮추어** 예측력을 최고조로 향상. | • **에이다부스트 (AdaBoost)**: 오분류한 샘플에 가중치를 주는 정석 모델.<br>• **그래디언트 부스팅 (GBM)**: 오분류 잔차(Residual)의 손실함수 음의 기울기를 다음 트리가 최적화하며 따라가는 초정밀 성능 모델. |
| **스태킹<br>(Stacking)** | • 서로 완전히 다른 이질적 다수 모델들의 예측 결과를 입력 특성으로 수립.<br>• 최종 **메타 모델(Meta Learner)**이 이 입력을 바탕으로 최종 학습 및 판정. | • **Base 모델 융합 + Meta 모델 결합** 기법. |

## 🛡️ 3. 서포트 벡터 머신 (SVM, Support Vector Machine)

데이터 집단들을 구분하는 최적의 결정 경계선인 **초평면(Hyperplane)**과 가깝게 맞닿은 데이터 포인트인 **서포트 벡터(Support Vector)** 간의 수직 거리인 **마진(Margin)**을 극대화하여 공간을 이분하는 알고리즘입니다.

> [!WARNING] 🚨 [초빈출 함정] 마진 규제 강도 $C$ 파라미터의 작동 원칙
> * **$C$ 파라미터**: 오분류(마진 침범)에 대해 얼마나 무거운 벌점(Penalty)을 가할 것인지 결정하는 인자.
> * **$C$ 가 극대화될 때 ($C \uparrow$)**: 오분류를 전혀 허용하지 않으려는 강박이 발생 ➡️ 결정 경계면이 구불구불해지며 마진 폭이 극도로 좁아짐 ➡️ **훈련 데이터에 대한 과대적합(Overfitting) 발생**.
> * **$C$ 가 극소화될 때 ($C \downarrow$)**: 오분류를 너그럽게 허용함 ➡️ 마진 폭이 넓어지며 결정 경계가 단순한 선형에 가깝게 직선화됨 ➡️ **모형의 과소적합(Underfitting) 발생 우려**.
> * **커널 가중치 Gamma ($\gamma$)**: RBF 커널 등에서 개별 데이터 포인트가 가지는 영향력의 거리 반경. **$\gamma \uparrow$ 이면 영향 반경이 극도로 좁아져 매우 불규칙하고 복잡한 결정 경계선이 유도**됩니다 (과대적합 유발).

## 📊 5. 비모수 통계 검정 (Non-parametric Test)

모집단의 정규성 분포 가정을 만족하지 못하거나 샘플 수($n < 30$)가 극히 부족할 때, 데이터의 **순위(Rank)나 부호(Sign)**를 치환해 가설을 검정하는 정밀한 분석 기법입니다.

| 분석 목적 (모수 검정 대비) | 대응되는 비모수 기법 | 귀무가설 ($H_0$)의 기준 수립 |
| :--- | :--- | :--- |
| **한 집단의 평균 vs 기준값 비교**<br>*(단일 표본 t-검정 대응)* | **부호 검정 (Sign Test)**<br>**윌콕슨 부호순위 검정** | $H_0: \text{모집단의 중위수}(\theta) = \text{기준 중위수}(\theta_0)$<br>• 순수 부호 검정은 대칭성 가정이 전혀 불필요해 이상치 영향 제로. |
| **서로 독립된 두 집단 비교**<br>*(독립 2표본 t-검정 대응)* | **윌콕슨 순위합 검정**<br>*(맨-휘트니 U 검정)* | $H_0: \text{두 집단의 중위수}(\theta_1) = \text{집단2 중위수}(\theta_2)$<br>• 두 집단 표본을 섞어 정렬해 순위를 매긴 후 순위합 통계량 검정. |
| **대응/짝지어진 집단 전후 비교**<br>*(대응표본 t-검정 대응)* | **윌콕슨 부호순위 검정** | $H_0: \text{전후 값들의 차이 중위수}(\theta_d) = 0$<br>• 차이의 절댓값 크기순으로 랭크를 매긴 뒤 원래 부호를 부착함. |
| **3개 집단 이상의 평균 비교**<br>*(일원배치 분산분석 ANOVA 대응)* | **크루스칼-왈리스 검정** | $H_0: \text{모든 집단(3개 이상)의 중위수는 동일하다.}$<br>• F-분포 대신 카이제곱($\chi^2$) 검정 통계량을 차용함. |
| **연속 관측값들의 무작위성 검정** | **런 검정 (Run Test)** | $H_0: \text{데이터(예: 연속된 부호, 값)의 배열은 완전히 임의적이다.}$<br>• 무작위 일관성을 테스트해 시계열의 노이즈 여부 등을 검출함. |

* 04 인공신경망
  * 1) 인공신경망(Artificial Neural Network, ANN)의 정의
  * ● 사람 두뇌의 신경세포인 뉴런이 전기신호를 전달하는 모습을 모방한 기계 학습 모델이다.
  * ● 인공신경망은 활성화 함수를 사용하고, 가중치를 알아내는 것이 목적이다.

  * 활성화 함수(Activation Function) : 입력 신호의 총합을 출력 신호로 변환하는 함수이다.
  * 퍼셉트론(perceptron) : 프랑크 로젠블라트가 1957년에 고안한 알고리즘이다. 이 퍼셉트론이 바로 신경망(딥러닝)의 기원이 되는 알고리즘이다.퍼셉트론은 다수의 신호(흐름이 있는)를 입력으로 받아 하나의 신호를 출력한다. 퍼셉트론은 이 신호를 입력으로 받아 '흐른다/안 흐른다'(1 또는 0)이라는 정보를 앞으로 전달한다.
  * XOR(Exclusive OR, 배타적 논리합) : XOR는 X, Y 중 하나만 1일 때 1이 출력되는 논리회로의 개념이다.
  * 기울기 소실(Gradient Vanishing) : 역전파(Backprogation) 과정에서 입력층으로 갈수록 기울기(Gradient)가 점점 작아
  * 지는 현상
  * 역전파 : 신경망의 각 노드가 가지고 있는 가중치(Weight)와 편향(Bias)을 학습시키기 위한 알고리즘으로, 딥러닝에 있어서 가장 핵심적인 부분이라고 할 수 있다.
