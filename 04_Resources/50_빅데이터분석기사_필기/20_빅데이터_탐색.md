# 데이터  전처리
2. 분석  변수  처리
변수  선택  방법
전진선택법  : 상관계수의  절댓값이  큰  것 ( 관련성  높음 ) 부터  하나씩  추가
후진제거법  : 모두  있는  상태에서  상관계수의  절댓값이  작은  것  부터  하나씩  제거
단계별  선택법  : 전진  + 후진  → 보완
차원축소
*차원의  저주 : 데이터  학습  시  차원이  높아질수록  알고리즘  성능이  저하됨
주성분  분석  (PCA) : 상관성  높은  변수의  선형  결합으로  차원  축소  & 새로운  변수  생성  ( 정방  행렬 )
고차원  데이터를  저차원으로  줄이면서도 , 데이터의  정보 ( 분산 ) 를  최대한  보존하는  방법
→ 데이터  속성들  간의  중복 ( 상관관계 ) 을  제거해서 ,
→ 새로운  축 ( 주성분 ) 을  만들고  이  축에  데이터를  투영하는  방식
→ 변수간  상관관계가  있을  시  유용함  / 정규분포를  반드시  가정  X  * 기출
→ 직교변환 (orthogonal transformation) 사용
요인분석 : 요인들을  회전시켜  데이터  내부  잠재  요인을  도출하고  구조를  해석하는  기법  
→ 독립 / 종속변수  구분  X / 기술  통계  기반  ( 공분산 , 상관계수 )
→ 변수들이  같은  요인끼리  묶이고 , 각 요인끼리는  서로  독립적 ( 직교 )
직각회전방식  - 요인들  사이  상관관계를  0으로  만들어  서로  독립적인  것으로  가정  (Varimax)
사각회전방식  - 요인들  사이  상관관계를  0 이  아닌  값으로  유지  (Promax, Oblimin)
다차원  척도법 : 개체  사이의  군집을  시각적으로  표현하는  방법
특이값  분해  (SVD) : MxN 크기의  비정방  행렬  분해
선형판별분석  & 독립성분분석
요약변수 & 파생변수
요약변수 : 수집된  정보를  종합하여  요약해  만든  변수   ex) 월  평균  기온
→ 주로  집계 (aggregate) 형태  / 전체  흐름이나  특성을  간단히  보여줄  수  있음
→ 다양한  분석에  공통으로  사용  가능  (재사용성  ↑)
→ 데이터  마트에서  가장  기본적인  변수
파생변수  : 기존  변수를  변형하거나  결합해서  새로운  변수를  생성한  것
ex) 성별  + 연령  = ‘중년  남성ʼ

→ 논리적  타당성이  중요  ( 왜  만들었는지  설명  가능  해야함 )
→ 분석  목표에  따라  달라짐  ( 유연성  ↑)
→ 머신머닝에서도  모델  성능  향상을  위해  사용
수치형 변수  변환
 Z-score 정규화  : 평균  0, 표준편차  1 로  변환
💫( 현재  값  - 평균 ) / 표준편차
 최소 - 최대  정규화
💫( 현재값 - 최소값 ) / ( 최대값 - 최소값 )
 로그  변환  - 한쪽으로  치우진  그래프
범주형 변수  변환
 레이블  인코딩  : 데이터를  단순  정수로  변환  (0, 1, 2…)
* 컴퓨터가  정수를  순서가  아닌  크기로  인식할  수  있음
 원 - 핫  인코딩  : 고유값  해당  칼럼만  1 로  표시 , 나머지는  0 으로  표시  ex) [0, 0, 1…
 타깃  인코딩  : 타깃  변수를  평균값으로  변환
불균형  데이터  처리
 가중치  균형  적용  : 불균형  데이터에  가중치를  줌
+) 비용민감학습  : 소수  클래스에  더  많은  가중치를  줌으로써  예측  정확도  향상  ( 모든  클래스의  중요도가  동일하지  않은  경우에  사
용 )
 언더샘플링  : 다수  데이터를  일부만  선택
 오버샘플링  : 소수  데이터를  복사해서  수를  늘림
*SMOTE  가상  직선을  활용해  소수  클래스  데이터를  합성하는  오버샘플링  기법

## Q1.
결측치(Null) 메커니즘 중 비무작위 결측(NMAR, Non-Random)에 대한 설명으로 가장 적절하지 않은 것은?

## Q3.
IQR(Interquartile Range) 기반 이상치 탐색 시, Q1−1.5×IQR 및 Q3+1.5×IQR 경계식을 통과하는 한계 범위 설정에 대한 통계학적 연계 원리로 가장 올바른 것은?

* ① 정규분포를 따르는 단일 분포 데이터셋에서 전체 데이터의 약 99.73% 영역을 이상치 경계선 외부로 영구 퇴출하는 수식이다.
* ② 데이터가 정확히 대칭적인 정규분포를 따를 경우, ±1.5는 대략 평균으로부터 양방향 ±2.7σ(표준편차) 이탈 범위를 감지하는 기하학적 임계값이다.
* ③ 표본의 크기가 무한히 증가할 때 모수적 가정이 없는 비모수 검정의 중심극한정리를 유도하기 위한 상수 수식이다.
* ④ IQR 연산은 데이터가 극단적 이상치에 밀려 크게 요동치므로, Z-Score 대비 이상치 왜곡에 극도로 약하다는 한계를 지닌다.

▶ 클릭하여 정답 및 해설 확인* **정답**: ②* **상세 해설**: 데이터가 정규분포 N(μ,σ2)를 따를 때, 제1사분위수 Q1은 대략 −0.675σ, 제3사분위수 Q3은 +0.675σ 부근에 위치합니다. 따라서 IQR=Q3−Q1≈1.35σ가 됩니다. 이를 식 Q3+1.5×IQR에 대입하면 $0.675\sigma + 1.5 \times 1.35\sigma \approx 2.698\sigma$가 됩니다. 즉, IQR 1.5배 한계선 방식은 정규분포 상에서 평균으로부터 양방향 약 ±2.7σ 이탈 경계를 통제하는 견고한 통계적 연계 당위성을 가집니다.* **오답 피드백**:* ①번: 전체 데이터의 $99.73%영역을이상치경계선′내부′로유지하는기준은모수적방법인3−SigmaRule(\pm 3\sigma$)입니다.* ③번: 해당 상수는 단순 중심극한정리와 관련이 없으며 백분위수의 대칭 분포 관측에 따른 경험론적 수치입니다.* ④번: IQR 방식은 비모수적 사분위수(중앙값 기준)를 취하므로 평균을 취하는 Z-Score 대비 극단적 이상치의 폭탄 영향을 받지 않는 매우 '강건한(Robust)' 이상치 대안 기술입니다.

## Q4.
고차원 다변량 데이터 공간에서 소수 이상 관측치를 통계적으로 분리 및 정제하는 비지도 학습 알고리즘들에 대한 설명으로 올바르게 연결되지 않은 것은?

* ① DBSCAN: 밀도 기반 탐색을 수행하며, 핵심 구역 최소 밀도 조건을 충족하지 못하고 무리에 귀속되지 않는 관측치를 잡음(Noise) 포인트로 고립 격리한다.
* ② Isolation Forest: 다차원 특징 공간을 완전 무작위 평면 분할하는 이진 트리를 수없이 만들 때, 경로 길이(Path Length)가 평균보다 길어 깊이가 깊은 객체를 이상치로 분류한다.
* ③ DBSCAN 한계: 데이터 차원이 기하급수적으로 늘어날 경우 유클리드 거리 붕괴(차원의 저주)로 인해 밀도 분포 식별력이 극도로 왜곡된다.
* ④ Isolation Forest 장점: 데이터가 정규성이나 특정 분포의 선형성을 전혀 띄지 않는 복잡한 기하 구조를 갖고 있더라도 비모수적으로 고속 탐지가 가능하다.

▶ 클릭하여 정답 및 해설 확인* **정답**: ②* **상세 해설**: Isolation Forest(고립 의사결정 나무)는 다수 클래스는 군집화되어 있어 공간을 무작위로 계속 분할해야 겨우 분리(경로의 깊이가 깊어짐, Path Length 증가)되는 반면, 소수 이상치(Outlier)는 밀집 무리에서 멀리 동떨어져 있으므로 단 몇 번의 공간 이진 분할만으로도 쉽게 격리(경로의 깊이가 매우 얕아짐, Path Length 감소)된다는 기하학적 특성을 이용합니다. 따라서 평균 경로 깊이가 극도로 '짧은(얕은)' 관측치(s→1)를 이상치로 진단하여 고립시킵니다.* **오답 피드백**:* ①번: DBSCAN 알고리즘의 노이즈 탐지 원리 표준 정의입니다.* ③번: 밀도(거리 기반) 탐색 알고리즘들은 고차원으로 갈수록 빈 공간이 기하급수적으로 팽창하여 작동이 정지되는 한계를 보입니다.* ④번: 트리 구조 기반 비지도 기법으로 차원의 저주로부터 비교적 자유롭고 가벼운 메모리만 소모합니다.

## Q5.
독립 변수 변환 시 변수 스케일링(Scaling) 기법들에 대한 설명으로 옳지 않은 것은?

* ① SVM, K-NN, K-Means 알고리즘은 내부 거리 척도를 쓰므로 특징들의 스케일 캘리브레이션 조정 유무가 정밀도에 생명선 역할을 한다.
* ② Min-Max Scaling은 전체 데이터를 [0,1] 범위로 일정 비율 압축하지만, 데이터 내에 극단적인 이상치 폭탄이 존재할 경우 스케일 자체가 우하향 쏠림 축소되는 왜곡에 취약하다.
* ③ **Standardization (Z-Score)**은 변형 후 평균 0, 분산 1.5인 표준 정규성을 띠도록 데이터를 수학적으로 일괄 재구성한다.
* ④ 랜덤 포레스트(Random Forest)나 그레디언트 부스팅(XGBoost, LightGBM)과 같은 트리 구조 기반 모델은 변수 간 스케일 격차에 성능이 지배되지 않는다.

▶ 클릭하여 정답 및 해설 확인* **정답**: ③* **상세 해설**: 표준화(Standardization)를 거친 가공 데이터의 통계적 평균은 정확히 0, 분산(Variance)과 표준편차(σ)는 완벽히 1.0으로 수렴 고정됩니다. (1.5 분산 유도는 명백한 수학적 에러입니다.)* **오답 피드백**:* ①번: 거리 함수를 수식 내에 탑재하는 모델들은 스케일링을 생략할 경우 스케일이 큰 거대 변수(예: 자산, 연봉)에 모델 학습 가중치가 수렴 왜곡되는 치명적 사태를 맞이합니다.* ②번: Min-Max 공식은 분모에 Xmax−Xmin을 가지므로 이상치 하나가 비정상적으로 거대하면 대다수 일반 관측치가 0 부근에 지나치게 수축 적재됩니다.* ④번: 트리 계열 알고리즘은 변수의 단순 단조 단일 분할(Single Split) 축 대소를 평가하므로 스케일링 전후의 분할 평면 성능 차이가 이론적으로 완벽히 동일합니다.

## Q6.
왜도(Skewness)가 오른쪽 꼬리 왜곡 형태(Skewness>0, 우측으로 길게 늘어짐)인 비대칭 관측 변수에 로그(Log) 변환을 적용하여 정규성을 수립하는 수학적 작동 원리에 대한 설명으로 가장 타당한 것은?

* ① 큰 관측값들의 스케일 차이는 급격히 축소하고, 작은 영역대 오밀조밀한 값들 간의 물리적 간격은 상대적으로 넓히는 비선형 단조 변환 효과이다.
* ② 선형 덧셈 관계를 곱셈 확률적 비선형 관계로 환산하여 음수와 양수를 공간상에서 대칭 축 회전하는 메커니즘이다.
* ③ 독립 변수와 종속 변수 간의 비선형적인 지수적 복잡도를 선형 미분 공간으로 투영하는 무한 차원 매핑 효과이다.
* ④ 양 극단치의 비대칭 밀도를 통계적 유의수준 α=0.05 기준 안으로 전부 제거하여 결측으로 치환하는 파괴적 기법이다.

▶ 클릭하여 정답 및 해설 확인* **정답**: ①* **상세 해설**: 왜도가 오른쪽 꼬리 왜곡 형태(오른쪽에 이상치가 몰려 평균이 중앙값보다 높음)인 데이터에 y=log(x) 비선형 변환을 적용하면 다음과 같이 작동합니다. 로그 함수는 입력값이 작을 때는 기울기가 급해 세밀하게 영역 간 차이를 구별하는 반면, 입력값이 커질수록 기울기가 완만하여 거대 수치 간 격차를 극도로 평평하게 수축시킵니다. 따라서 우측 꼬리에 넓게 흩뿌려진 큰 이상치들이 중앙 쪽으로 꽉 눌려 들어와 비대칭 왜도가 깔끔한 대칭 종형 정규분포로 캘리브레이션 교정됩니다.* **오답 피드백**:* ②번: 부호의 선형 관계를 바꾸는 목적이 아니며 왜도 조정에 직접 관여하지 않는 억지 설명입니다.* ③번: 무한 차원 매핑은 커널 트릭(Kernel Trick, 예: RBF Kernel)에 대한 정의입니다.* ④번: 데이터의 물리적 실존값을 지우거나 버리지 않고 스케일 궤적만 부드럽게 조정하는 비선형 보존 방식입니다.

## Q7.
차원 축소 비지도 학습의 대표 주자인 PCA(주성분 분석)의 수학적 공분산 축 회전 아키텍처 및 주성분(PC) 결정 원리로 올바르지 않은 것은?

* ① 원본 변수 공간의 상관관계가 있는 변수 벡터들을 직교 회전하여 서로 공분산 관계가 완전 무결한 독립(Cov(PCi,PCj)=0)이 되도록 신설 주성분 축을 유도한다.
* ② 공분산 행렬 Σ를 고유값 분해(Eigendecomposition)하여 획득한 고유벡터($Eigenvector$)들이 데이터 투영의 최대 회전 방향(PC)을 상징한다.
* ③ 스크리 플롯(Scree Plot)에서 스크리 계선 곡선이 수평을 향해 급격히 누우며 꺾이는 변곡점(Elbow Point) '이후' 단계의 대다수 고유값 성분들을 주성분으로 채택한다.

## Q10.
데이터 불균형 복원을 위해 데이터 생성 공간을 수리 보간하는 오버샘플링(Over-sampling) 계열 알고리즘들에 대한 설명으로 옳지 않은 것은?

* ① SMOTE: 단순 복제 가산의 과적합 단점을 극복하기 위해 소수 데이터 xi와 인접 K-최근접 이웃 xknn 간의 선형 가상 경로 궤적 상에 난수 보간을 얹어 완전히 새로운 가짜 합성 관측치를 생성한다.
* ② Borderline-SMOTE: 소수 클래스 주변 K-NN에 속한 다수 클래스의 개수 비율을 진단하여, 다수 클래스 비중이 절반 이상을 완전히 지배하는 경계 위험 영역인 'Danger' 등급 소수 관측치만을 표적 추적하여 집중 오버샘플링을 뿜어낸다.
* ③ ADASYN: 다수 클래스 밀도가 너무 빽빽하게 밀집되어 분류 경계를 모형이 구분하기 힘든 극악의 학습 난제 소수 클래스 공간 영역을 추적하여, 해당 구역에 가중치를 부여해 다량의 데이터를 더욱 압도적으로 집중 밀집 투하한다.
* ④ SMOTE 한계: 기하학적 선형 보간 경로 상에 합성 데이터를 만들기 때문에, 다차원 특징 공간에서 소수 클래스 변수의 주변에 이상치가 존재할 경우 데이터 공간 내 왜곡된 영역까지 오버샘플링을 뻗어 결합 노이즈를 심각하게 증폭시키는 약점을 노출할 수 있다.

▶ 클릭하여 정답 및 해설 확인* **정답**: 없음 (모든 보기의 설명이 완벽히 올바름)* **상세 해설**: 출제 오류나 함정 방어를 위해 10번 문항은 **모든 보기(①, ②, ③, ④)의 작동 메커니즘과 학술적 이론 정의가 100% 무결하고 완벽하게 기술된 명품 선지 세트**입니다.* **SMOTE 수식**: xnew=xi+rand(0,1)×(xknn−xi) 작동 논리* **Borderline-SMOTE의 3대 등급 분류 규칙**:* **Safe**: 이웃 중 소수 클래스가 다수 (오버샘플링 불필요)* **Danger**: 이웃 중 다수 클래스가 절반 이상 다수 (오버샘플링 핵심 대상)* **Noise**: 이웃 전체가 다수 클래스로 둘러싸인 외톨이 고립 객체 (오버샘플링 제외 대상)* **ADASYN**: 정밀한 다수 클래스 주변 조건 확률 비중 가중 생성 시스템* **SMOTE의 기하학적 선형 노이즈 확장 취약점**까지 완벽하게 정론을 가리키고 있습니다. 이 개념 전반을 온전히 체득해 가시기 바랍니다.
