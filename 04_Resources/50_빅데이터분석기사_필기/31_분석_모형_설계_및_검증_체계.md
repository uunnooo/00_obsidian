# 3-1. 분석 모형 설계 및 검증 체계

## 🚫 2. 분석 모형 설계 시 주의점 및 오류 현상

분석 모형 설계가 부적합할 때 다음과 같은 **부적합 모형 현상**이 발생합니다:
* **모형 선택 오류**: 실제 데이터 관계가 비선형인데 선형 모형을 채택하는 등의 구조적 가설 설정 오류.
* **변수 누락**: 종속변수에 결정적인 영향을 미치는 주요 독립변수가 모형 설계에서 누락되는 현상 (편향 발생).
* **부적합 변수 생성**: 무관하거나 상관성이 지극히 낮은 변수를 모형에 주입하여 무작위 노이즈가 학습되는 현상.
* **동시 편향 (Simultaneity Bias)**: 독립변수가 종속변수에 영향을 주는 동시에, 종속변수도 독립변수에 영향을 미쳐 인과관계의 선후가 꼬이는 현상.

## 🛠️ 3. 분석 모형 개발 및 운영 검증 프로세스

> [!INFO] **교안 상세 보강 (3. 분석 모형 설계 – 분석 절차 수립)**
* 1) 통계기반 분석 모형 선정
  * ③ 상관분석(Correlation Analysis)
  * ▶ 두 개 이상의 변수 사이에 존재하는 상호 연관성을 분석하는 방법으로 상관계수(r)를 이용하여
  * 상관관계를 분석한다.
  * ④ 회귀 분석(Regression Analysis)
  * ▶ 하나 이상의 독립변수(X)가 종속변수(Y)에 끼치는 영향을 수치적으로 추정하는 통계 방법이다.
  * 예) 흡연량에 따른 폐암 발병률 연구
  * ⑤ 인과관계 분석(Causality Analysis)
  * ▶ 독립변수(X)와 종속변수(Y) 간의 인과관계를 분석하는 방법이다.
  * ⑥ 분산 분석(ANOVA, Analysis of Variance)
  * ▶ 서로 다른 집단의 평균에서 분산값(총 평균과 각 집단 간의 평균 차이에 의해 생긴 분산)을 비교
  * 하여 집단 간의 통계학적 차이를 확인하는 방법이다.
  * ⑦ 주성분 분석(PCA, Principal Component Analysis)
  * ▶ 기존 데이터의 분포를 최대한 보존하면서 고차원 공간의 데이터들을 저차원 공간으로 변환하는
  * 방법이다.

> [!INFO] **교안 상세 보강 (3. 분석 모형 설계 – 분석 절차 수립)**
* 2) 데이터 마이닝 기반 분석 모형 선정
  * ● 데이터 마이닝(Data Mining)이란 많은 양의 데이터 속에서 데이터의 패턴, 규칙 등을 탐색하고,
  * 통계기법을 활용하여 분석한 뒤, 이러한 분석을 기반으로 가치 있는 정보를 추출하는 과정을 의미한다.
  * ● 데이터 마이닝 기반 분석 모델에는 분류 모델, 예측 모델, 군집화 모델, 연관규칙 모델이 있다.
  * ① 분류 모델(Classification)
  * ▶ 다수의 속성을 갖는 객체들을 사전에 정해진 그룹 중 하나로 분류하는 기법이다.
  * 예) 통계적 기법, 트리 기반 기법, 최적화 기법, 기계학습 모델
  * ② 예측 모델(Prediction)
  * ▶ 과거 데이터로부터 데이터의 특성을 분석하여 다른 데이터의 결과값을 예측하는 기법이다.
  * 예) 회귀 분석, 의사결정나무, 시계열 분석, 인공신경망

  * 의사결정나무(Decision Tree) : 데이터를 분석하여 이들 사이에 존재하는 패턴을 예측 가능한 규칙들의 조합으로 나타내는
  * 모형으로 그 모양이 나무와 비슷하여 의사결정 나무라고 부른다.
  * 인공신경망(Artificial Neural Network, ANN) : 사람 두뇌의 신경세포인 뉴런이 전기신호를 전달하는 모습을 모방한 기계 학습 모델이다. 인공신경망은 활성화 함수를 사용하고, 가중치를 알아내는 것이 목적이다.

> [!INFO] **교안 상세 보강 (3. 분석 모형 설계 – 분석 절차 수립)**
* 2) 데이터 마이닝 기반 분석 모형 선정
  * ③ 군집화 모델(Clustering)
  * ▶ 관측된 여러 개의 변숫값에서 유사한 성격을 갖는 몇 개의 군집으로 그룹화하여 그룹들 사이의
  * 관계를 분석하는 다변량 분석기법이다.
  * 예) 계층적 방법 : 병합적 방법, 분할적 방법
  * 비계층적 방법: K-평균군집
  * ④ 연관규칙 모델(Association Rule)
  * ▶ 주어지는 데이터에서 동시에 발생하는 사건 혹은 항목 간의 규칙을 수치화하는 기법으로 장바구니
  * 분석이라고도 하며, 주로 마케팅 분야에서 활용된다.
  * 예) 우유를 구입한 고객이 식빵을 함께 구입한 경우

  * K-평균 군집 분석(K-means clustering) : 주어진 데이터를 K개의 군집으로 묶는 알고리즘으로 군집수를 K개큼 초깃값으로 지정하고, 각 객체를 가까운 초깃값에 할당하여 군집을 형성하는 방법이다. 각 군집의 평균을 재계산하여 초깃값을 갱신하
  * 는 과정을 반복하여 K개의 최종 군집을 형성한다.
  * 다변량 분석(Multivariate analysis) : 여러 현상이나 사건에 대한 측정치를 개별적으로 분석하지 않고 동시에 한번에 분석 하는 통계적 기법을 말한다.

### ① 분석 모형 구축의 정석 7단계 (필수 암기 ⭐)
분석 요건 정의부터 최종 배포까지 수립되는 정밀 순서입니다.
$$\text{문제 및 평가지표 정의} \longrightarrow \text{데이터 분할} \longrightarrow \text{전처리} \longrightarrow \text{후보모형 학습} \longrightarrow \text{검증 및 튜닝} \longrightarrow \text{최종모형 선정} \longrightarrow \text{테스트 및 해석}$$

> [!WARNING] 🚨 [초빈출 함정] 테스트 데이터의 오염 및 낙관 편향
> * **개념**: **테스트 데이터(Test Set)는 오직 최종 일반화 성능 확인용으로만 딱 1번 사용**되어야 합니다.
> * **함정**: 모델 학습 및 하이퍼파라미터 튜닝(검증 단계) 시 테스트 데이터를 반복적으로 사용(참조)하면, 테스트 데이터 역시 모델 피팅 과정의 일부로 녹아들어 사실상의 검증 데이터(Validation Set)로 변질됩니다.
> * **결과**: 최종 평가 성능이 비정상적으로 **낙관적으로 편향(Optimistic Bias)**되어, 실제 배포 운영 시 심각한 성능 저하가 초래됩니다.

  * ▶ 정답인 레이블(Label)이 포함된 학습 데이터를 통해 컴퓨터를 학습시키는 방법이다.

  * ③ 강화 학습(Reinforcement Learning)
  * ▶ 컴퓨터가 선택 가능한 행동(Action) 중 보상(Reward)을 최대화하는 행동을 선택하도록 하는 학습
  * 방법이다.

### ② 데이터 분할 (Data Split)
모형의 **과대적합(Overfitting) 예방**과 일반화 성능 향상을 위해 전체 수집 데이터를 아래의 3대 구역으로 엄격히 분할하여 사용합니다.

```
┌────────────────────────────────────────────────────────┐
│                      전체 데이터                       │
└────────────────────────────────────────────────────────┘
       │                      │                      │
┌──────────────┐       ┌──────────────┐       ┌──────────────┐
│  학습 데이터 │       │  검증 데이터 │       │  평가 데이터 │
│  (Training)  │       │ (Validation) │       │    (Test)    │
│   60 ~ 80%   │       │   10 ~ 20%   │       │   10 ~ 20%   │
└──────────────┘       └──────────────┘       └──────────────┘
```

* **학습용 데이터 (Training Set, 60~80%)**:
  * 모형의 가중치(Weight)와 편향(Bias) 매개변수를 직접 학습시키는 데 사용됩니다.
* **검증용 데이터 (Validation Set, 10~20%)**:
  * 학습 과정 중간에 오버핏 여부를 진단하고, 에폭(Epoch) 중단점 결정 및 **하이퍼파라미터(Hyperparameter)** 튜닝에 사용됩니다.
* **평가용 데이터 (Test Set, 10~20%)**:
  * 모델 설계, 가중치 학습, 튜닝 전 과정에서 **단 한 번도 노출되지 않은 순수한 데이터**로, 최종 일반화 성능을 정량 평가하는 데 사용됩니다. (과적합 및 제2종 오류 예방의 최후 보루)

  * ▶ 주어지는 데이터에서 동시에 발생하는 사건 혹은 항목 간에 규칙을 수치화하는 기법으로 ‘장바구니 분석’이라고
