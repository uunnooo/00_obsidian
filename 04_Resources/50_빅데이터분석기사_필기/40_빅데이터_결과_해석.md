## 📝 2. 과목 종합 핵심 요약 (Master Summary)
순환  신경망 (Recurrent Neural Network, RNN): 순차적  데이터 ( 시계열  데이터 ) 학습에  특화  
이전  입력을  기억하여  현재  입력과  함께  처리
문장 , 주가 , 날씨 , 음성 , 필기체  등  순서가  중요한  데이터에  활용
단점  : 장기의존성 오래된  정보는  잘  기억하지  못함
⇒ LSTM / GRU 모델 (Reset, Update) 로  극복
오토인코더 : 입력  데이터를  인코더로  압축한  후  디코더로  재구성하는  비지도  학습  신경망  비지도학습
텍스트  마이닝  - 문자  데이터도  분석할  수  있음
통계적  기반
 TDM  문서에서  등장하는  단어들의  빈도를  행렬로  표현
 TFIDF  단어  등장  빈도를  특정  문서 , 전체  문서에서  비교하는  것
단어  수준  기반
 Word2Vec : 거리를  기반으로  하여  벡터로  표현  ~ CBOW, Skip-Gram
 FastText : 하나의  단어를  여러  개로  잘라서  벡터로  계산
 ELMo : 양방향  언어  모델  적용
트랜스포머  : RNN 의  느린  속도와  병렬  처리  불가  단점을  개선한  모델  (BERT, GPT)
앙상블  분석 : 여러  개의  예측  모형들을  조합  → 전체적인  분산을  감소시켜  성능  향상
⇒ 혼자보다  같이가  낫다 ! ⇒ 여러개  예측  모형  ⇒ 전체적인  분산  감소
 보팅 : 다수결  방식
 배깅 : 복원추출하는  붓스트랩으로  학습  후  보팅으로  결합 / 데이터  무작위  추출  + 병렬  학습

# 분석모형  평가  및  개선
1. 분석모형  평가
분류모델  평가지표
 ⭐ 혼동행렬 ( 오분류표 )
재현율 (Recall) = 민감도 (sensitivity) = TP Rate  Hit Rate
F1 Score 는  정밀도 (Precision) 와  재현율 (Recall) 의  조화평균
특이도 (Specificity) : 실제  False 인  것  중  맞춘  것

정밀도와  재현율은  Trade-off 관계
 ROC 커브
가로축  = 1- 특이도  (=FP Rate), 세로축  = 민감도
면적이  1 에  가까울수록  성능  좋다고  평가
 이익  도표 (Lift Table)
불균형  데이터  집합에  사용 , 성과  향상도를  각  등급별로  파악할  수  있음
향상도  곡선  : 이익도표를  시각화한  곡선
회귀모델  평가지표
 손실함수 ( 비용함수 ) : MSE, MAE, RMSE… 등
 결정계수 (R square) → 0~1 사이  값
군집분석  평가지표
⇒ 군집  내  유사 , 군집  간  분리
 실루엣  계수
실루엣  지표가  1 에  가까울수록  잘  된  군집화  (0.5 보다  크면  타당한  것으로  평가 )
 Dunn Index(DI) : 클수록  군집화  잘  되었다고  평가
교차  검증
 홀드아웃  : 훈련용 , 평가용  데이터셋  분리
 K-fold 교차검증  : 데이터를  k 개  집단으로  구분하여  k-1 개  학습 , 나머지  1 개로  평가
 LOOCV  1 개의  데이터로만  평가 , 나머지로  학습
 붓스트랩  : 복원추출  ( 데이터  부족과  불균형  문제  해소 )
적합도  검정  
 QQ plot : 데이터  정규성을  시각적으로  파악  ( 대각선  선을  따라  값들이  분포하면  정규성  만족 )
 카이제곱  검정
 샤피로  윌크  검정  : 선형상관관계를  측정하여  검정 , p-value 0.05 보다  크면  정규성  가정
 콜모고로프 - 스미르노프  검정  : 누적  분포함수  비교한  연속형  데이터  검정 , p-value 0.05 보다  크면  정규성  가정
2. 분석모형  개선
하이퍼  파라미터
 경사하강법  : a 가  너무  크면  값이  높은  곳으로  발산 , 너무  작으면  오랜  시간이  걸림
 Batch Size : 하나의  소그룹에  속하는  데이터  수
Epoch - 모든  데이터셋을  학습하는  횟수
Iteration  Epoch 를  한  번  마치기  위해  필요한  배치  수
하이퍼파라미터  튜닝
: 메뉴얼  서치 ( 경험  또는  감으로  설정 ), 그리드  서치 , 랜덤  서치 , 베이지안  최적화  ( 기존  평가  결과를  활용 )
경사하강법  옵티마이저

 확률적  경사  하강법  : 기울기가  가장  작은  지점에  도달하도록  함
 모멘텀  : 관성  물리법칙  적용 , 빠른  최적점  수렴  가능
 AdaGrad : 기울기  크기에  따라  학습률을  조정  / 처음엔  크게  → 점차  작게  학습

• 귀무가설 (H₀): 기본  주장  (“ 차이  없다 ˮ, “ 변화  없다 ˮ)

• 임계값: 기각역의  경계값
• 유의수준 (α): 1 종  오류  허용  한계  ( 보통  0.05)
📌  오류  구분

## Q6.

* 정답 공식 해설:버블 차트에서 시각적 착시와 왜곡을 차단하려면 버블의 **면적(Area, A)**이 데이터의 크기(V)에 정확히 비례해야 합니다.

* r = C * sqrt(V) (C는 비례 상수)
* 데이터 크기(V)가 9배 증가했다면, 반지름 r은 sqrt(9) = 3배만 증가시켜야 면적이 정확하게 9배 비례하여 확장됩니다.
* 만일 반지름 r을 데이터의 크기와 똑같이 9배로 키워버리면, 버블의 면적은 9^2 = 81배로 기하급수적으로 부풀어 올라 심각한 시각적 과장 왜곡이 유발됩니다. 따라서 반지름은 3배로 키워야 하므로 정답은 ①번입니다.
* 오답 분석:② 4.5배는 수치 9를 단순 반으로 나눈 무의미한 오류 수치입니다.

## Q7.
A 기업의 데이터 분석팀이 새로운 고객 예측 분석 시스템 도입을 추진하고 있다. 시스템 구축을 위한 총소유비용(TCO)은 100억 원이고, 향후 1년간 시스템 가동을 통해 발생할 것으로 기대되는 현재 가치 기준의 총현금 유입액은 125억 원이다. 분석 프로젝트의 투자대비효과(ROI)를 백분율 단위로 정확하게 산출한 결과는?

① 15%② 20%③ 25%④ 125%

* ▶ 클릭하여 정답 및 해설 확인정답: ③
* 정답 공식 해설:투자대비효과(ROI)를 계산하는 정품 공식은 다음과 같습니다.
* ROI = ( 순이익 / 총소유비용(TCO) ) * 100
* 여기서 순이익은 현재 가치 기준 총현금 유입액 - 총소유비용(TCO)으로 구합니다.
* 순이익 = 125억 원 - 100억 원 = 25억 원
* 공식에 대입하면 다음과 같습니다.
* ROI = ( 25억 원 / 100억 원 ) * 100 = 0.25 * 100 = 25%
* 따라서 올바르게 연산된 ROI는 25%이므로 정답은 ③번입니다.
* 오답 분석:① 15%는 순이익 계산이나 나눗셈 오류 시 산출되는 수치입니다.
* ② 20%는 순이익 25억 원을 총소유비용이 아닌 총유입액 125억 원으로 나누는 오류를 범했을 때 도출되는 오답입니다 (25 / 125 = 20%).
* ④ 125%는 순이익이 아닌 총현금 유입액 자체를 TCO로 나누어 백분율을 매겼을 때 산출되는 전형적인 수식 해석 오류입니다.

## Q8.
데이터 팀은 분석 인프라 확장을 위해 클라우드 GPU 노드를 신규 도입하려 한다. 초기 투자 금액은 200억 원이며, 사내 기준 할인율은 연 r = 10%이다. 도입 1년 후(t = 1) 총 242억 원의 단일 현금 유입이 단 한 번 발생할 것으로 예측될 때, 이 GPU 도입 프로젝트의 순현재가치(NPV)는 얼마인가?

① NPV = 0원② NPV = 20억 원③ NPV = 42억 원④ NPV = 220억 원

* ▶ 클릭하여 정답 및 해설 확인정답: ②
* 정답 공식 해설:순현재가치(NPV)를 연산하는 정품 공식은 다음과 같습니다.
* NPV = [ 현금유입_1 / (1 + r)^1 ] - 초기 투자 비용
* 문제에서 현금유입_1 = 242억 원, 할인율 r = 10% (0.1), 초기 투자 비용 = 200억 원이므로 공식에 값을 대입합니다.
* 현금유입의 현재 가치 = 242 / (1 + 0.1) = 242 / 1.1 = 220억 원
* NPV = 220억 원 - 200억 원 = 20억 원
* 최종 도출된 NPV가 20억 원(NPV > 0)이므로 실질적인 이득을 가져다주는 프로젝트로 판단할 수 있습니다. 따라서 정답은 ②번입니다.
* 오답 분석:① NPV = 0원은 내부수익률(IRR)이 사내 할인율과 동일하여 현재가치 합이 초기 금액과 같아질 때 도출되는 특수 케이스로 본 문항에서는 오답입니다.
* ③ NPV = 42억 원은 미래 가치 242억 원에서 1년 동안의 가치 하락에 따른 할인율(10%) 적용 없이 단순 차감 연산을 수행했을 때 저지르는 오류입니다 (242 - 200 = 42).
* ④ NPV = 220억 원은 현금유입의 현재 가치 금액 자체를 순현재가치로 혼동하여 초기 투자금을 차감하지 않은 수치입니다.

## Q9.
A 프로젝트를 승인할 것인지 기각할 것인지 결정하기 위해 의사결정 나무(Decision Tree) 분석 모델을 가동하여 기대가치(Expected Value)를 산정하려 한다. 프로젝트 진행 시 성공 확률은 70%(0.7)이고 이로 인한 순경제적 가치(이익)는 100억 원이다. 실패할 확률은 30%(0.3)이고 이때 손실액(마이너스 가치)은 50억 원이다. 이 의사결정 대안의 최종 기대가치(Expected Value)는 얼마인가?

① 35억 원② 50억 원③ 55억 원④ 70억 원

* ▶ 클릭하여 정답 및 해설 확인정답: ③
* 정답 공식 해설:의사결정 기대가치(EV)는 각 시나리오의 발생 확률과 발생 시 누리는 경제적 순가치를 곱한 후 총합하여 도출합니다.
* Expected Value = sum( 시나리오 확률 * 시나리오 순경제적 가치 )
* 성공 시나리오 기대가치: 0.7 * 100억 원 = 70억 원
* 실패 시나리오 기대가치: 0.3 * (-50억 원) = -15억 원
* 최종 의사결정 기대가치: 70억 원 + (-15억 원) = 55억 원
* 따라서 최종 계산된 대안의 순기대가치는 55억 원이 되므로 정답은 ③번입니다.
* 오답 분석:① 35억 원은 성공 확률 70%에 실패 시 손실액 50억 원을 잘못 곱하여 도출한 산출오류치입니다 (0.7 * 50 = 35).
* ② 50억 원은 성공 가치와 실패 가치의 단순 평균값을 산출한 무의미한 결과입니다.
* ④ 70억 원은 실패 시 시나리오 가치 하락의 마이너스 영향력을 합산 시 누락하고 성공 기대가치만 단독으로 산출한 오류입니다.

## Q10.
다음 중 데이터 분석과 결과 보고서 작성 시 중요하게 준수해야 하는 MECE(상호배제, 전체포괄)의 논리적 규칙 및 속성에 대한 설명으로 가장 적절하지 않은 것은?

① MECE는 전개하는 여러 논리적 카테고리들 간의 교집합(중복)이 단 하나도 없고, 합집합(전체)은 문제의 본질 전체를 고스란히 담아내는 이상적인 논리 구조 기법이다.② 사내 고객 연령대를 "20대 이하, 20대~30대, 40대 이상"으로 분류하는 보고서 레이아웃 구조는 완벽한 MECE 분류에 부합한다.③ MECE 원칙을 보고서 기획 및 피라미드 하위 논거 구성에 엄격하게 대입하면, 중요 사업 영역의 기획적 누출이나 동일 아이디어의 지루한 중복 제안을 완벽히 차단할 수 있다.④ MECE 프레임워크는 논리적 모순이 없는 깔끔한 문서 설계 체계를 보증하지만, 비즈니스 아이디어 수립 시 기계적 분류에만 너무 집착하면 창의적이고 유연한 대안 도출을 방해할 수 있다.

* ▶ 클릭하여 정답 및 해설 확인정답: ②
* 정답 공식 해설:MECE의 핵심은 "중복 없고 누락 없이" 전체를 아우르는 구조적 분류입니다.

* 오답 분석:① MECE 기법의 사전적 정의이자 벤 다이어그램상의 수학적 규칙을 정합성 있게 서술한 내용이 맞습니다.
* ③ MECE를 프로젝트 기획에 대입하면 중복 연산(리소스 낭비)과 누출(기회 손실)을 완전 무결하게 방지할 수 있습니다.
* ④ 기계적인 수치 분할에 매몰되면 비즈니스가 가질 수 있는 독창적 파생 아이디어나 예외적인 전략적 도메인 발굴 기회를 놓칠 우려가 있다는 학술적 비판이 실제로 존재합니다.
