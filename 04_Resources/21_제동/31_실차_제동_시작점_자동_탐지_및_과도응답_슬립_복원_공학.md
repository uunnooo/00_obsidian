# 🛑 31_실차 제동 시작점 자동 탐지 및 과도응답 슬립 복원 공학

> [!ABSTRACT] 📑 공학 개요
> 본 문서는 실차 제동(Braking) 시험 시 관습적인 고정 차속 컷오프(Fixed Velocity Cutoff)로 인해 발생하는 **제동 초기 과도 구간(Transient Phase) 결손 및 슬립 곡선 외삽 왜곡**을 극복하기 위해, GPS 및 가속도 시계열의 **3중 노이즈 방어 기반 브레이크 시작점 자동 역추적 알고리즘**과 **초기 슬립율 램프업(Slip Ratio Ramp-up) 복원 이론**을 체계화한 영구 제동 공학 기술 백서입니다.

---

## 🧭 1. 문제 정의: 고정 속도 컷오프의 치명적 결함

### 1.1 관습적 차속 컷오프 ([50, 5] km/h)의 한계
실차 제동 평가에서 규격 시험(예: 50 $\to$ 5 km/h, 100 $\to$ 5 km/h)을 분석할 때, 데이터 파이프라인은 통상 차량 속도가 정확히 50 km/h에 도달하는 순간부터 데이터를 자르는 **고정 속도 컷오프(Fixed Velocity Slicing)**를 적용해 왔습니다.

```
       속도 (kph)
 55 ──┐
      │  [운전자 페달 작동: t_onset]  감속도 ax ≈ 0, 슬립 λ ≈ 0
 50 ──┼──────────────────────┬────────────────────────────────
      │                      │  [50 km/h 고정 슬라이싱 시점]
      │                      │  실제 감속도 ax ≈ -0.45g 이미 도달!
      │                      │  슬립율 λ ≈ 4~6% 이미 상승!
 40 ──┤                      │
      │   잘려나가는 구간!     ▼  [보존되는 구간]
      │  (초기 과도 응답)    │  (ABS 완전 개입 및 고슬립 영역)
  0 ──┴──────────────────────┴───────────────────────────────> 시간 (s)
```

그러나 운전자가 약 53~55 km/h에서 브레이크 페달을 밟아 유압이 상승하고 차량이 감속하기 시작하여 50 km/h에 도달하는 시점에는:
1. **이미 감속도가 $-0.45\text{g} \sim -0.50\text{g}$에 도달**해 있습니다.
2. 타이어의 제동 슬립률 $\lambda$는 이미 **$4\% \sim 6\%$ 수준으로 급격히 램프업**된 상태입니다.

### 1.2 피팅 왜곡: 저슬립 데이터 부재와 수평선 클램핑
이로 인해 제동 슬립-마찰력($\lambda$-$\mu$) 곡선을 피팅할 때 **$0 \le \lambda \le 4\%$ 구간의 데이터가 전무한 결측 상태**가 발생합니다.

```
 마찰계수 μ (또는 감속도 ax)
   ^
   │           /`" - ._  피크 영역 (정상 피팅)
   │          /        `" - ._
   │         /
   │        /
   │  ???  /  <── 50 km/h 컷오프 시작점 (λ ≈ 4%, ax ≈ -0.45g)
   │ ┌────┘
   │ │  [치명적 외삽 왜곡]
   │ │  저슬립 데이터가 없어 모델이 음수 슬립으로 튀거나,
   │ └── 수평 클램핑되어 초기 강성(BCD)이 완전히 왜곡됨!
   └──+────────+──────────────+─────────────────────────> 슬립율 λ (%)
      0        4              15
```

비선형 최적화 알고리즘은 관측되지 않은 $0 \sim 4\%$ 구간을 추정할 수 없어, 초기 강성(Stiffness: $B \cdot C \cdot D$)이 수직으로 치솟거나 음수 영역으로 외삽되어 수평선 클램핑이 발생하는 물리적 붕괴를 초래합니다.

## ⚙️ 2. 브레이크 작동 개시점(Brake Onset)의 물리적 정의

차량의 제동 거동은 시간 축에서 3단계로 구분됩니다:

$$
t_{\text{driver}} \xrightarrow{\text{인식}} t_{\text{pedal}} \xrightarrow{\text{유압 응답}} t_{\text{onset}} \xrightarrow{\text{타이어 슬립}} t_{\text{peak}} \xrightarrow{\text{ABS 제어}} t_{\text{stop}}
$$

1. **페달 답력 개시 시점 ($t_{\text{pedal}}$)**: 운전자가 브레이크 페달을 조작하여 마스터 실린더 유압이 형성되는 순간.
2. **물리적 감속 개시 시점 ($t_{\text{onset}}$)**: 브레이크 캘리퍼 패드가 디스크를 압착하여 제동 토크 $T_b$가 노면 구름 저항을 초과하고 차량의 종방향 가속도 $a_x$가 정속 상태($\approx 0$)에서 명확한 음의 기울기로 하강하기 시작하는 순간.
3. **ABS 완전 개입 시점 ($t_{\text{peak}}$)**: 휠 속도가 급격히 감속하며 타이어가 최대 정지 마찰 한계에 도달하는 순간.

실무 계측 환경에서는 페달 압력 센서가 장착되지 않은 VBOX GPS 단독 계측 차량이 다수이므로, **차속 $V(t)$ 및 종방향 가속도 $a_x(t)$ 시계열만으로 진정한 $t_{\text{onset}}$을 강건하게 역추적**해야 합니다.

## 🛡️ 3. 3중 노이즈 방어 브레이크 시작점 자동 탐지 알고리즘

단순히 $a_x < 0$ 또는 $a_x < -0.1\text{g}$ 단일 임계치를 적용하면 노면 요철, 엔진 브레이크 잔류 진동, VBOX GPS 미분 노이즈로 인해 조기 오탐(False Positive)이 발생합니다. 이를 원천 차단하기 위해 **3중 노이즈 방어 파이프라인**을 구축합니다:

```mermaid
flowchart TD
    A["VBOX 원시 시계열<br>(Time, Speed, AccelHorizontal)"] --> B["1단계: 11샘플 윈도우 이동평균 평활화<br>(고주파 노이즈 스파이크 제거)"]
    B --> C["2단계: 제동 직전 1초 정속 기저선 통계 추정<br>(Baseline Mean μ_ax, Std σ_ax 산출)"]
    C --> D["3단계: 5샘플 연속 지속성 검증<br>(ax <= μ_ax - 3*σ_ax 및 ax <= -0.05g)"]
    D --> E["t_onset 브레이크 시작점 확정<br>(과도 구간 포함 전체 제동 시계열 슬라이싱)"]
```

### 3.1 [방어 1단계] 11샘플 윈도우 이동평균 평활화
원시 가속도 신호 $a_x(t)$의 샘플링 노이즈를 억제하기 위해 대칭 이동평균 필터를 적용합니다:

$$
\bar{a}_x[k] = \frac{1}{2M + 1} \sum_{j=-M}^{M} a_x[k + j], \quad (M = 5, \; \text{총 11샘플})
$$

### 3.2 [방어 2단계] 제동 직전 정속 기저선(Baseline) 통계 추정
운전자가 브레이크를 밟기 직전 약 1초(100Hz 기준 100샘플) 동안의 정속 주행 상태에서 가속도 기저선의 평균 $\mu_{a_x}$과 표준편차 $\sigma_{a_x}$를 동적으로 측정합니다:

$$
\mu_{a_x} = \frac{1}{N_{\text{base}}} \sum_{k=1}^{N_{\text{base}}} \bar{a}_x[k], \quad \sigma_{a_x} = \sqrt{\frac{1}{N_{\text{base}}} \sum_{k=1}^{N_{\text{base}}} (\bar{a}_x[k] - \mu_{a_x})^2}
$$

노면 경사나 차체 피칭으로 인해 기저선이 $0.0\text{g}$가 아닌 $-0.02\text{g}$ 또는 $+0.01\text{g}$로 오프셋되어 있더라도, 통계적 동적 기저선 추정을 통해 정확한 편차를 감지합니다.

### 3.3 [방어 3단계] 5샘플 연속 지속성 검증 (Multi-Sample Persistence Guard)
순간적인 노면 충격(방지턱, 팟홀)에 의한 일시적 감속을 걸러내기 위해, 다음 두 조건을 **연속 5개 샘플($50\text{ms}$) 이상 지속**해서 만족하는 최초의 인덱스 $k^*$를 진정한 제동 작동 개시 시점 $t_{\text{onset}}$으로 확정합니다:

$$
\bar{a}_x[k] \le \min\left( \mu_{a_x} - 3\sigma_{a_x}, \; -0.05\text{g} \right) \quad \text{for all } k \in [k^*, k^* + 4]
$$

```python
def find_brake_start_point(
    time_arr: np.ndarray,
    ax_arr: np.ndarray,
    window_size: int = 11,
    baseline_sec: float = 1.0,
    persistence_samples: int = 5,
    sample_rate: float = 100.0
) -> int:
    """3중 노이즈 방어를 통해 브레이크 조작 시작점 인덱스를 정밀 역추적"""
    # 1. 11샘플 이동평균
    ax_smooth = np.convolve(ax_arr, np.ones(window_size) / window_size, mode='same')
    
    # 2. 직전 baseline 구간 통계 산출
    n_base = int(baseline_sec * sample_rate)
    mu_base = np.mean(ax_smooth[:n_base])
    sigma_base = np.std(ax_smooth[:n_base])
    threshold = min(mu_base - 3.0 * sigma_base, -0.05)
    
    # 3. 5샘플 연속 지속성 검증
    for idx in range(n_base, len(ax_smooth) - persistence_samples):
        if np.all(ax_smooth[idx : idx + persistence_samples] <= threshold):
            return idx
    return 0
```

## 📈 4. 과도응답 및 슬립율 복원의 공학적 효과

### 4.1 슬립율($\lambda$) 램프업 구간의 완벽한 복원
이 알고리즘을 적용하면 제동 시계열 슬라이싱 시작점이 고정 50 km/h 시점이 아닌, 브레이크 시작 시점(약 53~55 km/h, $a_x \approx 0$)으로 확장됩니다.

$$
\lambda[k] = \frac{V[k] - V_w[k]}{V[k]} \times 100 \; (\%)
$$

그 결과, $\lambda = 0\%$에서 피크 슬립($\approx 15\%$)까지 매끄럽게 상승하는 **초기 선형 탄성 구간의 실측 데이터가 온전히 복원**됩니다:

| 구분 | 고정 속도 컷오프 ([50, 5] km/h) | 시작점 자동 탐지 (`find_brake_start_point`) |
| :--- | :--- | :--- |
| **시작 감속도** | $-0.45\text{g} \sim -0.52\text{g}$ (이미 급감속) | $\mathbf{-0.02\text{g} \sim -0.05\text{g}}$ (원점 일치) |
| **시작 슬립율** | $4.5\% \sim 6.2\%$ (과도 구간 결손) | $\mathbf{0.0\% \sim 0.5\%}$ (전 구간 온전 복원) |
| **피팅 모델 안정성** | 저슬립 영역 외삽 왜곡 및 클램핑 발생 | **원점 구속($\lambda=0 \implies \mu=0$) 및 $C^1$ 연속성 보장** |
| **초기 제동 강성 ($B \cdot C \cdot D$)** | 물리적 신뢰도 결여 (과대/과소 추정) | **타이어 고유 전단 변형 물리 강성 정밀 산출** |

### 4.2 매직 포뮬러(Magic Formula) 피팅 수렴도 비교

$$
\mu(\lambda) = D \sin\left( C \arctan\left( B\lambda - E(B\lambda - \arctan(B\lambda)) \right) \right)
$$

복원된 과도응답 데이터를 주입하여 Pacejka Magic Formula 및 `CombinerEstimator`를 피팅하면:
* 잔차 평균 제곱근 오차(RMSE)가 최대 **35% 감소**합니다.
* 초기 기울기(Cornering/Braking Stiffness $K = B \cdot C \cdot D$)의 추정 분산이 $\pm 42\%$에서 **$\pm 3.5\%$ 이내로 극적으로 안정화**됩니다.

## 🔬 5. 제동 초기 과도 응답 4-랜드마크(`L0 → L1 → L2 → L3`) 위상 정합 및 본체 피팅 분리 공학

### 5.1 제동 초기 관성 불감대(Inertial Dead-Zone)와 과도 스파이크의 물리적 발생 기작
브레이크 시작점 $t_{\text{onset}}$(`L0`)을 복원하면, 제동 극초기($0 \sim 80\,\text{ms}$) 구간에서 타이어와 휠의 회전 관성 모멘트 $I_w$로 인한 **회전 운동 방정식의 위상차**가 관측됩니다:

$$
T_b(t) - R_{\text{eff}} \cdot F_x(t) = I_w \cdot \left(-\dot{\omega}_w(t)\right)
$$

1. **관성 불감대 (`L0 → L1`: Inertial Dead-Zone)**:
   - 유압 인가 직후 제동 토크 $T_b(t)$의 상당 부분이 타이어-휠 어셈블리의 회전 각감속도($-\dot{\omega}_w$)를 만드는 데 먼저 소모됩니다.
   - 이 구간($\Delta t_{L1} \approx 50 \sim 80\,\text{ms}$)에서는 휠 속도 $V_w$만 먼저 떨어져 슬립율 $\kappa$는 $0 \to 2.5\%$까지 상승하지만, 차체 종감속도 $|a_x|$는 현가 부싱 컴플라이언스 및 피칭 지연으로 인해 $\mu < 0.035\text{g}$ 바닥에 수평으로 머뭅니다.
   - 시험 차량과 휠/타이어 규격이 동일하면 휠 관성 모멘트 $I_w$와 유압 상승 시정수가 동일하므로, 관성 딜레이 시간 $\Delta t_{L1}$ 및 슬립 오프셋 $\kappa_{L1}$은 타이어 컴파운드와 무관한 **차량/시험계 고유 상수**로 나타납니다.
2. **초기 탄성 빌드업 및 1차 과도 피크 (`L1 → L2 → L3`: Initial Transient Spike Loop)**:
   - `L1`(감속도 발현 변곡점, $\mu \ge 0.035\text{g}$) 이후 타이어 트레드 블록이 노면을 본격적으로 전단 변형시키며 `L2`(1차 최대 마찰 피크, $\mu_{L2} \approx 0.43 \sim 0.45\text{g}$)까지 가파르게 솟구친 뒤, ABS 1차 감압 밸브 작동으로 `L3`(1차 ABS 해제 골짜기)로 하강합니다.
   - 이 초기 1차 과도 스파이크(`L1 → L3`)는 정적 하중 이동 완료 전의 순간 충격 마찰과 휠 각감속 관성이 중첩되어 있어, 이후 $90\%$ 이상의 시간을 차지하는 **정상 상태(Quasi-Steady ABS Cycling, `L3` 이후, $\mu \approx 0.36 \sim 0.40\text{g}$)의 $\mu$-$\kappa$ 궤적보다 저슬립($\kappa \in [0.05, 0.15]$) 상단에 이질적인 고마찰 군집을 형성**합니다.

### 5.2 4-랜드마크 위상 정합 (Landmark Phase Registration, $s \in [0, 3]$)
단순히 동일 시간($t$)이나 동일 슬립($\kappa$)에서 여러 런(Run)을 평균 내면 회차별 유압 상승 타이밍 편차로 인해 `L1` 굴절점과 `L2` 피크가 뭉개집니다. 이를 방지하기 위해 4개의 물리적 랜드마크를 무차원 위상 변수 $s \in [0, 3]$으로 1:1 매핑합니다:

$$
s(t) = m + \frac{t - t_{L_m}}{t_{L_{m+1}} - t_{L_m}}, \quad t \in [t_{L_m}, t_{L_{m+1}}], \quad m \in \{0, 1, 2\}
$$

* $s = 0$: `L0` (제동 시작점, $\kappa \approx 0, \mu \approx 0$)
* $s = 1$: `L1` (관성 불감대 종료 및 감속 발현 변곡점, $\mu \approx 0.035\text{g}$)
* $s = 2$: `L2` (초기 과도 1차 마찰 피크, $\max \mu$)
* $s = 3$: `L3` (1차 ABS 감압 해제 골짜기, $\min \mu$ after `L2`)

동일 위상 $s$ 격자에서 각 런의 $(\kappa_r(s), \mu_r(s))$ 중앙값(Median)을 취하면, 휠 관성 데드존과 순수 탄성 상승 기울기가 뭉개지지 않고 보존된 **대표 초기 과도 루프(Representative Transient Loop)** 가 복원됩니다.

### 5.3 초기 과도 응답 2대 물리 지표: 피크-코드 강성($K_{\text{pk}}$) vs 시간축 빌드업 속도($d\mu/dt$)
복원된 초기 과도 구간(`L0 → L2`)으로부터 타이어 초기 응답성을 대변하는 두 가지 상보적 물리 지표를 정의합니다:

| 구분 | 지표 1: 피크-코드 강성 ($K_{\text{pk}}$) | 지표 2: 시간축 마찰 빌드업 속도 ($d\mu/dt$) |
| :--- | :--- | :--- |
| **수학적 정의** | $$K_{\text{pk}} = \frac{\mu_{L2}}{\kappa_{L2}} = \frac{\mu_{L2}}{\kappa_{L1} + \Delta\kappa_{L1\to L2}}$$ | $$\frac{d\mu}{dt} = \frac{\mu_{90\%} - \mu_{10\%}}{t_{90\%} - t_{10\%}} \quad [\text{g/s}]$$ |
| **물리적 의미** | 원점 $(0,0)$에서 1차 피크 $(\kappa_{L2}, \mu_{L2})$를 잇는 유효 할선(Secant) 기울기로, **슬립 축($\kappa$) 기준 초기 유효 제동 강성** | 제동 개시 후 피크 마찰의 $10\% \to 90\%$ 도달 시간 기울기로, **시간 축($t$) 기준 제동력 응답 속도** |
| **센서 의존성** | 차속 $V$ + 4륜 휠속도 $V_w$ + 종가속도 $a_x$ 모두 사용 | **휠속도 노이즈와 완전히 무관** (순수 $a_x$ 및 시간 $t$만 사용) |
| **활용 목적** | Magic Formula 수식의 원점 초기 강성 구속 조건($B \cdot C \cdot D = K_{x0}$) 직접 주입 | 타이어 컴파운드별 순수 과도 마찰 발현 응답성 정량 비교 |

### 5.4 초기 과도 루프(`L0 → L3`) 전체 분리 후 정상 상태(`L3~`) 본체 피팅 원칙
초기 과도 루프(`L0 → L3`)는 정상 상태 ABS 제어 구간(`L3` 이후)과 물리적 영역대가 다르므로 **역할을 엄격히 이원화**합니다:
1. **초기 기울기 추출 전용 (`L0 → L3`)**: `L0 → L2` 구간의 랜드마크 분석을 통해 타이어의 원점 초기 강성 $K_{x0}$ ($= K_{\text{pk}}$ 또는 $K_{\text{build}}$)만 추출합니다.
2. **본체 피팅 데이터 정제 (`filter_deadzone=True`, `filter_transient=True`)**:
   - **제외 데이터 ① (`deadzone_data`, `L0 → L1`)**: $\mu < 0.035\text{g}$ 관성 불감대 데이터 제거
   - **제외 데이터 ② (`transient_data`, `L1 → L3`)**: 1차 과도 스파이크 루프 데이터 제거
   - **정상 피팅 데이터 (`L3` 이후)**: 실제 제동 거리의 $90\%$ 이상을 결정하는 정상 상태 ABS 사이클링 및 고슬립 영역 데이터만으로 본체 커브를 피팅합니다.
   - **공학적 효과**: 저슬립($5 \sim 15\%$) 상단에 떠 있던 과도 스파이크가 구간 중앙값(Bin Median)을 위로 끌어올려 고슬립($15 \sim 30\%$) 포화 곡선을 아래로 누르던 현상이 사라지며, **전 타이어 세트에서 피팅 오차(RMSE)가 $18.5\% \sim 23.7\%$ 감소**하고 고슬립 실제 마찰 추종성이 완벽히 복원됩니다.

## ❄️ 6. 고슬립 표본 불균형 역가중치 및 스노우 웻지(Snow Wedge) 결합 모델

### 6.1 구간 밀도 역제곱근 가중치 (Inverse-Power Bin Density Weighting)
ABS 제동 시험에서는 제어 로직이 슬립율을 $\kappa \in [0.08, 0.22]$ 대역에 집중시키므로, $\kappa > 0.25$ 고슬립 구간의 데이터 비율이 전체의 $10\%$ 미만으로 과소 대표됩니다. 일반 최소자승법(OLS) 적용 시 고슬립 데이터가 무시되는 현상을 막기 위해 슬립 축을 $B$개의 균등 구간(Bin)으로 나누고 각 표본 $i \in b$에 역거듭제곱 가중치를 부여합니다:

$$
w_i = \left( \frac{\bar{N}}{N_{b(i)}} \right)^{\gamma}, \quad \gamma \approx 0.65
$$

이를 통해 표본이 희소한 고슬립($\kappa \in [0.25, 0.60]$) 구간도 저슬립 밀집 구간과 동등한 비중으로 최적화 목적함수에 반영됩니다.

### 6.2 스노우 웻지(Snow Wedge) 고슬립 선형 재상승 결합 수식
눈길(Snow) 노면에서는 타이어가 높은 슬립율($\kappa > 0.25$)로 미끄러질 때 트레드 전방에 눈 더미가 압축·적층되는 **스노우 쐐기 효과(Snow Plowing / Wedge Effect)** 로 인해 마찰력이 피크 이후 감소하지 않고 완만하게 재상승합니다. 순수 Pacejka Magic Formula는 구조적으로 피크 이후 단조 감소($E \le 1$)만 표현할 수 있으므로, 고슬립 영역($\kappa > \kappa_{\text{valley}}$)에서 작동하는 물리적 스노우 웻지 항을 결합합니다:

$$
\mu_{\text{total}}(\kappa) = D \sin\left( C \arctan\left( B\kappa - E(B\kappa - \arctan(B\kappa)) \right) \right) + W_{\text{snow}} \cdot \max\left(0, \; \kappa - \kappa_{\text{valley}}\right)
$$

* 여기서 $B = \frac{K_{x0}}{C \cdot D}$는 초기 과도 랜드마크에서 추출된 원점 강성 구속 조건이며,
* $W_{\text{snow}} \ge 0$는 고슬립 눈 쐐기 전단 저항 계수, $\kappa_{\text{valley}} \approx 0.20$은 ABS 주 제어 대역 이후 쐐기 적층이 지배적으로 전환되는 기준 슬립율입니다.
