# **측정불확도 자동 평가 모듈 (`uno_uncertainty.py`) 상세 사용자 매뉴얼 (v3.0)**

#### **1. 개요 (Overview)**

**1.1. 모듈의 목적과 철학**

`uno_uncertainty.py` 모듈은 GUM(Guide to the Expression of Uncertainty in Measurement) 국제 표준에 기반하여, 복잡한 다변수 수학 모델의 측정불확도를 자동으로 산출하기 위해 개발된 파이썬 라이브러리입니다.

본 모듈의 핵심 철학은 평가자가 복잡하고 실수하기 쉬운 편미분 유도나 통계 공식 암기에서 벗어나, **자신의 시험 본질(측정 데이터와 물리 공식)에만 집중**할 수 있도록 돕는 것입니다.

**1.2. 주요 특징**

-   **임의의 수학 모델 지원**: 평가하려는 공식이 아무리 복잡해도, 일반적인 파이썬 함수 형태로 정의만 하면 즉시 적용 가능합니다.
-   **민감도 계수 자동 계산**: 수치미분(중심차분법)을 통해 각 입력 변수가 최종 결과에 미치는 영향(민감도 계수 cᵢ)을 컴퓨터가 자동으로 계산하여, 수식 유도 과정의 실수를 원천 차단합니다.
-   **GUM 표준 완전 준수**: Welch-Satterthwaite 공식을 이용한 유효자유도(ν_eff)와, 이를 바탕으로 t-분포표를 역산하여 구한 정밀한 포함인자(k)를 적용합니다.
-   **상세 리포트 및 시각화**:
    1.  **피쉬본 다이어그램**: 불확도의 원인을 시각적으로 구조화하여 보여줍니다.
    2.  **불확도 누적 차트**: 개별 오차가 최종 오차로 누적되는 과정을 단계별로 시각화합니다.
    3.  **기여율 파레토 차트**: 어떤 오차 요인이 가장 지배적인지 한눈에 파악하게 해줍니다.

#### **2. 설치 및 기본 설정**

**2.1. 설치**

별도의 설치 과정은 없습니다. 제공된 파이썬 코드를 `uno_uncertainty.py` 라는 이름의 파일로 저장한 뒤, 분석을 수행할 메인 스크립트나 주피터 노트북과 같은 폴더에 위치시키면 됩니다.

**2.2. 필요 라이브러리**

본 모듈은 아래의 표준 과학 계산 라이브러리들을 사용합니다. (아나콘다 환경에는 대부분 기본 설치되어 있습니다.)

-   `numpy`
-   `scipy`
-   `matplotlib`
-   `pandas`

**2.3. 모듈 임포트**
```python
from uno_uncertainty import FlexibleUncertaintyEvaluator
```

#### **3. 핵심 클래스 소개**

**3.1. `InputVariable` 클래스**

하나의 입력 변수(하나의 센서 또는 측정 장비)가 가진 모든 정보를 담는 데이터 컨테이너입니다.

-   **역할**: 반복 측정 데이터(A타입 근거)와 장비 사양(B타입 근거)을 모두 입력받아, 해당 변수 하나가 가진 **종합 표준불확도(u(xᵢ))**와 **자유도**를 스스로 계산합니다.
-   **주요 입력 인자**:
    -   `name` (str): 변수 이름 (예: `w_front`). **가장 중요하며, 모델 함수의 인자명과 반드시 일치해야 합니다.**
    -   `data` (list): n회 반복 측정한 원시 데이터 리스트. A타입 불확도 산출에 사용됩니다.
    -   `spec_limit` (float): 장비 사양서의 허용 오차 한계(반폭). B타입 불확도 산출에 사용됩니다.
    -   `distribution` (str): `spec_limit`의 확률 분포. `'rectangular'`, `'triangular'`, `'normal'` 중 선택합니다.

**3.2. `FlexibleUncertaintyEvaluator` 클래스**

전체 측정불확도 평가 프로젝트를 총괄하는 메인 컨트롤 타워입니다.

-   **역할**: 사용자가 정의한 수학 모델(`model_function`)과 여러 개의 `InputVariable`들을 입력받아, ①자동 편미분, ②합성, ③최종 확장불확도 계산까지 모든 과정을 수행하고, 보고서와 그래프를 출력합니다.
-   **주요 입력 인자**:
    -   `name` (str): 평가 프로젝트의 전체 이름 (예: "수중 제동 슬립율 평가").
    -   `model_function` (Callable): 최종 결과값을 계산하는 파이썬 함수.
    -   `confidence_level` (float): 최종적으로 보증하고자 하는 목표 신뢰수준. (기본값: 0.95)

#### **4. 단계별 사용법 (Step-by-Step)**

**1단계: 측정 모델을 파이썬 함수로 정의**

측정 결과를 계산하는 물리 공식을 일반 파이썬 함수로 작성합니다.

```python
# 사례: 슬립율(%) 계산 공식
def calc_slip_ratio(w_front, w_rear):
    if w_rear == 0: return 0
    return ((w_front / w_rear) - 1.0) * 100.0
```

**2단계: `FlexibleUncertaintyEvaluator` 객체 생성**

프로젝트 이름과 위에서 만든 모델 함수를 전달하여 평가기를 생성합니다.

```python
slip_evaluator = FlexibleUncertaintyEvaluator(
    name="수중 제동 슬립율 평가",
    model_function=calc_slip_ratio,
    unit="%"
)
```

**3단계: `add_variable()`로 모든 입력 변수 정보 등록**

측정에 사용된 모든 센서(입력 변수)의 정보를 각각 등록합니다.

```python
# 전륜 RPM 센서 정보 등록
slip_evaluator.add_variable(
    name="w_front",  # 모델 함수의 'w_front' 인자와 이름 일치
    data=[907.6, 913.2, 885.6, 904.8, 902.5, 892.7], # A타입 평가용 데이터
    spec_limit=0.1,                                   # B타입 평가용 데이터
    unit="RPM",
    description="전륜 휠 스피드 센서"
)

# 후륜 RPM 센서 정보 등록
slip_evaluator.add_variable(
    name="w_rear", # 모델 함수의 'w_rear' 인자와 이름 일치
    data=[648.0, 648.0, 638.1, 648.2, 646.4, 641.3],
    spec_limit=0.1,
    unit="RPM",
    description="후륜 휠 스피드 센서"
)
```

**4단계: `.calculate()` 실행 및 결과 확인**

단 한 줄의 코드로 모든 복잡한 계산을 실행하고, 원하는 형태로 결과를 출력합니다.

```python
# 모든 불확도 자동 연산 실행
slip_evaluator.calculate()

# 1. 콘솔에 종합 리포트 출력
slip_evaluator.print_report()

# 2. 불확도 원인 분석 (피쉬본 다이어그램)
slip_evaluator.plot_fishbone_diagram()

# 3. 불확도 누적 과정 시각화
slip_evaluator.plot_uncertainty_buildup()
```

#### **5. 결과 해석 및 시각화**

-   **`print_report()`**: 콘솔에 출력되는 **불확도 총괄표(Uncertainty Budget)**의 `Contribution (%)` 열을 주목하십시오. 이 값이 높은 변수가 전체 오차의 주범이므로, 시험 정밀도를 개선하려면 해당 변수의 `u_A`(반복성) 또는 `u_B`(장비 성능)를 개선해야 합니다.
-   **`plot_fishbone_diagram()`**: 어떤 측정 과정(뼈대)에서 어떤 오차 요인(잔가지)들이 발생하는지 시각적으로 보여주어, 품질 관리 및 개선 회의에 활용하기 좋습니다.
-   **`plot_uncertainty_buildup()`**: 개별 변수의 작은 불확도 성분(A, B타입)들이 어떻게 합쳐져서 최종 확장불확도(U)라는 큰 오차 범위를 만들어내는지 그 과정을 시각적으로 보여주므로, 불확도 전파 과정을 직관적으로 이해하는 데 가장 효과적입니다.
