## 🏆 1. 실시간 매매 성적 요약 (Overview)

```dataviewjs
const trades = dv.pages('"03_Areas/트레이딩/20_2026_매매일지"')
  .where(p => p.type === "trade");

const total = trades.length;
const wins = trades.where(p => p.status === "Win").length;
const losses = trades.where(p => p.status === "Loss").length;
const be = trades.where(p => p.status === "BE").length;
const winRate = (wins + losses) > 0 ? ((wins / (wins + losses)) * 100).toFixed(1) : 0;
const ruleOk = trades.where(p => p.rule_followed === true).length;
const ruleRate = total > 0 ? ((ruleOk / total) * 100).toFixed(1) : 0;

let totalPnl = 0;
trades.forEach(t => {
  if (t.pnl_usd) totalPnl += Number(t.pnl_usd);
});

dv.paragraph(`
| 🎯 누적 매매 | 🟢 승리 (Win) | 🔴 패배 (Loss) | ⚪ 본절 (BE) | 🏆 공식 승률 | 🛡️ 원칙 준수율 | 💰 누적 손익 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **${total} 회** | **${wins} 회** | **${losses} 회** | **${be} 회** | **${winRate}%** | **${ruleRate}%** | **$${totalPnl.toLocaleString()}** |
`);
```

## 🌊 2. 진입 파동별 승률 통계 (Wave Pattern Analytics)

> [!NOTE]- 🌊 파동 패턴별 세부 승률 표 [클릭하여 펼치기]
> ```dataviewjs
> const trades = dv.pages('"03_Areas/트레이딩/20_2026_매매일지"')
>   .where(p => p.type === "trade" && p.pred_wave_pattern);
> 
> const groups = {};
> trades.forEach(t => {
>   const pat = t.pred_wave_pattern;
>   if (!groups[pat]) groups[pat] = { total: 0, win: 0, loss: 0, be: 0 };
>   groups[pat].total++;
>   if (t.status === "Win") groups[pat].win++;
>   if (t.status === "Loss") groups[pat].loss++;
>   if (t.status === "BE") groups[pat].be++;
> });
> 
> let md = "| 진입 파동 패턴 | 매매 횟수 | 승 | 패 | 본절 | 승률 (%) |
| :--- | :---: | :---: | :---: | :---: | :---: |
";
> for (const [pat, stat] of Object.entries(groups)) {
>   const wr = (stat.win + stat.loss) > 0 ? ((stat.win / (stat.win + stat.loss)) * 100).toFixed(1) : "-";
>   md += `| **${pat}** | ${stat.total} | ${stat.win} | ${stat.loss} | ${stat.be} | **${wr}%** |
`;
> }
> dv.paragraph(md);
> ```

## 🧠 3. 심리 상태 및 매매 진단 통계 (Psychology & Diagnosis)

> [!NOTE]- 🧠 심리 및 진단 분석 상세 [클릭하여 펼치기]
> ### ① 진입 시 심리 상태별 승률
> ```dataviewjs
> const trades = dv.pages('"03_Areas/트레이딩/20_2026_매매일지"')
>   .where(p => p.type === "trade" && p.psychology);
> 
> const psychMap = {};
> trades.forEach(t => {
>   const ps = t.psychology;
>   if (!psychMap[ps]) psychMap[ps] = { total: 0, win: 0, loss: 0 };
>   psychMap[ps].total++;
>   if (t.status === "Win") psychMap[ps].win++;
>   if (t.status === "Loss") psychMap[ps].loss++;
> });
> 
> let mdPsych = "| 심리 상태 | 매매수 | 승 | 패 | 승률 (%) |
| :--- | :---: | :---: | :---: | :---: |
";
> for (const [ps, s] of Object.entries(psychMap)) {
>   const wr = (s.win + s.loss) > 0 ? ((s.win / (s.win + s.loss)) * 100).toFixed(1) : "-";
>   mdPsych += `| **${ps}** | ${s.total} | ${s.win} | ${s.loss} | **${wr}%** |
`;
> }
> dv.paragraph(mdPsych);
> ```
> 
> ### ② 매매 복기 및 최종 진단 분류
> ```dataviewjs
> const trades = dv.pages('"03_Areas/트레이딩/20_2026_매매일지"')
>   .where(p => p.type === "trade" && p.final_diag);
> 
> const diagMap = {};
> trades.forEach(t => {
>   const d = t.final_diag;
>   diagMap[d] = (diagMap[d] || 0) + 1;
> });
> 
> let mdDiag = "| 복기 진단 항목 | 횟수 | 비율 (%) |
| :--- | :---: | :---: |
";
> const totalDiag = trades.length;
> for (const [d, cnt] of Object.entries(diagMap)) {
>   const pct = totalDiag > 0 ? ((cnt / totalDiag) * 100).toFixed(1) : 0;
>   mdDiag += `| **${d}** | ${cnt} 회 | ${pct}% |
`;
> }
> dv.paragraph(mdDiag);
> ```
