## 🎯 핵심 목표 달성 현황 (Dataview)

```dataview
TABLE WITHOUT ID
  file.link AS "자기개발 목표 / 과제",
  topic AS "분야",
  progress AS "진도율",
  target_date AS "목표일",
  satisfaction AS "만족도(1~5)"
FROM "03_Areas/자기개발"
WHERE file.name != this.file.name
SORT target_date ASC
```
