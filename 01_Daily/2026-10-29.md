   - 빈 데이터프레임이 캐싱되어 있음에도 프로퍼티 조회 시마다 `analysis()`가 강제 재기동되던 루프 폭포수를 원천 박멸하고, 프로퍼티 레벨 임시 가드(`_is_ready_to_analyze()`)를 걷어내어 순수 $O(1)$ 자가 복원 규격(`if self._df is None: ...`)으로 복원.
2. **`VTAccBrkTire.analysis()` 선제적 빈 데이터프레임 초기화(Pre-emptive Initialization) 도입**:
   - `analysis()` 진입 즉시(try 블록 최상단) 모든 결과 필드(`_result.df`, `summary`, `summary_all`, `detail`, `detail_all`)를 빈 데이터프레임으로 선제 채움.
   - 유효 구간 미검출로 조기 반환(`return self`)하더라도 외부나 플로터에서 `.summary.empty` 조회 시 `AttributeError: NoneType` 다운을 100% 방어.
3. **하위 분석기 3종(`skewness`, `response`, `mu_drop`) 단일 위임(Single Delegation) 아키텍처 확립**:
   - 최상단 중복 가드(`if not is_col_wheel_speed`)를 제거하고, 오직 상위 결과의 존재 여부(`if self.test.slip_pdf.df.empty: return self`)만 확인하는 직교적 단일 위임 구조로 복원 (`func_acc_brk.py`의 `is_col_wheel_speed` 헬퍼 함수는 영구 보존).
4. **시각화 모듈(`PlotterTire`, `PlotterProject`) 연계 멱등성(Idempotency) 완비**:
   - 휠속도가 없는 시험 데이터에서 플로터가 다중 가드 체크를 위해 프로퍼티를 연속 조회하더라도, 최초 1회만 경고 후 이후 조회는 0초 만에 빈 DF를 즉시 반환하여 평화롭게 플롯을 건너뛰도록 보장.

## 🧠 2. 온디맨드 하이브리드 캐싱 핵심 엔지니어링 지식 집대성

### 💡 `None` vs `pd.DataFrame()`(빈 데이터프레임)의 상반된 라이프사이클 모델

| 상태 값 | 내부 의미 | `@property` 접근 시 동작 | 발생 시점 |
| :---: | :---: | :---: | :---: |
| **`None`** | **캐시 부재 / 메모리 소거**<br/>(연산 미수행 상태) | **`analysis()` 백그라운드 자동 복원 기동** | 최초 인스턴스 생성 시, `.tir` 저장 직렬화 시(`__getstate__`), `clear_cache()` 호출 시 |
| **`pd.DataFrame()`**<br/>(`empty == True`) | **연산 완료 (결과 부재 센티널)**<br/>(Sentinel Value) | **재연산 절대 금지! 빈 DF $O(1)$ 즉시 반환** | `analysis()`를 실행했으나 휠속도 채널 부재 또는 유효 구간 미검출로 조기 종료된 경우 |
| **`pd.DataFrame`**<br/>(`empty == False`) | **연산 완료 (정상 데이터 적재)** | **결과 데이터프레임 $O(1)$ 즉시 반환** | `analysis()`가 정상 완료된 경우 |

* **빈 데이터프레임의 센티널(Sentinel) 방어막 역할**:
  - 데이터 부재 시 `self._df = None`으로 남겨두면 시스템은 "미실행 상태"로 오판하여 무한 재호출 루프에 빠짐.
  - 빈 DF를 채워 `self._df is not None` 상태를 유지함으로써 **"이미 검증을 완료했으니 재연산하지 말라"**는 방어막을 구축.
* **선제적 초기화(Pre-emptive Initialization) 패턴**:
  - 함수 시작부에서 모든 결과 속성을 빈 DF로 미리 깔아두는 설계로 모든 조기 반환 분기에서의 안전성 보장.
