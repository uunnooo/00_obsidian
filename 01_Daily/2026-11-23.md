## ⚠️ 2. 차기 세션 3대 인수인계 미완결 과제 (Next Session Handover)

> [!WARNING] 📌 다음 세션 착수 시 최우선 해결 대상
> 사용자가 직접 정리한 미완결 핵심 3대 항목으로, 다음 작업 착수 시 이 내용을 기준으로 즉시 디버깅 및 정합을 진행할 것:

1. **확대 버튼(`[ ⛶ ]`) 일반 버튼(Secondary Dark Slate) 테마 완결**:
   - **현상**: 확대 버튼이 일반 보조 버튼 테마가 아닌 사파이어 테마로 변질되는 현상 잔존.
   - **원인 분석**: 메인 사파이어 버튼 규칙(`div.stButton button`, `stFormSubmitButton button`) 및 L1228 전역 버튼 규칙과의 CSS 우선순위 간섭.
   - **조치 방향**: 메인 버튼 선택자와 완전히 독립된 전용 선택자 및 명확한 클래스 격리를 통해 정사각 38px 다크 슬레이트 일반 보조 버튼 스타일로 확고히 안착시킬 것.

2. **메인 버튼 호버 시 테두리 시안(#00F0FF) 발광 및 글자 블루 사파이어(#38BDF8) 전환 복원**:
   - **현상**: 메인 버튼 호버 시 테두리 일렉트릭 시안 발광이 온전하게 표출되지 않는 문제.
   - **원인 분석**: L1266 등 이전 하드코딩된 호버 스타일과의 충돌 및 `<p>`, `<span>` 자식 요소의 텍스트 그림자 상속 간섭.
   - **조치 방향**: 프로젝트 탭의 테이블 모드 셀렉터(`4-B`)와 100% 동일하게, 평소에는 차분한 사파이어 테마를 유지하다가 호버 시 **테두리 전체가 일렉트릭 시안(#00F0FF)으로 팟! 발광하며 글자가 시원한 블루 사파이어(#38BDF8)로 전환**되는 인터랙션으로 완전 복구할 것.

3. **병합 대상 및 그래프 선택 드롭박스(`st.multiselect`) 호버 테마 일체화**:
   - **현상**: 다른 일반 입력창(`st.selectbox`, `st.text_input`)의 호버 기능과 다르게 반응함.
   - **사용자 핵심 분석**: **"아마도 배경이 투명하지 않아서 사파이어 격자가 안 보이는 것 같다"**
   - **조치 방향**: `stMultiSelect` 외곽 컨테이너의 배경 투명도 및 내부 래퍼 요소의 배경을 점검하여, 일반 입력창과 100% 동일한 **30% 사파이어 격자무늬 홀로그램 + 사파이어 테두리(#38BDF8) + 사파이어 림 발광**이 선명하게 투과되도록 일체화할 것.
