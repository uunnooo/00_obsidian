# 📅 2026-11-06 (Fri) 데일리 로그

## 📋 오늘 진행한 주요 핵심 업무 (Summary)

### ⚡ 1. unoUtil.vehicle.acc_brk 성능 최적화 및 75% 연산 가속
1. **`AnResponse` 알고리즘 병목 규명 및 고속화 (`func_acc_brk.py`)**:
   - `calc_response` 내부에서 75만 행 전체 시계열을 대상으로 윈도우 200(0.2초) 이동평균 필터를 통째로 돌리느라 2초 이상을 낭비하던 구조적 결함 발굴 (실제 분석에 필요한 6개 런 구간은 총 1.6만 행, 전체의 2.2%에 불과).
   - 동일한 `pd.concat` 및 컬럼 대입 블록이 2회 연속 중복 실행되던 코드 결함 제거.
   - 전체 75만 행 대신 **각 런별 유효 슬라이스(`idx_start:idx_end` + 패딩)만 바퀴 루프 밖에서 1회 사전 필터링**하는 구조로 전면 리팩토링.
   - **실측 개선 결과**: `AnResponse` 분석 소요 시간 **2.36초 ➔ 0.58초 (약 75% 단축, 4배 가속)** 달성, 수치 지표(`sys_response_time: 0.137`, `sys_rising_time: 0.23`, `sys_rising_slope: -3.862`) 100% 완전 일치 검증.
2. **`correct.py` DataFrame 파편화 경고(`PerformanceWarning`) 원천 소멸**:
   - Control 보정 루프에서 수십 개 컬럼에 대해 `df[f"index_{col}"] = ...`를 1개씩 insert하여 콘솔에 반복 출력되던 `PerformanceWarning: DataFrame is highly fragmented` 경고 제거.
   - 계산 결과를 딕셔너리에 수집한 후 `pd.concat`으로 단 1회 일괄 병합(Batch Concat)하도록 리팩토링하여 경고 0건 및 메모리 복사 오버헤드 원천 차단.

### 🎛️ 2. 5대 `save_*` 및 `plot` 파라미터 직교 분리 및 기본값 `False` 단일 표준화
1. **5대 저장 제어 파라미터 체계 확립 (`vt_acc_brk.py`, `vt_acc_brk_project.py`, `vt_acc_brk_tire.py`)**:
   - `save_file: bool = False`: 원시 계측 캐시(`.gz`) 저장 제어
   - `save_tire: bool = False`: 개별 타이어 분석 객체(`.tir`) 저장 제어
   - `save_pjt: bool = False`: 최종 프로젝트 객체(`.pjt`) 저장 제어
   - `save_result: bool = False`: **제동 수치 결과 테이블(`2.result/*.csv` 3종) 저장 제어 (신규 도입)**
   - `save_plot: bool = False`: **시각화 그래프 이미지(`1.figure/*.png`) 저장 제어 (기존 모호한 save에서 변경)**
   - `plot: bool = False`: 화면 플롯 창 띄우기 제어 (기본값 False)
   - `excel: Optional[dict] = None`: 시각화 차트 삽입형 엑셀 보고서(`.xlsx`) 저장 제어
2. **백그라운드 무음 파일 저장 (`plot=False, save_plot=True`) 완비**:
   - `plot`과 `save_plot`의 역할을 완전히 분리하여, 화면에 GUI 창을 띄우지 않고 백그라운드 메모리에서 차트 렌더링 후 디스크에만 저장하고 즉시 창을 닫는 무음 저장 파이프라인 구현 및 22개 차트 실측 검증 완료.
3. **100% 클린 인메모리 연산 실증**:
   - 모든 `save_*` 옵션이 `False`일 때 `check_path(dir_db)` 무조건 호출 결함을 수정하여, `0.db`, `1.figure`, `2.result` 그 어떤 찌꺼기 폴더도 디스크에 남기지 않는 완전한 클린 인메모리 실행 보장.

### 💻 3. 코어 수 자동 감지 기반 스마트 병렬화(`n_jobs: int = -1`) 탑재
1. **하드웨어 코어 수 런타임 자동 감지**:
   - 파이썬 내장 `os.cpu_count()`를 통해 사용자 PC(현재 시스템 기준 12코어)의 스레드 수를 스스로 파악.
2. **스마트 자동 분기 엔진**:
   - `n_jobs: int = -1` 기본값 설정:
     - 타이어가 1개일 때: 프로세스 생성 오버헤드 없이 순차 실행 (1초대 완료)
     - 타이어가 2개 이상일 때: `ProcessPoolExecutor` 기반으로 코어 수만큼 프로세스를 띄워 동시 병렬 처리 가속
3. **수치 무결성 실측 검증**:
   - 실제 VBO 2개 데이터(C1, T1)를 대상으로 순차(`n_jobs=1`) vs 병렬(`n_jobs=2`) 실행 결과 비교:
   - C1 제동거리: `40.282647m` (오차 0.000000)
   - T1 제동거리: `41.831274m` (오차 0.000000)
   - T1 제동지수: `96.155598%` (오차 0.000000) 100% 완전 일치 확인.
