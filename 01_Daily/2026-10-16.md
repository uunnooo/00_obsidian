* **문제 배경 및 원인 규명**:

  - 가속 시험 초기 거동에서 $0.1g$ 이하의 바닥 데이터가 선행 잘려나가면서 피크치의 30% 이하인 데이터가 `size 0`이 되어 `.index[-1]` 조회 시 크래시 유발.
* **공학적 해결 및 모드별 독립 분기**:
  - `response_target`을 단일 리스트 대신 모드별 딕셔너리(`brk: [-0.20, -0.05]g`, `acc: [0.05, 0.20]g`)로 분기하여, 바닥 데이터 유실 없이 눈길 가속/감속 특성을 1:1로 수용.
  - `rising_target`은 10% 및 90% 부근의 페달 초기 채터링 및 휠스핀 노이즈를 회피하여 깨끗한 선형 피팅 기울기를 산출하기 위해 사용자 실무 Rationale에 따라 **`[0.3, 0.9]`(30%~90%)**로 최종 확정.
  - `func_acc_brk.py` 빈 매칭 방어선 구축과 함께 실제 `25RD110010EF\run2` 재실증 결과 100% 정상 완주(Exit Code 0).
### 🛠️ vt_acc_brk 캐시 라이프사이클 로깅 시스템 개편 및 INFO/DEBUG 계층화 (v3.37)
* **문제 배경 및 기술적 Rationale**:
  - `a_make_SnowSurfaceCharacteristic_DF.py` 등 동계 노면 시험 배치 실행 시, 각 일자별 `.pjt` 파일을 로드할 때마다 `VTAccBrkProject.__setstate__`와 `VTAccBrkTire.__setstate__`에서 `tire_analyzers` 전체 명판과 `result.df: None` 검증 로그가 수백 줄씩 쏟아져 터미널 가독성을 심각하게 저해.
  - 과거 v2 리팩토링 초기 `weakref` 재연결 과정에서 대용량 데이터의 조기 복원(Early Restore)을 감시하던 안전 검증 로그였으나, 현재 아키텍처가 완전히 안정화되어 상시 노출될 실익이 소멸됨.
* **INFO vs DEBUG 명확한 역할 분리 및 슬림화**:
  - **`INFO [ℹ️ INFO  ]`**: 일반 실행 시 터미널을 어지럽히지 않고 상태 완료만 1줄로 브리핑 (`[Project] 프로젝트 역직렬화 로드 완료 (타이어 N개: [...])`, `[Memory] {set}[ACC/BRK] : 대용량 캐시 복원 완료`, `[Memory] {set} : 대용량 캐시 삭제 완료`).
  - **`DEBUG [🔍 DEBUG ]`**: 캐시 내부 구조를 정밀 분석하고 싶을 때만 활성화하여 실제 데이터 스펙(`Shape`, `Columns`) 및 타이어 상세 명판(`__repr__`) 출력.
* **기본 로거 레벨 조정 및 실증 검증**:
  - `vt_acc_brk_project.py` 및 `vt_acc_brk_tire.py`의 모듈 로거 기본 레벨을 `logging.INFO`로 정합.

### 🏎️ vt_acc_brk 파라미터 3계층 분기 단일 표준화 및 스마트 디폴트 시스템 완결 (v3.36)
* **단일 표준 계층 분기 아키텍처 (`resolve_hierarchy_param`)**:
  - 기존의 폴더 분배 함수(`make_path_dict`)와 타이어 추출 함수(`get_tire_value`)의 비대칭성을 해소하고, `[1. 폴더(노면/환경)]` $\to$ `[2. 속도 조건(vel_tag) / 시험 모드(mode)]` $\to$ `[3. 타이어 시편(tire_set)]` 우선순위로 일관되게 해석하는 단일 SSOT 엔진으로 통합.
  - 사용자가 단일값, 폴더별 dict, 모드별 dict(`{'brk': ..., 'acc': ...}`), 타이어별 dict, 또는 완전 계층 dict(`{'dry': {'80-5': {'T1': [2]}}}`) 등 어떤 형태로 전달하든 100% 매끄럽게 자동 매핑.
* **스마트 디폴트 및 물리 부호 자동 정규화 (Auto-Sign Alignment)**:
  - `response_target`: 미입력 시 가속/제동 방향에 맞춰 `[0.2, 0.5]` / `[-0.5, -0.2]` 자동 주입. 양수 `[0.2, 0.6]` 입력 시 제동 모드 음수 `[-0.6, -0.2]` 자동 반전 처리.
  - `vel_split`: 미입력 시 현재 `test_vel`의 중간값으로 자동 스마트 계산 (`[100, 0]` $\to$ 50.0, `[80, 5]` $\to$ 42.5, `[20, 35]` $\to$ 27.5).
  - `slip_mode_vel_range`: 미입력 시 현재 `test_vel` 구간 자동 상속.
* **입력 설정 종합 가이드라인 확립 (`vt_acc_brk_config_guide.md`)**:
  - 소스 코드 디렉토리(`unoUtil/vehicle/acc_brk/`) 내에 4대 입력 형태 작성법, 전체 파라미터 스펙 매트릭스, 물리 부호 정규화 원리, 4대 실무 실전 코드 레시피 수록 (Code Manual Isolation Law 준수).
* **무결성 단위 검증 통과**:
  - Case 7(신규 계층 분기 실증), Case 1(Mock 제동 파이프라인), Case 2(다중 프로젝트 병합), Case 6(실무 VBB 가속 풀링 배치) Exit Code 0 전수 통과.
