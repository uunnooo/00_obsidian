  - 사용자가 단일값, 폴더별 dict, 모드별 dict(`{'brk': ..., 'acc': ...}`), 타이어별 dict, 또는 완전 계층 dict(`{'dry': {'80-5': {'T1': [2]}}}`) 등 어떤 형태로 전달하든 100% 매끄럽게 자동 매핑.
* **스마트 디폴트 및 물리 부호 자동 정규화 (Auto-Sign Alignment)**:
  - `response_target`: 미입력 시 가속/제동 방향에 맞춰 `[0.2, 0.5]` / `[-0.5, -0.2]` 자동 주입. 양수 `[0.2, 0.6]` 입력 시 제동 모드 음수 `[-0.6, -0.2]` 자동 반전 처리.
  - `vel_split`: 미입력 시 현재 `test_vel`의 중간값으로 자동 스마트 계산 (`[100, 0]` $\to$ 50.0, `[80, 5]` $\to$ 42.5, `[20, 35]` $\to$ 27.5).
  - `slip_mode_vel_range`: 미입력 시 현재 `test_vel` 구간 자동 상속.
* **입력 설정 종합 가이드라인 확립 (`vt_acc_brk_config_guide.md`)**:
  - 소스 코드 디렉토리(`unoUtil/vehicle/acc_brk/`) 내에 4대 입력 형태 작성법, 전체 파라미터 스펙 매트릭스, 물리 부호 정규화 원리, 4대 실무 실전 코드 레시피 수록 (Code Manual Isolation Law 준수).
* **무결성 단위 검증 통과**:
  - Case 7(신규 계층 분기 실증), Case 1(Mock 제동 파이프라인), Case 2(다중 프로젝트 병합), Case 6(실무 VBB 가속 풀링 배치) Exit Code 0 전수 통과.
