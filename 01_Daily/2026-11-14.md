# 📅 2026-11-14 (Sat) 데일리 로그

## 📋 오늘 진행한 주요 핵심 업무 (Summary)

### 🚀 1. 가감속/제동 대시보드 (dashboard_app.py) v2.0 완성 및 파일 저장 무결성 확립 (v4.12)
1. **파일명 금지 특수문자 자동 정제기 구축 (`sanitize_filename`)**:
   - 타이어 명칭(`tire_name`) 자동 생성 시 포함되던 슬래시(`/`), 콜론(`:`), 역슬래시(`\`), 꺾쇠괄호 등 Windows 및 Chromium 파일 시스템 금지 특수문자를 언더스코어(`_`)로 자동 치환하여 `TypeError` 원천 차단.
2. **크롬 브라우저 다운로드 매니저 일원화**:
   - `trigger_client_save_as_dialog`를 Blob URL 기반 `a.download` 방식으로 통일하여, 타이어(`.tir`)와 프로젝트(`.pjt`) 저장 시 모두 크롬 우상단 다운로드 창에 진행 상태 및 파일이 동일하게 노출되도록 인터랙션 정합.
3. **전체 타이어 저장 안정화 (쇼다이렉터리피커 일괄 폴더 쓰기)**:
   - 크롬의 다중 다운로드 자동 차단(Silent Block) 문제를 해결하기 위해 `showDirectoryPicker`를 전면 복원하여, 1회 폴더 선택으로 프로젝트 내 모든 타이어(`.tir`)가 지정한 로컬 폴더에 압축 없이 100% 일괄 저장되도록 보장.
4. **타이어 저장 버튼 4열 마스터 그리드 밀착 배치**:
   - `[선택 타이어 저장]` 바로 옆에 `[전체 타이어 저장]` 버튼이 나란히 찰떡같이 밀착되도록 그리드 비율(`[1.0, 1.9, 0.6, 0.6, 0.9]`)을 최적화하고, 불필요한 ZIP 기능 완전 삭제.

### 🖼️ 2. 차트 뷰어 이미지 저장 정상화 및 우상단 확대 버튼 완전 소멸 (v4.12)
1. **플로터 공식 피규어 타이틀 기본 파일명 자동 연동 (0.png 결함 완전 해결)**:
   - Streamlit의 `alt="0"` 인덱스 강제 주입 버그를 규명하고, Figure 객체의 대제목(`_suptitle`) 및 `stImageCaption` 최우선 추출 파이프라인으로 `0.png`를 원천 박멸하여 `Braking_Test_Result_...png` 공식 타이틀로 100% 자동 다운로드되도록 완비.
2. **Same-Origin Base64 DataURL 무결 저장 파이프라인**:
   - 메인 창에서 Canvas를 통해 원본 차트의 순수 Base64 PNG DataURL을 추출하여 새창 뷰어로 전달함으로써, Chromium의 Cross-Origin 다운로드 차단 및 Canvas 오염 보안 에러를 완벽 회피하여 0초 만에 즉시 다운로드 보장.
3. **Streamlit 1.50+ 호환 차트 툴바(확대 버튼) 완전 소멸**:
   - Streamlit 1.50 신규 컴포넌트 `stElementToolbar` 및 버튼 셀렉터를 CSS에 전수 등록하여 숨김 처리하고, 자바스크립트 `MutationObserver` 2중 차단을 탑재하여 차트 마우스 호버 시 뜨던 거추장스러운 버튼을 완전히 소멸 (더블클릭 새창 뷰어로 단일 일원화).
