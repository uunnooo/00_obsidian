## 🚀 1. 진행 중인 핵심 프로젝트 (In Progress)

```dataview
TABLE WITHOUT ID
  file.link AS "프로젝트명",
  category_sub AS "세부 분야",
  date AS "기준일자",
  status AS "상태",
  tags AS "태그"
FROM "02_Projects"
WHERE type = "project" AND status = "진행중" AND file.name != this.file.name
SORT date DESC
```

## ⏳ 2. 프로젝트 상태별 현황판

```dataviewjs
const projs = dv.pages('"02_Projects"')
  .where(p => p.type === "project" && p.file.name !== dv.current().file.name);

const active = projs.where(p => p.status === "진행중").length;
const pending = projs.where(p => p.status === "대기").length;
const done = projs.where(p => p.status === "완료").length;

dv.paragraph(`
| 🚀 진행중인 프로젝트 | ⏳ 대기/준비중 | ✅ 완료된 프로젝트 | 📁 전체 프로젝트 수 |
| :---: | :---: | :---: | :---: |
| **${active} 개** | **${pending} 개** | **${done} 개** | **${projs.length} 개** |
`);
```
