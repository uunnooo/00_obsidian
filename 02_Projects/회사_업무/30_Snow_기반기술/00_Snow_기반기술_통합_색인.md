## 🤖 3. 환경 보정 후보 모델군 및 검토 현황

현재 보정 시스템은 특정 단일 알고리즘을 강제 고정하지 않고, **연구 목적과 평가 데이터 조건에 따라 유연하게 선택할 수 있는 다형성(Polymorphic) 체계**로 운용되고 있습니다:

```text
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                              환경 보정 머신러닝 후보군 및 적용 영역                        │
├───────────────────┬─────────────────────────────────────┬──────────────────────────────┤
│      후보 모델     │               적용 영역 및 역할      │       현재 검증 성과 및 특징   │
├───────────────────┼─────────────────────────────────────┼──────────────────────────────┤
│ Random Forest     │ • [Case 1] 눌림량 + 절대습도 (VIF 1.07)│ • R²=0.591, 물리 0.516m / 지수 2.89%p│
│ (주력 후보 1)     │ • [Case 3] 기온 + 상대습도 (VIF 2.53) │ • R²=0.544, 물리 0.495m / 지수 2.73%p│
├───────────────────┼─────────────────────────────────────┼──────────────────────────────┤
│ SVR (RBF Kernel)  │ • 마진 기반 이상치 저항 보정        │ • [Case 1] R²=0.458, 물리 0.538m │
│ (주력 후보 2)     │ • 매끄러운 비선형 등고선 곡면 형성  │ • 시험타이어 지수 MAE = 2.916%p│
├───────────────────┼─────────────────────────────────────┼──────────────────────────────┤
│ KNN Regressor     │ • 2D/3D 등고선 보정 맵 시각화       │ • [Case 3] R²=0.412, 물리 0.638m │
│ (보조 후보)       │ • 국소 거리 가중 곡면 보정          │ • 다중 스케일 StandardScaler 정합│
├───────────────────┼─────────────────────────────────────┼──────────────────────────────┤
│ 2D-KNN / LOESS    │ • 노면 센서가 없는 과거 7개년       │ • 동일 스펙 기준선 대비 잔차  │
│ (슬로프 모델)     │   기상 기반 공간 보정 (Method 2)    │   러프 평활화로 과적합 방어   │
├───────────────────┼─────────────────────────────────────┼──────────────────────────────┤
│ Ridge / Linear    │ • 물리적 단위당 감도 해석 기준선    │ • [Case 3] R²=0.362, 물리 0.636m │
└───────────────────┴─────────────────────────────────────┴──────────────────────────────┘
```

> [!TIP] 💡 최신 다중 모델 비교 시각화 및 다중 스케일 자동 정규화 탑재 (`v3.47`)
> 최신 파이썬 프레임워크(`unoUtil.snow_condition`)에 다중 스케일 피처($\max(\sigma_X)>2.5$) 감지 시 `StandardScaler`를 자동 결합하는 파이프라인과 기상/노면 인자별 동적 등고선 스케일링(`correction_map_comparison`, `scatter_restoration_comparison`)이 탑재되어, 노면 모델(`Case 1`)과 기상 모델(`Case 2`, `Case 3`)을 왜곡 없이 Side-by-Side로 직접 대조할 수 있습니다.

## 🏛️ 4. 사내 표준 프레임워크 연계 (`unoUtil.snow_condition`)

모든 스노우 환경 보정 알고리즘은 사내 표준 라이브러리인 **`unoUtil`** 12대 공식 도메인으로 이관되어 단일 공급원(SSOT)으로 관리됩니다:

* **소스 코드 위치**: `D:\uno\Python\Projects\unoUtil\unoUtil\snow_condition\`
* **7대 코어 모듈 구성**:
  1. `schema.py`: 47대 SSOT 표준 컬럼 명세 및 `harmonize_snow_dataframe()` 데이터 정규화 단일 관문.
  2. `physics.py`: Sonntag 증기압 공식 기반 상대습도 $\to$ 절대습도 변환 및 물리식.
  3. `surface_interpolator.py` / `surface_animator.py`: 3D 트랙 센서 공간 격자화 및 Plotly 애니메이션.
  4. `correction_model.py`: 6대 머신러닝 회귀 학습(다중 스케일 `StandardScaler` 자동 파이프라인 내장) 및 데이터프레임 일괄 보정 (`SnowCorrectionModel`).
  5. `correction_validator.py`: 1st(Ref) vs 2nd(Corr) 정밀 대조표 산출 및 오차 개선율 요약.
  6. `correction_plotter.py`: Figure 1~4 핵심 검증 차트, 기상/노면 동적 그리드 스케일링 및 Side-by-Side 멀티 모델 비교 시각화.
  7. `slope_model.py`: 과거 7개년 데이터 보정 전담 2D 공간 슬로프 보정 엔진 (`SnowSlopeModel`).
