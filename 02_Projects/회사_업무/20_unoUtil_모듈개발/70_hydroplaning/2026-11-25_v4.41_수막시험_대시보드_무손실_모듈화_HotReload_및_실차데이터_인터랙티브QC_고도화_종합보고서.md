# 🏎️ 수막 시험(Hydroplaning) 대시보드 무손실 모듈화, 핫리로드 엔진 장착 및 실차 계측 데이터 기반 인터랙티브 QC 고도화 종합보고서 (v4.41)

## 📌 1. 개발 배경 및 목적 (Background & Objectives)

1. **단일 모놀리식 파일의 유지보수 한계 극복**:
   - 기존 `hydroplaning/dashboard/dashboard_app.py`는 약 800라인에 달하는 단일 파일 내에 백엔드 시뮬레이션, 데이터프레임 정제, 직렬화, CSS 테마 주입, 5대 탭 렌더링 로직이 혼재되어 있어 유지보수성 및 확장성이 저하되어 있었습니다.
2. **제동/가속(`acc_brk`) 대시보드와 동일한 모듈화 표준 규격 확립**:
   - 최근 성공적으로 완료된 `acc_brk` 대시보드의 5대 모듈화 분할 체계(`engine.py`, `theme.py`, `components.py`, `tabs/`, `dashboard_app.py`)를 하이드로플래닝 대시보드에 1:1로 적용하여 전사 통합 대시보드 프레임워크의 아키텍처 일관성을 확보합니다.
3. **Streamlit 서브모듈 캐싱 결함 방어 (HotReload)**:
   - Streamlit의 기본 동작 특성상 `tabs/` 하위 모듈 수정 시 파이썬 `sys.modules`에 기존 바이트코드가 캐싱되어 브라우저 새로고침을 해도 화면이 갱신되지 않는 문제를 해결하기 위해 실시간 컴파일 기반 핫리로드 엔진을 도입합니다.
4. **실차 계측 데이터(태안 테크노링 IONIQ5) 기반 고속 데모 및 QC 워크플로우 혁신**:
   - 가상 난수 시뮬레이션을 폐기하고 실제 시험 데이터(`.VBO`) 기반의 고속 캐싱 로더를 구축하며, 엔지니어의 피팅 조작성을 극대화하기 위해 **좌측(Plotly 피팅 곡선) - 우측(랩 데이터 편집기) 1:1 가로 나란히(Same-Row) 배치**를 구현합니다.

## 🚀 3. 주요 개발 및 개선 내역 (Detailed Changelog)

### ① 5대 탭 분할 및 SSOT 직접 참조 체계 완결
- **`engine.py`**:
  - `StreamlitLiveConsole`: 실시간 배치 파이프라인 로그 스트리밍 콘솔 격리.
  - `_safe_pickle_dump`, `serialize_project_bytes`, `serialize_tire_bytes`: Streamlit 핫 리로드 시 클래스 불일치를 자동 치유하는 고신뢰성 직렬화 엔진.
  - `build_demo_hydro_project`: 실차 계측 캐시(`.pjt.gz`)를 기반으로 0.1초 만에 프로젝트를 로드하는 데모 팩토리.
- **`theme.py`**:
  - `acc_brk`의 마스터 CSS 원본을 직접 상속하고, 5대 메뉴(`Information`, `Load & Combination`, `Tire`, `Project`, `Weather`)에 맞추어 사이드바 버튼 SVG 아이콘 1:1 패치.
- **`components.py`**:
  - `style_pjt_summary_dataframe`: 컨트롤 타이어 기준행 라임 하이라이팅 스타일러 분리.
- **`tabs/` 패키지 분리**:
  - 기존 거대 함수들을 `tab_information.py`, `tab_load.py`, `tab_tire.py`, `tab_project.py`, `tab_weather.py`로 100% 독립 분리.

### ② 실시간 컴파일 기반 HotReload 엔진 도입 (`dashboard_app.py`)
- Streamlit이 `tabs/*.py` 파일 수정을 감지하지 못하던 치명적 캐싱 현상을 방어하기 위해 `acc_brk`의 입증된 핫리로드 루프를 이식:
  ```python
  importlib.reload(theme_mod)
  _tabs_dir = DASHBOARD_DIR / "tabs"
  for _tab_sub in ("tab_information", "tab_load", "tab_tire", "tab_project", "tab_weather"):
      _tab_py = _tabs_dir / f"{_tab_sub}.py"
      if _tab_py.exists():
          _sub_mod = getattr(tabs_mod, _tab_sub, None)
          if _sub_mod is not None:
              _src = _tab_py.read_text(encoding="utf-8")
              exec(compile(_src, str(_tab_py), "exec"), _sub_mod.__dict__)
  ```
- 이제 코드 수정 후 브라우저 새로고침(F5)만으로 모든 레이아웃 변경이 즉시 화면에 반영됩니다.

### ③ 탭 규격 정합: Save 탭 폐기 및 Weather 탭 직결
- 레거시 Save 탭을 영구 폐기하고, 제동/가속 대시보드의 `tab_weather.py`를 직접 호출하는 `render_tab_weather` 어댑터를 탑재하여 기상 마스터 데이터베이스 조회 기능을 1:1 공유.

### ④ Information 탭 5열 마스터 그리드 및 스펙·마킹 요약표 동기화
- 하드코딩된 더미 수심/수온 위젯을 전면 제거.
- `acc_brk`와 동일한 5대 메타데이터 그룹(기본정보, 차량, 위치/노면, 환경, 중량, 기상, 예비정보)을 5열 마스터 그리드로 칼정렬.
- 하단에 모든 타이어의 규격(Spec), 마킹, 세트명, 공기압 등을 일괄 수정할 수 있는 `st.data_editor` 기반의 [타이어별 스펙·마킹 요약] 테이블 및 ⛶ 팝아웃 버튼 완벽 연동.

### ⑤ Tire 탭 좌우 1:1 나란히(Same-Row) 인터랙티브 QC 뷰 구축
- **CSS 높이 충돌 해결**:
  - `div[data-testid="stHorizontalBlock"]:has(.group-title)` CSS가 컬럼 높이를 38px로 압축하던 현상을 방어하기 위해 각 섹션 헤더를 독립된 가로 행으로 분리.
- **Same-Row 1:1 배치**:
  - `col_graph, col_table = st.columns([1.35, 1.0])`
  - **좌측**: Plotly 산포도 & 다항식/토요타/스플라인 피팅 곡선 인터랙티브 그래프 (`height=470px`).
  - **우측**: 랩 데이터 편집기 (`st.data_editor`, `height=440px`).
  - 우측 표에서 랩 체크 해제 시, 좌측 피팅 곡선이 실시간으로 재피팅되어 Outlier 제거에 따른 커브 변화를 한눈에 관측 가능.
  - 종수막(HLO) 역시 동일하게 좌측 거리 vs 슬립율 그래프 + 우측 런 데이터 편집기로 1:1 대칭 정렬.
