## Executive Summary (핵심 성과 요약)

본 작업은 하이드로플래닝(수막 시험) 대시보드를 전사 모범 사례인 **가감속/제동 대시보드(`acc_brk`)의 입증된 UX 아키텍처와 100% 동일한 구조와 흐름으로 완전 일원화**하고, 기존의 합성 시뮬레이션 데이터를 폐기하여 **한국테크노링 실차 계측 원본(`26RE040033KF GOLF7`) 기반의 정규 벤치마크 데모**를 수립한 전면적 고도화 작업입니다.

1. **실차 계측 원본 데모 구축 (`26RE040033KF GOLF7`)**: 한국타이어(C1/T1), 미쉐린(T2), 콘티넨탈(T3), 피렐리(T4) 5대 브랜드 전 타이어의 HLA 189랩 및 HLO 35런 원본 계측 데이터를 사전 분석·캐싱(`demo_hydro_real_hla.pjt.gz`, `demo_hydro_real_hlo.pjt.gz`)하여 즉시 로딩 실현.
2. **Tire 탭 HLA/HLO Plotly 인터랙티브 QC 체계 완성**:
   - **HLA (횡수막)**: `[피팅(2.5) : 로컬좌표 궤적(2.5) : Lap테이블(1.0)]` 3열 다크 테마 레이아웃, 선 색상-테이블 컬러 칩 1:1 연동, 범례 3종 고정(라벨 팽창 방지).
   - **HLO (종수막)**: `[거리vs속도(1.67) : 속도vs슬립율(1.67) : 거리vs슬립율(1.67) : Run테이블(1.0)]` 4열 인터랙티브 체계 구축, 클릭/체크박스 실시간 필터링.
   - **세션 흐름 정합**: `[평가 설정 ➡️ 유효데이터 선택 ➡️ 타이어(.tir) 저장 ➡️ 2열 그래프 선택 뷰어]` 순서로 재정렬.
3. **Project 탭 제동가속 표준 4대 섹션 체계 구축**:
   - `[성능보정 설정 ➡️ 요약 테이블 ➡️ 프로젝트(.pjt) 저장 ➡️ 2열 비교 그래프 다중 선택 뷰어]`
   - `PlotterProject`에 단독 비교 메서드 5종 분리 및 `st.multiselect` 2열 고정 렌더러 탑재.
4. **Load 탭 제동가속 표준화 및 완전 자동화 파이프라인**:
   - 불필요한 예제 바로가기 섹션 및 수동 설정 UI 삭제. 대상 폴더 탐색 시 HLA/HLO 전자동 감지 및 `n_jobs=-1` 풀코어 병렬 처리 상시 적용.
   - `[계측 데이터 분석 ➡️ .pjt/.tir 파일 불러오기 ➡️ 통합 병합 ➡️ 프로젝트 목록]` 4대 섹션 완성.
5. **v2 과도기적 레거시 소멸**: 임시 별칭(`render_tab_load_combination`) 및 분기 코드를 완전 제거하고 단일 표준 `Load` 및 `render_tab_load`로 직교화.

## 2. Tire 탭: HLA/HLO Plotly 인터랙티브 QC 체계

### 2.1 HLA (횡수막) 3열 인터랙티브 QC (`2.5 : 2.5 : 1.0`)
- **[피팅 그래프 (너비 2.5)]**: 속도-횡가속도 산포도 및 피팅 곡선(Poly/Toyota/Spline) 실시간 표출, 박스/올가미 선택으로 제외/복원 지원.
- **[로컬 주행 궤적 그래프 (너비 2.5)]**: 선회 중심점 기준 이상 원호(R=103m), 랩별 궤적, 진입/탈출 지점을 Plotly 다크 테마로 구현. 종횡비 1:1(`scaleanchor="x"`) 유지.
  - **범례 3종 고정**: 개별 랩 범례를 숨기고 `Ideal Lane (R=103m)`, `Lap (실선)`, `제외 Lap (점선)` 3종으로 고정하여 랩 제외 시 범례가 팽창하는 문제 차단.
- **[Lap 데이터 테이블 (너비 1.0)]**:
  - `Valid` (너비 32px), `Color` (너비 28px, SVG 원형 컬러 배지), `Lap` (너비 42px), `속도(kph)` (너비 74px), `횡G(g)` (너비 70px)
  - 가로 횡스크롤 완전 제거 (총합 폭 약 246px) 및 높이 470px 수직 정렬.
  - 로컬 궤적 선 색상과 테이블 컬러 배지를 1:1로 일치시켜 별도의 그래프 라벨 없이도 몇 번 Lap인지 즉시 식별.

### 2.2 HLO (종수막) 4열 인터랙티브 QC (`1.67 : 1.67 : 1.67 : 1.0`)
- **[차트 1: Distance vs Velocity]**: Water Basin Zone(0~100m) 음영, Entry(0m) 수직선, 런별 감속 프로파일.
- **[차트 2: Velocity vs Slip Ratio]**: Target Slip(15.0%) 기준 수평선, 피크 슬라이싱 적용된 속도별 슬립율 곡선.
- **[차트 3: Distance vs Slip Ratio]**: 주행 거리별 슬립율 거동 및 한계 통과 거리 분석.
- **[Run 데이터 테이블]**: HLA와 100% 동일한 폭(1.0)으로 우측 배치, 런별 컬러 배지 및 실시간 체크박스 필터링 연동.

### 2.3 세션 흐름 및 타이어 저장 정합
- `[평가 설정 ➡️ 유효데이터 선택 ➡️ 타이어(.tir) 저장 ➡️ 2열 그래프 선택 뷰어]` 순서 정합.
- `타이어(.tir) 저장`: 파일명 입력창(2.0열) + `[.tir 다운로드]`(0.8열) + `[요약 CSV 다운로드]`(0.8열)의 5열 마스터 그리드 정합.
- `그래프`: `st.multiselect`로 보고 싶은 물리 차트를 선택하여 **무조건 2열 그리드(`st.columns(2)`)**로 나란히 렌더링.

## 3. Project 탭: 제동가속 표준 4대 섹션 체계

```
[섹션 1: 성능보정 설정]
  ├── 보정 방식 (control / none), 기준 타이어 키워드 (ref_kwd), 보정 적용 버튼
[섹션 2: 테이블 (프로젝트 타이어별 성능 요약 · 보정 결과)]
  └── style_pjt_summary_dataframe을 통한 컨트롤 보정 지표(MaxLatAcc, V1, V2, Area, Index 등) 하이라이팅
[섹션 3: 프로젝트(.pjt) 저장]
  └── 파일명 입력창 + [.pjt 다운로드] + [요약 CSV 다운로드] (5열 마스터 그리드)
[섹션 4: 그래프 (PlotterProject 2열 다중 선택 뷰어)]
  └── st.multiselect 기반 2열 나란히 보기 렌더러
```

- **`PlotterProject` 모듈화 리팩터링**:
  - HLA: `compare_trajectory(...)`, `compare_lateral_acc(...)` 분리
  - HLO: `compare_profile(...)`, `compare_slip_velocity(...)`, `compare_slip_distance(...)` 분리

## 4. Load 탭: 완전 자동화 및 제동가속 표준화

1. **`4대 표준 예제 폴더 바로가기` 섹션 및 수동 설정 제거**:
   - 하드코딩된 예제 폴더 버튼 삭제.

2. **제동가속 표준 4대 섹션 완성**:
   - `계측 데이터 분석`: 5열 마스터 그리드 (경로 입력 + 폴더/파일 찾기 토글) + 실시간 LiveConsole
   - `프로젝트(.pjt) 및 타이어(.tir) 불러오기`: 드래그 앤 드롭 파일 업로더
