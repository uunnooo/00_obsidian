# 🏎️ 가감속/제동 대시보드 v2.0(v4.21) 백엔드 SSOT 전면 연동 및 브라우저 네이티브 디렉토리 안정화 종합보고서

## Executive Summary

본 보고서는 사내 파이썬 실차 데이터 분석 프레임워크 **`unoUtil v2.0`**의 핵심 웹 시각화 도구인 **가감속/제동 통합 인터랙티브 웹 대시보드(`dashboard_app.py`, 10,300+ 라인)**에서 발생하던 5대 고질적 결함(하드코딩 산재, 드래그앤드롭 시각 피드백 부재, 개발용 `test_data` 절대경로 오매칭, `TireCurve` 순환 참조 크래시, 자바스크립트 가짜 이벤트 차단 및 `MutationObserver` 무한 루프로 인한 브라우저 프리징)을 근본적으로 해결하고, **단일 진실 공급원(SSOT) 아키텍처와 웹 표준(HTML5 네이티브) 정공법으로 전면 개편**한 엔지니어링 기록입니다.

---

## 1. 배경 및 문제점 (5대 핵심 결함)

1. **대시보드 내 리터럴 하드코딩 산재**:
   - 의뢰번호 정규식, 지원 노면(`dry`, `wet`, `snow`, `ice`), 시험항목(`brk`, `acc`), 유효 확장자, 물리 단위(`Unit.G`, `Unit.MPS2KPH`), 15+종 분석기 파라미터가 대시보드 내부에 분산 하드코딩되어 백엔드 코어 모듈 변경 시 동기화 누락 위험 존재.
2. **드래그앤드롭 시각적 피드백 부재**:
   - 사용자가 Windows 탐색기에서 폴더나 파일을 끌고 올 때 올바른 드롭존 영역인지 명확한 안내가 없고, 드롭 직후 0.3~0.5초 통신 지연 동안 아무런 시각 피드백이 없어 사용자가 수신 여부를 확신하지 못함.
3. **디스크 실제 절대경로 역추적 오매칭 (`test_data` 가로채기)**:
   - 사용자가 `D:\uno\1.2026\...\run2`를 드롭했음에도, 탐색기 1순위가 `DEFAULT_TEST_DATA_DIR`로 설정되어 소스 코드 내 샘플 폴더(`unoUtil/test_data/acc_brk/.../run2`)가 먼저 발견되어 오매칭되는 버그 발생.
4. **`TireCurve` 순환 참조(Circular Import) 크래시**:
   - `acc_brk/__init__.py` 최상단에서 `TireCurve`를 즉시 임포트하면서 `cf_tire.py`와 양방향 순환 참조가 발생하여, 전체 비우기(Clear all) 시 Streamlit이 Rerun될 때 페이지가 뻗어버림.
5. **브라우저 폴더 선택(Browse files) 가짜 이벤트 차단 및 무한 루프 프리징**:
   - 자바스크립트로 클릭을 가로채서 `showDirectoryPicker`를 열고 인위적인 합성 이벤트(`DragEvent`, `change`)를 주입하려 했으나, 최신 React 18 및 크롬 샌드박스가 가짜 이벤트를 신뢰하지 않고 100% 차단함.
   - 또한 `MutationObserver`가 attributes 변경을 감시하면서 콜백에서 `setAttribute`를 매번 실행하여 초당 수만 회의 무한 루프가 발생, 브라우저가 완전히 얼어붙음(Freeze).

## 2. 핵심 엔지니어링 해결 조치

### 2.1 단일 진실 공급원(SSOT) 전면 동적 연동
- **의뢰번호 SSOT**: `TestInformation.extract_req_no()` 및 `REQ_NO_PATTERN` 정규식 연동.
- **가감속 도메인 SSOT**: `vt_acc_brk` 모듈의 `RAW_DATA_EXTENSIONS`, `SUPPORTED_SURFACES`, `SUPPORTED_ITEMS`, `SURFACE_PATTERNS`, `ITEM_PATTERNS`, `parse_surface_and_item()` 동적 참조.
- **물리 단위 SSOT**: `Unit.G` (9.80665), `Unit.MPS2KPH` (3.6), `Unit.KPH2MPS` (1/3.6) 공식 상수 적용으로 물리 엔진 오차 완전 제거.
- **계층 파라미터 SSOT**: 15+종 파라미터에 `resolve_hierarchical_param`을 연동하여 런처 ➔ 함수 ➔ 대시보드 3단 상속 체계 완성.
- **Weather 탭 전면 고도화**: 3초 자동 소멸 `st.toast()`, `mkdtemp` 세션별 격리, [4대 KPI] ➔ [마스터 테이블 & 멀티셀렉트] ➔ [100% 풀 와이드 Base64 고해상도 차트] 순서 재배치 및 우측 여백 버그 완전 박멸.

### 2.2 전 영역 3단계 스마트 드래그앤드롭 네온 피드백 시스템
- **1단계 (Drag Over)**: 마우스가 드롭존에 진입하면 즉시 1.015배 확대되며 테두리가 눈부신 네온 라임(`#BEF264`)으로 펄스 발광 (`.uno-drag-over`).
- **2단계 (Drop Success)**: 마우스를 놓는 순간 0.95초간 에메랄드 사이버 시안(`#00F0FF`) 네온 펄스 애니메이션(`@keyframes unoDropSuccessPulse`)이 촤라락 번쩍이며 수신 성공 피드백 전달.
- **3단계 (Data Loaded)**: 메인 화면 사파이어 블루 파일 관리 테이블에 즉시 자동 표출.
- 대시보드 내 5대 업로더(원시데이터 폴더/파일, 객체 로더, 기상 DB 로더, 테크노링 빌더) 전수 일원화 적용.

### 2.3 디스크 실제 절대경로 역추적 우선순위 교정
- 탐색 우선순위를 재설계하여 개발용 `test_data`를 최하위 폴백으로 강등:
  - 1순위: 최근 확인된 실제 업무 디렉토리 (`_RECENT_RESOLVED_DIRS`)
  - 2순위: `D:/uno` 직속 실제 업무 데이터 디렉토리 (`D:/uno/1.2026`, `0.DB` 등)
  - 3순위: 사용자 홈 디렉토리 (`Desktop`, `Downloads`, `Documents`)
  - 4순위: Windows 실제 데이터 드라이브 (`D:\`, `E:\`, `C:\`)
  - 5순위 (최하위): `DEFAULT_TEST_DATA_DIR`
- `_is_test_path` 2중 가드를 적용하여 실제 업무 데이터를 발견하면 0.11초 만에 100% 우선 선택 반환.

### 2.4 `TireCurve` 순환 참조 지연 로딩(`__getattr__`) 전환
- `unoUtil/vehicle_test/acc_brk/__init__.py` 최상단 즉시 임포트를 제거하고, `__getattr__` 훅 내부에서 온디맨드로 임포트되도록 전환하여 `cf_tire.py`와의 순환 참조를 원천 차단.

### 2.5 브라우저 표준 네이티브 `webkitdirectory` 전환 및 무한 루프 해소
- **250줄의 불안정한 자바스크립트 누더기 코드 완전 폐기**: 클릭을 가로채서 `showDirectoryPicker`를 호출하고 합성 이벤트를 억지로 주입하려던 모든 코드를 깨끗이 걷어냄.
- **HTML5 `webkitdirectory` 네이티브 표준 직결**: `<input type="file">`에 `webkitdirectory`, `directory`, `multiple` 속성을 브라우저 네이티브로 상시 주입하여, 사용자가 Browse files 버튼을 클릭하면 브라우저 C++ 엔진이 직접 OS 폴더 선택창을 열고 100% 신뢰할 수 있는 네이티브 이벤트(`isTrusted=True`)로 파일들을 서버로 전송하도록 정돈.
- **`MutationObserver` 무한 재귀 루프 제거**: `attributes: true` 감시를 완전 삭제하고 `hasAttribute` 가드를 걸어 브라우저 메인 스레드 100% CPU 프리징을 완벽히 해결.
