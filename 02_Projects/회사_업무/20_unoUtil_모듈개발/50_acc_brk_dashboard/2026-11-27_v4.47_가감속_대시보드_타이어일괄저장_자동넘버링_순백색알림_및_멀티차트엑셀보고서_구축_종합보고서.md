## 🎯 1. 개발 배경 및 목적 (VOC & Objectives)

1. **타이어 일괄 저장 브라우저 다중 다운로드 불편 해소 및 파일 보존 요구**:
   - 기존의 브라우저 기반 다중 다운로드 시 Chrome 브라우저의 다운로드 확인 대화상자가 파일 개수만큼 반복해서 뜨거나 원치 않는 다운로드 폴더로 저장되는 문제를 해결.
   - 폴더를 단 한 번만 선택하면 각 타이어의 지정된 표준 이름(`[req]_[surface]_[item]_[cond]_[vel_tag]_[set].tir`)으로 즉시 로컬 디스크에 일괄 저장되도록 개편.
   - 특히 동일한 이름의 파일이 폴더 내에 이미 존재할 경우, 기존 파일을 덮어쓰지 않고 `_1`, `_2` 등의 증분 넘버링으로 기존 파일과 신규 파일을 모두 안전하게 보존하도록 구현.

2. **대시보드 전 탭 알림 시스템의 시인성 및 일관성(SSOT) 결여 해결**:
   - 탭마다 제각각으로 `st.warning`, `st.error`, `st.success`, `st.info`를 호출하여 화면 공간을 영구적으로 차지하거나 우측 구석에 번잡한 `st.toast`가 뜨는 파편화된 UI를 단일 진실 공급원(`_render_auto_dismiss_alert`)으로 일원화.
   - 어두운 배경 위에서 틴트 글씨가 묻히는 문제를 해결하기 위해, 본문 글씨를 **고대비 순백색(`#FFFFFF`, 700 bold)**으로 통일하고 외곽 테두리와 글로우만 **성공: 네온 바이올렛(`#C084FC`) / 경고·실패: 네온 레드(`#F87171`)**로 입혀 시인성을 극대화하며 3.6초 후 공간까지 부드럽게 자동 소멸하도록 개선.

3. **기상(Weather) 탭 이모지 전수 제거 및 제목 직관화**:
   - 기상 DB 로드 성공 시 붙던 초록색 동그라미(`🟢`) 및 탭 전반에 흩어져 있던 불필요한 이모지(`⚠️`, `❌`, `📁`, `🌤️`, `💡`, `📋`, `📈` 등)를 전수 제거하여 군더더기 없는 전문적 엔지니어링 텍스트로 정제.
   - 소제목을 간결하고 직관적인 `마스터 테이블 (최근내역)` 및 `그래프`로 개편.

4. **하이드로 대시보드의 보고서 내보내기 기능 1:1 이식 및 고도화**:
   - `hydroplaning/dashboard`의 프로젝트 탭에서 호평받은 세션 3(`[프로젝트 저장]`, `[요약 CSV]`, `[엑셀 보고서]`) 5열 마스터 그리드 구조를 ACC/BRK 프로젝트 탭에 그대로 이식.
   - 특히 엑셀 보고서(`Summary` 시트) 상단에 사용자가 선택한 비교 그래프들을 순서대로 고해상도 이미지로 삽입하고, 하단에 시험 기본정보, 제동거리/가속시간, 반복표준편차, 인덱스를 집약한 정밀 요약 테이블을 배치하는 완성형 보고서 파이프라인 수립.

## 🛠️ 2. 핵심 개발 및 개선 내역 (Core Deliverables)

### 1) 타이어 일괄 저장 로컬 원클릭 폴더 선택 및 자동 넘버링 보존
* **`select_directory_dialog` GUI 다이얼로그 연동**:
  - `tabs/tab_tire.py`의 `[전체 타이어 저장]` 클릭 시, 화면 최상단(topmost)에 Windows 폴더 찾아보기 대화상자가 팝업되어 저장 대상 폴더를 1회 선택.
  - 직전 저장 폴더를 `st.session_state`에 기억하여 재탐색 편의성 제공.
* **`save_all_tires_to_directory` 및 `SavedTireFilesList` 구현 (`engine.py`)**:
  - 지정된 폴더에 프로젝트 내 모든 타이어 객체를 표준 명명 규칙으로 일괄 직접 저장.
  - `auto_numbering=True` 지원: 대상 폴더에 이미 동일 파일명이 존재할 경우, 기존 파일을 절대 덮어쓰지 않고 `_1`, `_2`, `_3`... 증분 넘버링을 자동 부여하여 안전 보존.
  - 완료 시 넘버링 적용 현황(`(기존 파일 보존을 위해 N개 자동 넘버링 적용)`)을 성공 메시지에 명시.

### 2) 전 탭 알림 시스템 순백색 + 네온 바이올렛/레드 3.6s 자동 소멸 모듈화
* **SSOT 알림 함수 `_render_auto_dismiss_alert` 전면 개편 (`theme.py`, `engine.py`)**:
  - **본문 텍스트**: 완전한 고대비 순백색 (`#FFFFFF`, 700 bold, letter-spacing -0.01em)으로 통일하여 가독성 100% 확보.
  - **성공 (`success`)**: 딥 다크 바이올렛 배경 + 선명한 **네온 바이올렛 1.5px 테두리 (`#C084FC`)** + 네온 발광 글로우 + `✔️` 아이콘.
  - **경고 / 실패 (`warning`, `error`)**: 딥 다크 레드 배경 + 선명한 **네온 레드 1.5px 테두리 (`#F87171`)** + 네온 발광 글로우 + `⚠️` / `❌` 아이콘.
  - **3.6초 자동 소멸**: CSS 키프레임 애니메이션으로 3.6초 후 페이드아웃되며 높이, 패딩, 마진까지 완전히 0px로 축소되어 화면 공간 낭비 방지.
  - **우측 토스트(`st.toast`) 전면 배제**: 화면 우측 구석에 번잡하게 뜨던 팝업을 원천 차단.
* **5대 탭 전수 적용**:
  - `tab_weather.py`: 19개 지점의 `st.warning`/`st.error`/`st.info`를 전면 교체.
  - `tab_information.py`: 공통 정보 및 메타데이터 수정 반영 피드백을 세션 기반 네온 알림으로 연결.
  - `tab_project.py`: 보정 경고 및 그래프 미선택 경고를 네온 레드로 일원화.
  - `tab_tire.py`: 런 체크 경고, 그래프 미선택 경고 및 일괄 저장 결과를 공통 알림으로 일원화.
  - `tab_load.py`: 경로 에러, 파일 미선택 경고 및 객체 제거/비우기 완료 알림을 일원화.

### 3) 기상(Weather) 탭 이모지 전수 제거 및 UI 명칭 정제
* **초록색 동그라미(`🟢`) 및 이모지 완전 삭제**:
  - 로드 성공 메시지: `기상 마스터 데이터베이스 로드됨 (총 N건 관측 데이터 | 파일: ...)` (초록 동그라미 제거)
  - 탭 내 모든 메시지, 헤더, 툴팁에 포함되어 있던 `⚠️`, `❌`, `📁`, `🌤️`, `💡`, `📋`, `📈` 전수 제거.
* **소제목 직관화**:
  - `최근 기상 데이터프레임 내역 (마스터 테이블)` ➔ **`마스터 테이블 (최근내역)`**
  - `선택 기상 센서 시계열 트렌드 차트 (16:10 테크 차트)` ➔ **`그래프`** (불필요한 '16:10 테크 차트' 수식어 제거)

### 4) 프로젝트 탭 요약 CSV 및 멀티시트 정밀 엑셀 보고서 이식
* **5열 마스터 그리드 정합 (`tabs/tab_project.py`)**:
  - `[프로젝트 파일명 (.pjt)]` : `[프로젝트 저장 (.pjt)]` : **`[요약 CSV (.csv)]`** : **`[엑셀 보고서 (.xlsx)]`** : `_grid_spacer()`
  - 사용자 지정 순서(요약 CSV ➔ 엑셀 보고서) 완벽 반영.
* **`[요약 CSV (.csv)]` 내보내기**:
  - `project.result.summary_all` (또는 `summary`) 종합 성능 요약표를 UTF-8 BOM(`utf-8-sig`) 단일 CSV 파일로 즉시 다운로드 (엑셀 한글 깨짐 방지).
* **`[엑셀 보고서 (.xlsx)]` (`export_project_excel_report`)**:
  - **`Summary` 시트 상단**: 프로젝트 탭의 `chosen_pjt_plots`에서 선택된 비교 차트들을 순서대로 고해상도(110 DPI) 이미지로 렌더링하여 차례로 삽입.
  - **`Summary` 시트 하단**: 그래프 바로 아래에 정밀 요약 테이블 배치:
    - 기본 정보: `세트 (Set)`, `규격 (Spec)`, `마킹/패턴 (Marking)`, `차량 (Vehicle)`, `노면 (Surface)`
    - 성능 지표: 제동 시 `실측 제동거리 [m]`, `보정 제동거리 [m]` / 가속 시 `실측 가속시간 [s]`, `보정 가속시간 [s]` (모드 자동 판별)
    - 반복표준편차: 유효 회차(Run)들의 통계적 표준편차 (`반복표준편차 [m]` / `반복표준편차 [s]`)
    - 인덱스: 기준 타이어(C1) 대비 상대 성능 백분율 (`인덱스 [%]`, 100% 기준)
    - 다크 네이비 헤더, 얇은 테두리, Zebra 스트라이핑 배경, 소수점 자릿수 서식 자동 적용.
  - **타이어별 런 상세 시트 (`{t_k}_RunDetail`)**: 각 타이어 세트별 회차별 세부 원시 계측 데이터를 개별 시트로 멀티 패키징.
