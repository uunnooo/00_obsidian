# 🏎️ 가감속/제동 대시보드 v2.0(v4.24) 공식 매뉴얼 실화면 1:1 최신화 및 로딩 UI 단일 표준화 종합보고서

> **작성일자**: 2026년 11월 18일

## Executive Summary

본 보고서는 사내 파이썬 실차 데이터 분석 프레임워크 **`unoUtil v2.0+`**의 핵심 웹 시각화 도구인 **가감속/제동 통합 인터랙티브 웹 대시보드(`dashboard_app.py`)** 및 공식 프레젠테이션 매뉴얼(`ACC_BRK_DASHBOARD_USER_MANUAL.pptx`)의 전면 고도화 기록입니다.

최신 대시보드 v2.0의 실제 운영 화면을 **16:9 Full HD 무왜곡 실물 규격(1904x929)**으로 자동 캡처하여 매뉴얼 7개 핵심 슬라이드에 1:1 교체 탑재하였으며, 사이드바 5대 탭 아이콘 전수에 네온 바이올렛 포인트를 정밀 주입하였습니다. 아울러 '신규 분석 실행(터미널 콘솔 로그)' 단 하나를 제외한 모든 버튼 액션과 파일 로딩 인터랙션을 **'그리기 버튼'과 100% 동일한 다크 네온 회전 스피너(`st.spinner`) 단일 표준 규격으로 통일**하고, 타이어 순서정렬 세부설정 UI 초간결화 및 전치요약표/성능지수요약표 새창 확대 인덱스 복원을 완벽하게 완료하였습니다.

## 1. 주요 개발 및 개선 내역 (8대 핵심 과업)

### 1-1. 공식 PPTX 사용자 매뉴얼 실화면 1:1 최신화 (`ACC_BRK_DASHBOARD_USER_MANUAL.pptx`)
- **16:9 Full HD 무왜곡 실물 규격 전면 캡처**:
  Selenium Headless 브라우저를 통해 최신 v2.0 실화면을 1904x929 해상도로 정밀 캡처하여 슬라이드 1(타이틀), 6(Tab 1 계측 파일 관리), 7(Tab 2 정렬·요약표·저장), 8(Tab 2 14종 비교 차트), 9(Tab 3 런 편집 및 5열 저장 그리드), 10(Tab 3 심층 차트 및 뷰어 무결 저장), 11(Tab 5 Weather 인라인 업로더) 배경을 1:1 전면 교체.
- **최신 기능 명세 텍스트 정합**:
  슬라이드 콜아웃 및 본문 설명에 네온 바이올렛 인라인 토글 업로더, 5열 마스터 그리드 밀착 배치, 사파이어 블루 실시간 하이라이트 등 최신 명세를 완벽 동기화.
- **작업용 백업본 분리 보존**:
  파워포인트 동시 작업 충돌을 방지하기 위해 `ACC_BRK_DASHBOARD_USER_MANUAL_2.pptx`로 추가 분리 저장.

### 1-2. 사이드바 5대 탭 아이콘 네온 바이올렛 포인트 튜닝 (`STYLE_B_SVG_B64`)
- 기존 Weather 탭의 노면 센서 파형과 동일한 톤앤매너로 5대 탭 아이콘 전수에 **네온 바이올렛/퍼플(`rgba(192, 132, 252, ...)`, `#C084FC`)** 국소 발광 포인트를 주입:
  - ℹ️ **Information**: 대/소형 기어 내부 코어 링 및 체크리스트 중앙 항목 악센트
  - 📂 **Load & Combination**: 데이터 문서 상단 틴트, 결합 화살표 경로 및 수용 독 언더바
  - 🛞 **Tire**: 알로이 휠 림과 트레드 사이 텔레메트리 센서 링 및 휠 센터 허브 코어 (배경 홀로그램 차량 바퀴 발광색과 1:1 일치)
  - 📊 **Project**: 중앙 메인 타이어 텔레메트리 코어 링 및 좌/우 후방 타이어 센터 허브
  - 🌤️ **Weather**: 기존 세련된 노면 온도 센서 파형 라인 보존 및 완벽한 시각적 일체감 형성

### 1-3. 작업 진행 로딩/피드백 UI의 '그리기 버튼' 기준 100% 단일 표준화
- **예외 유지**: 수십 개 파일의 실시간 로그가 흐르는 `[신규 데이터 분석 실행]` 단 하나만 `StreamlitLiveConsole` 터미널 콘솔 유지.
- **단일 표준 적용**:
  - 보정 적용(`btn_apply_corr`), 타이어 설정 재연산(`btn_reanalyze_tire`), 런 재분석(`btn_re_run_top`), 차트 그리기(`btn_draw`), 통합 병합(`btn_combine_run`), 기상 DB 연결(`btn_connect_to_pjt`), 기상 DB 로드/빌드 전수를 **`div[data-testid="stSpinner"]` 다크 네온 회전 스피너(`border: 1.6px solid #A3FF12`)**로 일원화.
  - 연산 완료 시 거추장스러운 우측 상단 토스트(`st.toast`)나 화면 밑에 덜컥 열리던 까만 콘솔창 없이 **스피너가 깨끗하게 싹 사라지도록(Auto-Dismiss)** 정합.
- **보정 적용 시 강제 자동 그리기 버그 완전 소멸**:
  - `st.session_state[auto_redraw_key] = True` 플래그를 완전 제거하여, 보정 적용 시 멋대로 아래쪽 프로젝트 비교 그래프 전체가 다시 렌더링되던 문제를 원천 차단.

### 1-4. 파일 드래그앤드롭 렉 해소 및 0초 즉각 네온 스피너 상태 머신 구축
- **브라우저 파일 전송 렉 원천 해결**:
  파이썬 코드가 돌기 전 브라우저에서 서버로 파일 바이트가 전송되는 동안 발생하는 멍때림(렉)을 해소하기 위해, 사용자가 마우스를 놓는 0.001초 순간 섹션 상단 앵커에 그리기 버튼과 100% 동일한 다크 네온 회전 스피너를 즉각 렌더링.
- **정밀 상태 머신(State Machine) 라이프사이클 연동**:
  1. `[파일 드롭/선택]` ➔ 스피너 0초 즉각 노출 (전송 중 회전 유지)
  2. `[파이썬 실행 시작]` ➔ 우측 상단 `stStatusWidget(RUNNING)` 감지
  3. `[파이썬 실행 종료]` ➔ 우측 상단 스트림릿 스피너가 꺼지는 바로 그 순간 0.08초 만에 스피너가 칼같이 즉시 소멸.

### 1-5. 타이어 순서 정렬 세부설정 UI 초간결화
- 기존의 불필요한 이중·삼중 뎁스(`st.expander` ➔ `st.tabs` ➔ `st.checkbox` ➔ 순서 바)를 전면 삭제.
- 이제 토글을 열면 곧바로 마우스 드래그 바(`# 1. C1, # 2. C2 ...`)와 우측 `[정렬 반영]` 버튼이 1줄로 즉시 표출되어 원클릭으로 순서를 재배치할 수 있도록 대폭 간결화.
- Rerun 시 토글이 멋대로 접히지 않도록 세션 상태(`exp_pjt_order_{pjt}`)로 열림/닫힘 상태 보존.

### 1-6. 전치요약표 및 성능지수요약표 새창 확대 인덱스 복원 (`render_table_popout_button`)
- `active_pjt.make_summary()` 및 `make_summary_index()`의 행 인덱스(`TestReqNo`, `brk_mean`, `index_brk_mean` 등)가 새창 확대 시 통째로 누락되던 결함 해결.
- 의미 있는 행 인덱스를 자동 감지하여 첫 번째 컬럼에 `항목 / 지표` 헤더와 함께 인덱스 라벨을 온전히 렌더링하도록 개편하고, 팝업 내 `[💾 CSV 다운로드]` 시에도 지표명이 100% 정상 저장되도록 보장.

### 1-7. 기상 DB 불러오기/빌드/연결 실시간 화면 갱신 완비
- 기상 파일 업로드 시 백그라운드 메모리 로드(`load_master_database`) 직결.
- `[불러오기]` 및 `[DB 빌드]` 성공 시 `st.rerun()`을 호출하여 4대 기상 KPI(수집 기간, 외기온도, 노면온도, 풍속)와 16:10 시계열 트렌드 차트가 즉시 활성화되도록 연동, 이질적이던 `st.toast` 완전 소멸.

### 1-8. 가용 포트 자동 탐색 엔진 탑재 (`_find_available_port`)
- `launch_dashboard()`에 `_find_available_port()`를 장착하여, PyCharm이나 타 프로세스가 8501 포트를 선점하고 있더라도 에러로 뻗지 않고 자동으로 다음 빈 포트(8502, 8503...)를 탐색하여 기동하도록 안전 폴백 구축.
