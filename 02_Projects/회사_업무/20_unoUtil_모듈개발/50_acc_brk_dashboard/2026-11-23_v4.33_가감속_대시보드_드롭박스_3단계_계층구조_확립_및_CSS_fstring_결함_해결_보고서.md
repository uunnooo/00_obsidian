# 🏎️ 가감속/제동 대시보드 v4.33 드롭박스·입력창 UI 3단계 계층 구조 확립 및 결함 해결 종합보고서

> [!ABSTRACT] 🚀 핵심 개요
> 본 보고서는 `unoUtil.vehicle_test.acc_brk.dashboard` 모듈의 시각 디자인 및 인터랙션 시스템을 정비하여,
> 1. 모든 일반 폼 입력창(`st.text_input`, `st.number_input`, `st.selectbox`, `st.multiselect`)의 UI 위계를 **[UI 계층 3단계 아키텍처]**로 명확히 정립하고,
> 2. 기존 Streamlit BaseWeb의 무차별 하위 자손 투명화 선택자로 인해 발생하던 **일반 드롭다운(`st.selectbox`)의 배경 투명화 및 테두리 증발 결함**을 원천 해결하며,
> 3. `theme.py` 내 f-string 템플릿의 CSS 중괄호 이스케이프 누락으로 인한 치명적 런타임 에러 **`NameError: name 'background' is not defined`**를 완벽하게 조치하고 하단 중복 CSS 98줄을 영구 소멸시킨 통합 엔지니어링 개발 보고서입니다.

---

## 🔍 1. 배경 및 문제 분석

### 1.1. 드롭다운 컨트롤 UI 파편화 및 투명화 결함
- **문제 현상**:
  - 일반 텍스트 입력창(`st.text_input`)과 숫자 입력창(`st.number_input`)은 다크 배경(`color_bg_dark`), 42px 고정 높이, 슬레이트/라임 테두리, 마우스 호버 시 네온 라임 발광 오라를 완벽히 유지하고 있었으나,
  - **일반 단일 드롭박스(`st.selectbox`)만 배경이 투명하게 비치고 테두리 박스가 소실**되어 시각적 일체감이 크게 훼손됨.
  - 동시에 CSS 내부에 드롭박스 관련 선택자가 여러 계층(티어)으로 중복·난립하여 유지보수성이 저하되어 있었음.
- **원인 분석**:
  - 기존 CSS에 선언된 와일드카드 자손 선택자 `div[data-testid="stSelectbox"] div[data-baseweb="select"] div { background: transparent !important; }`가 문제였음.
  - Streamlit BaseWeb의 구조상 `div[data-baseweb="select"]` 바로 밑의 최외곽 컨테이너(`StyledControlContainer`)까지 위 선택자에 매칭되어, 외곽선과 다크 배경 스타일이 일괄 제거되면서 박스가 증발하는 현상이 발생함.

### 1.2. `NameError: name 'background' is not defined` 런타임 크래시
- **문제 현상**:
  - `streamlit run dashboard_app.py` 구동 시 `theme.py`의 `_get_dashboard_css()` 함수 1789번 라인에서 `NameError: name 'background' is not defined`가 발생하며 대시보드 기동이 즉시 중단됨.
- **원인 분석**:
  - `_get_dashboard_css()` 함수 내부의 정적 CSS 템플릿은 `_DASHBOARD_STATIC_CSS = f"""..."""`와 같이 파이썬 f-string으로 선언되어 있음.
  - 신규 폼 컨트롤 CSS 규칙을 추가/수정하는 과정에서 CSS 규칙 블록의 중괄호(`{`, `}`)가 f-string 이스케이프(`{{`, `}}`) 처리되지 않은 채 단일 중괄호로 작성됨.
  - 파이썬 인터프리터가 `background-color: {cfg.color_bg_dark} !important;`를 파싱할 때 `background`를 파이썬 변수명으로 오인하여 표현식 파싱 에러(NameError)를 유발함.

## 🛠️ 2. 아키텍처 및 상세 조치 내역

### 2.1. 폼 입력 컨트롤 UI 3단계 계층 구조 (3-Tier UI Architecture) 정립
사용자와의 인터뷰를 통해 직교적이고 명료한 3단계 상속 및 오버라이드 계층을 확립했습니다:

```
[UI 계층 1단계: Base Form Controls (전역 폼 입력 기본)]
 ├── st.text_input
 ├── st.number_input
 ├── st.selectbox (일반 단일 선택 드롭박스)
 └── st.multiselect (다중 선택 드롭박스 기본 컨테이너)
      │
      ▼ (상속 및 특화 확장)
[UI 계층 2단계: MultiSelect Controls (컴포넌트 그룹 변형)]
 └── st.multiselect
      ├── 1단계 다크 배경/서브그리드/라임 호버 100% 상속
      ├── 네온 사파이어 반투명 유리 질감 태그 칩 (선택 뱃지)
      └── 다중 태그 추가 시 42px 기준 가변 높이 자동 확장 (height: auto; min-height: 42px;)
      │
      ▼ (인스턴스 개별 오버라이드)
[UI 계층 3단계: Instance Override (개별 화면 맞춤 특화)]
 └── pjt_table_mode_select (프로젝트 탭 테이블 모드 셀렉터)
      └── 상단 헤더 액션 버튼 규격(132px × 38px, 딥 사파이어 베이스, 네온 시안 호버 발광) 일체화
```

### 2.2. BaseWeb 외곽선 증발 버그 원천 해결
- 기존의 위험한 와일드카드 선택자를 폐기하고, BaseWeb의 내부 `ValueContainer` 및 직계 자식만을 정밀 타겟팅하도록 수정:
```css
/* [개선 전: 외곽 컨테이너까지 투명화되어 테두리 증발] */
div[data-testid="stSelectbox"] div[data-baseweb="select"] div {
    background: transparent !important;
    border: none !important;
}

/* [개선 후: 외곽선은 1단계에서 견고히 유지하고, 실제 텍스트 영역만 투명화] */
div[data-baseweb="select"] > div > div:first-child,
div[data-baseweb="select"] > div > div:first-child div,
div[data-baseweb="select"] > div > div:first-child span,
div[data-testid="stSelectbox"] div[data-baseweb="select"] div:has(> input),
div[data-testid="stSelectbox"] div[data-baseweb="select"] input {
    color: #FFFFFF !important;
    font-weight: 700 !important;
    background: transparent !important;
    border: none !important;
}
```

### 2.3. f-string 중괄호 파싱 결함 조치 및 중복 CSS 98줄 영구 소멸
1. **f-string 중괄호 전수 치환**:
   - `theme.py` 내 `_get_dashboard_css()`의 1783~1958 라인 범위에서 모든 CSS 규칙 블록 중괄호(`{`, `}`)를 이스케이프(`{{`, `}}`)로 정밀 치환 완료.
   - `{cfg.color_bg_dark}`, `{cfg.grid_size}` 등 실제 파이썬 변수 토큰만 단일 중괄호로 정상 보존.
2. **중복 레거시 CSS 98줄 영구 소멸**:
   - 파일 하단에 잔존하던 구버전 드롭다운 스타일 규칙(UI Tier 5-B, Tier 6-B) 98줄을 완전 삭제하여 스타일 충돌 가능성을 근본적으로 제거.
