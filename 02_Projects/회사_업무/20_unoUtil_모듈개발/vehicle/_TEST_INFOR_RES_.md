## 🏛️ 시스템 흐름 (Architecture)

모듈은 효율적인 데이터 관리를 위해 3단계 Layer로 작동합니다.

1.  **준비 계층 (Ready Layer)**: `TEST_INFORMATION` 객체를 생성하여 물리 단위 계수(`gain`)를 설정하고 기초 정보를 입력합니다.
2.  **핵심 계층 (Core Layer)**: 입력된 정보를 바탕으로 `infor` 딕셔너리와 `df` 데이터프레임을 자동 빌드합니다.
3.  **실행 계층 (Action Layer)**: 분석된 데이터와 결합(`add_info_df`)하거나 `TEST_RESULT`에 최종 결과물을 패키징합니다.

## 🪄 공통 키워드 및 마법의 인자 (**kwargs)

| 키워드 | 타입 | 추천값/효과 | 설명 |
| :--- | :---: | :--- | :--- |
| **unit_ax** | `str` | `'g'` (중력가속도) | 'g' 입력 시 자동으로 **9.80665**를 곱해 물리량 보정 |
| **unit_vel** | `str` | `'kmh'` (시속) | 'kmh' 입력 시 **1/3.6**을 곱해 m/s 단위로 자동 변환 |
| **sr** | `float` | `100` (Hz) | 데이터의 샘플링 주기를 설정하여 시간축 계산의 정밀도 확보 |

> **💡 무한한 스타일 커스텀 자유도**
> `from_dict` 메서드를 사용하면 외부의 거대한 데이터 딕셔너리에서 필요한 정보만 쏙쏙 골라냅니다. 정의되지 않은 키값이 들어와도 무시하므로, 기존 라이브러리와의 **100% 호환성**을 자랑합니다.

## 📖 함수별 상세 가이드 (Docstring)

### 1. `TEST_INFORMATION.__post_init__`
💡 **기능 (Pain Point Killer)**: 인스턴스 생성 버튼을 누르는 순간, 흩어져 있던 변수들을 '차량', '노면', '날씨' 등 카테고리별로 자동 분류합니다. 사용자가 일일이 딕셔너리를 코딩하는 노고를 100% 제거합니다.

* **⚙️ 모듈 전용 키워드**: `gain_ax`, `gain_vel` (단위에 따른 변환 계수 자동 생성).
* **📚 데이터 해석 팁**: 생성 직후 `obj.df`를 확인하세요. 모든 정보가 Pandas 한 줄로 정리되어 있어 엑셀 저장용으로도 완벽합니다.

### 2. `TEST_INFORMATION.add_info_df`
💡 **기능 (Pain Point Killer)**: "이 제동거리가 어떤 타이어에서 나온 거였지?" 라는 혼란을 방지합니다. 분석 결과 데이터프레임 옆에 현재의 모든 시험 정보를 '복사-붙여넣기' 하듯 결합해 줍니다.

* **⚙️ 모듈 전용 키워드**: `df_data` (결합할 대상 데이터프레임).
* **🎨 추천 스타일 키워드**: `how='cross'` (모든 행에 정보를 매칭).
* **💻 실전 응용 예시**:
    ```python
    df_source_result = pd.DataFrame({'float_stop_dist': [33.5, 34.1]})
    # 시험 정보를 결과 데이터 옆에 자동으로 쫙 붙여줍니다.
    df_combined_final = obj_test_info.add_info_df(df_source_result)
    ```

### 3. `TEST_INFORMATION.from_dict`
💡 **기능 (Pain Point Killer)**: 외부 API나 DB에서 가져온 지저분한 딕셔너리에서, 우리 클래스에 꼭 필요한 데이터만 필터링하여 깨끗한 객체를 만들어냅니다.

* **⚙️ 모듈 전용 키워드**: `di` (원본 데이터 딕셔너리).
* **📚 데이터 해석 팁**: `list_valid_fields`를 통해 허용된 데이터만 통과시키는 '보안 게이트' 역할을 수행합니다.
* **💻 실전 응용 예시**:
    ```python
    dict_source_raw = {'req': 'REQ-2026', 'trash': 'ignore', 'surface': 'Dry'}
    # trash 데이터는 버리고 유효한 정보로만 객체를 생성합니다.
    obj_clean_info = TEST_INFORMATION.from_dict(dict_source_raw)
    ```

### 4. `TEST_RESULT.__repr__`
💡 **기능 (Pain Point Killer)**: 변수명만 쳐도 현재 분석이 어디까지 되었는지, 요약 결과가 무엇인지 화면에 즉시 출력합니다. `print()`를 남발할 필요가 없습니다.

* **📚 데이터 해석 팁**: `summary`가 비어있다면 `(Empty)`라고 친절히 알려주어 데이터 유실 여부를 즉시 판단하게 돕습니다.
