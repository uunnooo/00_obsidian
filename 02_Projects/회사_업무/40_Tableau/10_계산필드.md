# 📐 Tableau 계산된 필드 (Calculated Fields) 수식 가이드

> [!NOTE] 💡 개요
> Tableau에서 Dry / Wet / Snow 시험 데이터의 제동거리를 동적 매개변수(`INPUT_BRK_TYPE`, `INPUT_SPEC_TYPE`)에 따라 통합 분석하고, 가중평균 비율을 계산하기 위한 주요 계산된 필드 수식 모음입니다.

---

### 1. `BRK_DIST_INPUT_BRK_TYPE` (제동거리 통합 수식)
선택한 제동 평가 유형(Dry, Wet, Snow)에 따라 적절한 평균 제동거리를 반환합니다.
```sql
// BRK_DIST_INPUT_BRK_TYPE
{ EXCLUDE [SPEC_CD] :
    CASE [INPUT_BRK_TYPE]
        WHEN 'Dry' THEN AVG([TEST_BRK_DRY_BRKGT_BRKGDST_TMPRT_AVRG])
        WHEN 'Wet' THEN AVG([TEST_BRK_WET_BRKGT_BRKGDST_TMPRT_AVRG])
        WHEN 'Snow' THEN AVG([TEST_BRK_SNOW_BRKGT_BRKGDST_DRIVER_AVRG])
    END
}
```

---

### 2. `VAR_FIX_X_AVR_Y` (기준 제동거리)
스펙코드 제외 기준 Dry 제동거리 평균치를 고정 산출합니다.
```sql
// VAR_FIX_X_AVR_Y
{ EXCLUDE [SPEC_CD] :
    AVG(IF NOT ISNULL([TEST_BRK_DRY_BRKGT_BRKGDST_TMPRT_AVRG])
        THEN [TEST_BRK_DRY_BRKGT_BRKGDST_TMPRT_AVRG]
    END)
}
```

---

### 3. `VAR_FIX_X_AVR_RATIO_Y` (가중평균 비율 적용 거리)
```sql
// VAR_FIX_X_AVR_RATIO_Y
[VAR_FIX_X_AVR_Y] * { FIXED [VAR_X_INPUT_SPEC_TYPE] : AVG([VAR_X_SET_RATIO]) }
```

---

### 4. `LABEL_X_SET_RATIO` 및 `LABEL_X_AVR_RATIO_Y` (라벨 출력용)
```sql
// LABEL_X_SET_RATIO
IF [VAR_X_SET_RATIO] > 0 THEN [VAR_X_SET_RATIO] END
```
```sql
// LABEL_X_AVR_RATIO_Y
IF [VAR_FIX_X_AVR_RATIO_Y] > 0
THEN "(" + LEFT(STR(ROUND([VAR_FIX_X_AVR_RATIO_Y], 1)), 4) + ")"
ELSE ""
END
```

---

### 5. `VAR_Y_INPUT_BRK_TYPE` (Y축 동적 매개변수)
```sql
// VAR_Y_INPUT_BRK_TYPE
CASE [INPUT_BRK_TYPE] // Y축 매개변수
    WHEN 'Dry' THEN {FIXED [SPEC_CD] : AVG([TEST_BRK_DRY_BRKGT_BRKGDST_TMPRT_AVRG])}
    WHEN 'Wet' THEN {FIXED [SPEC_CD] : AVG([TEST_BRK_WET_BRKGT_BRKGDST_TMPRT_AVRG])}
    WHEN 'Snow' THEN {FIXED [SPEC_CD] : AVG([TEST_BRK_SNOW_BRKGT_BRKGDST_DRIVER_AVRG])}
    ELSE 0
END
```

---

### 6. `TEST_BRK_SNOW_BRKGT_BRKGDST_DRIVER_AVRG` (스노우 드라이버 평균)
1차와 2차 드라이버 결과의 유무에 따라 평균값 또는 단일 유효값을 자동 선택합니다.
```sql
// TEST_BRK_SNOW_BRKGT_BRKGDST_DRIVER_AVRG
IF NOT ISNULL([TEST_BRK_SNOW_BRKGT_FIRST_DRVR_RES_AVRG]) AND NOT ISNULL([TEST_BRK_SNOW_BRKGT_SECOND_DRVR_RES_AVRG]) THEN
    // 첫번째 결과와 두번째 결과가 다 있으면 두개의 평균 사용
    ([TEST_BRK_SNOW_BRKGT_FIRST_DRVR_RES_AVRG] + [TEST_BRK_SNOW_BRKGT_SECOND_DRVR_RES_AVRG]) / 2
ELSEIF NOT ISNULL([TEST_BRK_SNOW_BRKGT_FIRST_DRVR_RES_AVRG]) THEN
    // 첫번째 결과만 있으면 첫번째 결과 사용
    [TEST_BRK_SNOW_BRKGT_FIRST_DRVR_RES_AVRG]
ELSEIF NOT ISNULL([TEST_BRK_SNOW_BRKGT_SECOND_DRVR_RES_AVRG]) THEN
    // 두번째 결과만 있으면 두번째 결과 사용
    [TEST_BRK_SNOW_BRKGT_SECOND_DRVR_RES_AVRG]
ELSE
    // 둘다 없으면 null 반환
    NULL
END
```

---

### 7. `VAR_X_INPUT_SPEC_TYPE` (X축 동적 스펙 선택)
```sql
// VAR_X_INPUT_SPEC_TYPE
CASE [INPUT_SPEC_TYPE] // 매개변수 값 선택
    WHEN 'SNS' THEN [SNS]
    WHEN 'PTTRNM' THEN [PTTRNM]
    WHEN 'CPTRD_CMPND_CD' THEN [CPTRD_CMPND_CD]
    WHEN 'SPEC_SIZE' THEN [SPEC_SIZE]
    WHEN 'TIRE_RMICH' THEN STR([TIRE_RMICH])
    WHEN 'TIRE_NCSW' THEN STR([TIRE_NCSW])
    WHEN 'TIRE_APTRT' THEN STR([TIRE_APTRT])
    WHEN 'SBTRD_CMPND_CD' THEN [SBTRD_CMPND_CD]
    WHEN 'JNTRC_TYPE_CD' THEN [JNTRC_TYPE_CD]
    WHEN 'GRV_DTH' THEN STR([GRV_DTH])
    WHEN 'FIRST_BT_ANG' THEN STR([FIRST_BT_ANG])
    WHEN 'BDFL_LTH' THEN STR([BDFL_LTH])
    WHEN 'SPEC_CD' THEN [SPEC_CD]
    ELSE "데이터 없음"
END
```
