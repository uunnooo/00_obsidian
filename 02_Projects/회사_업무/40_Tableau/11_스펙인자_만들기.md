# 🛠️ PLM 타이어 스펙 인자 생성 SQL 쿼리

> [!NOTE] 📋 개요
> Tableau 대시보드에서 타이어 규격별 분석을 수행하기 위해 PLM 타이어 스펙 기본 테이블(`tb_pl_dw_spec_plm_tire_bas`)과 시험 의뢰 스펙 테이블(`tb_th_req_tire_spec_bas`)에서 추출하는 주요 칼럼 매핑 정의서입니다.

---

### 1. 주요 추출 칼럼 정의 (SELECT Fields)

```sql
SELECT
    -- [PLM 고유 식별자]
    tb_pl_dw_spec_plm_tire_bas.PLM_SPEC_OBJ_TBLK,   -- PLM 키값
    tb_pl_dw_spec_plm_tire_bas.SPEC_CD,             -- SPEC 코드

    -- [시험의뢰 타이어 기본 스펙]
    tb_th_req_tire_spec_bas.PTTRNM,                  -- 패턴명 (Pattern Name)
    tb_th_req_tire_spec_bas.SPEC_SIZE,              -- 전체 규격 사이즈 (예: 245/45R18)
    tb_th_req_tire_spec_bas.SIZE_INCH,              -- 림 지름 (Inch)
    tb_th_req_tire_spec_bas.SIZE_WIDTH,             -- 단면폭 (Width)
    tb_th_req_tire_spec_bas.SIZE_RATIO,             -- 편평비 (Aspect Ratio)

    -- [PLM 설계 상세 스펙]
    tb_pl_dw_spec_plm_tire_bas.CPTRD_CMPND_CD,      -- 캡트레드 컴파운드 코드
    tb_pl_dw_spec_plm_tire_bas.SBTRD_CMPND_CD,      -- 서브트레드 컴파운드 코드
    tb_pl_dw_spec_plm_tire_bas.TIRE_NCSW,           -- 타이어 공칭 단면폭
    tb_pl_dw_spec_plm_tire_bas.GRV_DTH,             -- 메인 그루브 깊이 (Groove Depth)
    tb_pl_dw_spec_plm_tire_bas.JNTRC_TYPE_CD,       -- 조인트리스 커버 유형 코드 (JLB)
    tb_pl_dw_spec_plm_tire_bas.SNS,                 -- 시즌 구분 (Summer / All-Season / Winter)
    tb_pl_dw_spec_plm_tire_bas.FIRST_BT_ANG,        -- 제1 벨트 각도 (Belt Angle)
    tb_pl_dw_spec_plm_tire_bas.BDFL_LTH             -- 비드필러 길이 (Bead Filler Length)
FROM tb_pl_dw_spec_plm_tire_bas
JOIN tb_th_req_tire_spec_bas
  ON tb_pl_dw_spec_plm_tire_bas.SPEC_CD = tb_th_req_tire_spec_bas.SPEC_CD
```

---

### 2. Tableau 매개변수 바인딩용 스펙 키 리스트
대시보드 X축/필터 전환 매개변수(`INPUT_SPEC_TYPE`)에 등록되는 파라미터 값 목록:
* `SNS` (시즌)
* `PTTRNM` (패턴명)
* `CPTRD_CMPND_CD` (캡트레드 컴파운드)
* `SPEC_SIZE` (규격 사이즈)
* `TIRE_RMICH` (림 인치)
* `TIRE_NCSW` (공칭 단면폭)
* `TIRE_APTRT` (편평비)
* `SBTRD_CMPND_CD` (서브트레드 컴파운드)
* `JNTRC_TYPE_CD` (조인트리스 커버)
* `GRV_DTH` (그루브 깊이)
* `FIRST_BT_ANG` (벨트 각도)
* `BDFL_LTH` (비드필러 길이)
* `SPEC_CD` (스펙 코드 고유값)
