## 1. 개요 및 구축 목적

본 문서는 사내 실차 제동(Dry, Wet, Snow) 평가 데이터베이스(Databricks DW)와 PLM 타이어 사양 데이터를 결합하여 엔지니어링 분석을 수행하는 **`BRK_260309.twb`** 통합 문서의 아키텍처, 집합 동작(Set Action) 연동 메커니즘, 시트 스와핑 최적화 및 안정화 내역을 기록한 공식 엔지니어링 보고서입니다.

## 2. 대시보드 핵심 엔지니어링 아키텍처

```mermaid

    end

    subgraph Param_Layer ["⚙️ 매개변수 및 집합 레이어"]

        SetEngine["11개 사양 집합 (Set Action)<br/>SET_SNS, SET_PTTRNM 등"]
        BoolIntersect["[BOOL_SELECT_SET_SPEC]<br/>11개 집합 AND 교집합 연산"]
    end

    subgraph Visual_Layer ["📊 차트 렌더링 레이어"]
        MainChart["메인 차트 (BRK_DIST_SPEC)<br/>초록 바(전체) vs 수박색 바(선택스펙)"]

    BtnBrk -->|매개변수 동작| P1
    BtnSpec -->|매개변수 동작| P2
```

### 2.1 11종 사양 집합(Set) 교집합 필터링 파이프라인
* **교집합 수식 (`[Calculation_1347983701694119936]`)**:
  ```tableau
  // BOOL_SELECT_SET_SPEC
  [SET_BDFL_LTH] AND [SET_CPTRD_CMPND_CD] AND [FIRST_BT_ANG 집합] AND
  [SET_GRV_DTH] AND [SET_JNTRC_TYPE_CD] AND [PTTRNM (사용자 지정 SQL 쿼리) 집합] AND
  [SBTRD_CMPND_CD 집합] AND [SET_SNS] AND [SET_TIRE_APTRT] AND
  [SET_TIRE_NCSW] AND [SET_TIRE_RMICH]
  ```
* **수박색 바 동적 평균 산출식 (`[Calculation_1740359818890792960]`)**:
  ```tableau
  // BRK_DIST_AVG_SELECT_SPEC
  CASE [Parameters].[매개 변수 1]
      WHEN 'Dry' THEN AVG(IF [Calculation_1347983701708283905] THEN [TEST_BRK_DRY_BRKGT_BRKGDST_TMPRT_AVRG] END)
      WHEN 'Wet' THEN AVG(IF [Calculation_1347983701708283905] THEN [TEST_BRK_WET_BRKGT_BRKGDST_TMPRT_AVRG] END)
      WHEN 'Snow' THEN AVG(IF [Calculation_1347983701708283905] THEN [Calculation_1799469563635376128] END)
  END
  ```

## 3. 핵심 트러블슈팅 및 결함 해결 내역

### 🚨 이슈 1: 세부스펙 원형 버튼 클릭 시 수박색 바 미반응 및 색상 미변경
* **원인**:
  * 원형 버튼 시트의 마크 선반과 대시보드 액션 간의 바인딩 결함 및 집합 초기화 오류.
  * 집합이 비정상적으로 복잡한 다중 유니온 상태로 꼬여 Tableau C++ 엔진이 단일 마크 할당(`assign`)을 거부(Abort)하여 먹통 발생.
* **해결**:
  * `bak5` 정합 구조로 복원: `function="member" level="[SNS]" member="All Season"` 구조 확립.
  * 행 선반(Rows)에 해당 차원 필드를 온전히 유지하여 마우스 클릭 시 대상 집합으로 1:1 직통 전달 복원.
  * 원형 버튼 클릭 시 선택한 스펙만 수박색으로 켜지고, 나머지는 회색(Out)으로 딤 처리되며, 재클릭 시 전체 선택으로 부드럽게 토글 복귀.

### 🚨 이슈 2: 가상 S: 드라이브 유령 추출(hyper)로 인한 열 누락 에러
* **증상**: 추출 시도 시 `[BTNSPECTYPE] 열이 없습니다` (SQLSTATE: 42P01) 팝업 발생.
* **원인**: 과거 파일 내부에 존재하지 않는 가상 드라이브 경로(`S:/260310.hyper`, `S:/Button_Type.hyper`) 참조가 3개 데이터 소스에 잔여물로 박혀있었음.
* **해결**:
  * 파일 내 유령 추출 참조 3건 완전 소거.
  * UI 보조 CSV 파일(`BTNBRKTYPE.CSV`, `BTNSPECTYPENAME.CSV`)을 통합 문서와 동일한 작업 폴더(`D:\uno\99. 기타\3. Tableau\brk\`)로 복사 및 로컬 상대 경로로 직접 연결.

### 🚨 이슈 3: 히스토그램 시트 스와핑 중복 및 파일 비대화
* **원인**: 노면 조건(Dry/Wet/Snow)마다 3개의 히스토그램 시트를 중복 생성하고 시트 스와핑을 적용하여 대시보드 유지보수성 저하.
* **해결**:
  * `DYNAMIC_BRK_DIST` 및 `DYNAMIC_HISTO_BIN` 수식을 신설하여 `HISTO_DRY` 1개 시트에서 Dry/Wet/Snow를 동적으로 단독 처리.
  * 불필요 시트 3종(`HISTO_SNOW`, `HISTO_WET`, `HISTO_DRY (2)`)을 영구 삭제하여 파일 최적화.

## 4. 사용자 레이아웃 및 UI 표준 보존 규격

* **엄격 보존된 좌표 표준 (1920x1080 FHD 기준)**:
  * 상단 제동종류 버튼 (`BTN_BRK_TYPE`): `x=1404, y=1563, w=11995, h=7031`
  * 좌측 스펙비교 버튼 (`BTN_SPEC_TYPE`): `x=468, y=8705, w=5793, h=90402` (디폴트 2줄 개행 `&#10;` 적용)
  * 메인 차트 (`BRK_DIST_SPEC`): `x=468, y=10342, w=42225, h=88721`
  * 상단 제목 표시줄 (`zone id="30"`): `x=14844, y=893, w=31116, h=9450, fontsize=16pt`
* **무결성 검증**:
  * 대시보드 Zone ID 총 30개 고유성 100% 통과.
  * 윈도우 Viewpoint 총 16개 고유성 100% 통과.
